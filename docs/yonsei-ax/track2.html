왜 이 트랙인가

팔로워 수가 아니라, 내 커리어의 방향을 씁니다

AI 시대엔 "내 전문성을 어떻게 알릴까"가 진짜 질문입니다. 그 답이 퍼스널 브랜딩입니다. 단순한 SNS가 아니라 — 커리어 설계의 도구로 다룹니다.

학생일 때 첫 콘텐츠를 시작하면, 졸업할 때 "이 사람은 이 분야"라는 인식이 쌓여 있습니다. 3주면 그 첫돌을 놓습니다.

OPENING DT + 핵심 개념

"퍼스널 브랜딩 = 자기 PR이 아니라, 커리어 설계"

이번 3주, 다루는 핵심 개념 4가지:

  • Sweet Spot — 지식 × 취향 × 관점의 교집합
  • 콘텐츠 Tilt — 남들과 다른 나만의 각도
  • 다각화 — 한 주제를 여러 플랫폼·형태로
  • 커리어 연결 — 전문성이 진로로 이어지는 길

CONTENT PIPELINE

AI 콘텐츠 파이프라인 — 5단계

  1. 아이디어 발굴 — LLM으로 주제 후보 10·20개
  2. 구조 설계 — 후킹·본문·CTA 구조 잡기
  3. 초안 작성 — LLM이 첫 초안, 내가 재구성
  4. 배포 최적화 — 플랫폼별 포맷·해시태그·타이밍
  5. 반응 분석 — 지표 읽고 다음 콘텐츠에 반영

HANDS-ON · 제작 도구

초안은 LLM이, 마감은 내가

  • Claude로 콘텐츠 초안 — 튜토리얼 10분 → 개인 실습 50분
  • Canva로 카드뉴스/썸네일 마감
  • (선택) KlingAI로 숏폼 영상 실험
  • 핵심 원칙 — LLM 초안을 그대로 쓰지 않는다. 내 관점·경험을 덧입힌다

산출: 콘텐츠 제작물 (글 1 + 영상/카드뉴스 1) — 캘린더의 첫 두 칸

HANDS-ON · 캘린더

캘린더는 '실행 계획서'입니다

  • 추적 지표 — 측정할 항목 3~5개 (좋아요·저장·DM·커리어 전환 등)
  • LLM 튜토리얼(5분) → 개인 실습(25분)

TWO TYPES

킬러 콘텐츠 vs 에픽 콘텐츠

기준킬러 콘텐츠에픽 콘텐츠
목적단기 폭발장기 자산
효과트래픽 몰이 · 트렌드 타기검색·신뢰 축적 · "이 사람은 이 분야"
수명짧다 (며칠~몇 주)길다 (몇 달~몇 년)
커리어 가치인지도 확보전문성 내러티브 구축

커리어 브랜딩엔 에픽이 더 중요. 킬러는 가끔, 에픽은 꾸준히

DEEP DIVE

[심화] 반복되는 제작은 Skills에게

아이디어 생성 · 초안 작성 · 포맷팅 · 배포 — 반복되는 콘텐츠 태스크를 Custom GPTs/Skills로 자동화합니다.

3주차 안에 "나만의 콘텐츠 제작 봇" v0를 만들어 봅니다. 이게 8월 자동화 체인의 씨앗입니다.

ANALYZE · ITERATE

반응을 읽고, 캘린더를 고친다

  • 반응 신호 — 좋아요 · 댓글 · 공유 · 저장 · DM
  • 커리어 내러티브 도달 평가 — "내가 겨냥한 사람에게 닿았나" (정량은 참고, 정성이 핵심)
  • 캘린더 수정 — 무엇을 더 / 덜 / 다르게 할지 결정

강의(30분) + 개인 실습(30분) — 실제 반응 사례를 함께 읽습니다
