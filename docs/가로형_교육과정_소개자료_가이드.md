# 가로형 교육과정 소개자료 가이드 (curriculum-intro 스킬)

> **스킬명: `curriculum-intro`** · 생성일 2026-08 · 원본: 롯데이커머스 3트랙 소개자료 (2026.07)

## 1. 이건 뭔가

미팅·사전 공유용 **가로(A4 landscape) 교육과정 소개 문서**를 생성하는 스킬.
커버 → 트랙 상세 → 클로징까지 **섹션 카드를 고객사 커리큘럼에 맞춰 자유 조합**하되,
디자인은 `parent.css` + 컴포넌트 라이브러리로 **100% 재현**한다.

### 포지셔닝 (다른 시스템과 혼용 금지)

| 시스템 | 형태 | 용도 |
|---|---|---|
| `build.py` + `templates/*.html` | 세로 A4 PDF | 정식 제안서 (계약 문서) |
| `modu-slide` 스킬 | 16:9 인터랙티브 덱 | 강의·세미나 화면 발표 |
| **curriculum-intro** | **가로 A4 문서** | **미팅·공유용 커리큘럼 소개** |

롯데 스타일 = "코랄 발표덱도, 세로 제안서도 아닌 제3의 포맷"이라 전용 스킬로 분리됨.
`projects/LGE/LGE_교육과정_소개자료.html`은 modu-slide 계열(코랄·덱 방식)이라 이 스타일과 다름.

## 2. 파일 맵 (아키텍처 3계층)

```
templates/curriculum-intro/
├── parent.css        ← 1계층: 디자인 시스템 전체. 통째 복사. 값 수정 금지.
├── components.md     ← 2계층: 12종 컴포넌트 계약서 (정규 스니펫 + 조합표)
└── golden/
    └── 롯데이커머스_3트랙_교육과정_소개.html   ← 스타일 기준 원본 (골든 샘플)

.claude/skills/curriculum-intro/SKILL.md   ← 3계층: 워크플로우·금지사항 (AI 에이전트용)
```

- **고정 계층** (1·2): 스타일 재현성의 원천. 손대지 않는다.
- **가변 계층** (3): 고객사마다 섹션 구조·메시지·커리큘럼을 새로 설계한다.

### 변수 vs 고정

| 고정 (절대 수정 금지) | 변수 (고객사마다 변경) |
|---|---|
| parent.css의 모든 값 (색·폰트·간격·radius·shadow) | 기업명, 날짜, 커버 메타 |
| 컴포넌트의 HTML 구조·클래스명 | 메시지 카피 (kicker/h2/lead) |
| Pretendard CDN v1.3.9 링크 | 트랙·과정 수, 일차·모듈 구성 |
| 섹션=1페이지 print 규칙 | 산출물, 직군, 운영 차수 |
| sign 비즈팀 공용 서명 1줄 (개인 연락처 금지) | 테마 스왑 시 `--primary` 계열 토큰만 |

## 3. 사용법

### AI 에이전트 (Claude Code / OpenClaw)

스킬은 자동 트리거된다. 트리거 표현 예:

- "가로형 소개자료 만들어줘" / "교육과정 소개 페이지" / "3트랙 소개자료"
- "롯데이커머스 소개자료 스타일로"

명시 호출: "curriculum-intro 스킬 규칙 따라서 만들어줘".

### 워크플로우 요약

1. **입력 수집** — `projects/{기업명}/`의 요구조건·리서치·content.json 우선 참조
2. **섹션 설계 제안** — `COVER → OVERVIEW → [TRACK-GROUP | TRACK-DETAIL]* → [OPERATION] → CLOSING` 조합 목차 확인
3. **HTML 조립** — parent.css 통째 인라인 + 컴포넌트 스니펫 복사 → `projects/{기업명}/{기업명}_{구성}_교육과정_소개.html`
4. **데이터 정합성 검증** — 시간 합계·rowspan·sec-num 연번·차수 산정
5. **PDF 변환** — 아래 커맨드
6. **품질 체크리스트** — SKILL.md Step 6 참조

### 수동 PDF 변환 (검증 완료)

```powershell
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
if (!(Test-Path $edge)) { $edge = "C:\Program Files\Microsoft\Edge\Application\msedge.exe" }
$src  = (Resolve-Path "projects\{기업명}\{파일명}.html").Path
$out  = (Join-Path (Split-Path $src) "{기업명}_교육과정_소개.pdf")
& $edge --headless=new --disable-gpu --no-pdf-header-footer "--print-to-pdf=$out" "file:///$($src -replace '\\','/')"
```

> ⚠️ **반드시 `--headless=new`** — 구형 `--headless`는 `@page landscape`를 무시해 세로로 나온다
> (기존 "Edge는 @page 무시" 이슈의 실제 원인. 2026-08 검증 완료: MediaBox 842×595pt = A4 가로 10페이지)

## 4. 유지보수

### 새 컴포넌트 추가 절차

1. 골든 샘플에는 없는 조합이 필요하면 → PR로 제안
2. `components.md`에 스니펫+사용처 등록
3. `parent.css`에 필요 CSS 추가 (기존 값 보존 원칙, `[확장]` 표기)
4. 골든 샘플은 갱신하지 않음 (원본 기준 유지)

### 스타일 개선 절차

- parent.css를 직접 수정하지 말고 PR로 — 골든 샘플과의 diff 검증 후 반영
- 재현성 검증: 골든 HTML의 CSS 선언과 parent.css를 대조하여 값 드리프트 0 확인
