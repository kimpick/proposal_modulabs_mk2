# 모두의연구소 AI 교육 제안서 생성 가이드

## 1. 전체 워크플로우

```
고객 요구사항 수령
  → projects/{기업명}/요구조건.md      ← 고객 정보·교육 요구 정리
  → projects/{기업명}/제안서/content.json ← 제안서 데이터 작성
  → python build.py {기업명}            ← HTML + PDF 자동 생성
  → PDF 파일명 정리                     ← 제안서_제안서.pdf → {기업명}_AI교육_제안서.pdf
  → projects/{기업명}/{기업명}_AI교육_견적서.md ← 견적서 별도 작성
```

## 2. 프로젝트 폴더 구조

```
projects/{기업명}/
├── 요구조건.md                    ← 고객 요구사항 정리 (최초 작성)
├── {기업명}_AI교육_견적서.md       ← 견적서 (별도 작성)
└── 제안서/
    ├── content.json               ← 제안서 데이터 (핵심)
    ├── proposal_render.html       ← 빌드 결과 HTML
    └── {기업명}_AI교육_제안서.pdf   ← 최종 PDF
```

## 3. 템플릿 선택 기준

`content.json`의 최상위 키에 따라 템플릿이 자동 감지됩니다.

| content.json 키 | 템플릿 파일 | 용도 | 적용 사례 |
|---|---|---|---|
| `tracks` | track.html | 직군별/주제별 다중 트랙 | 기업 교육 (가장 범용) |
| `modules` | module.html | 단일 과정 모듈형 | 개발자 대상 심화 과정 |
| `seminars` | khp-seminar.html | **[K-HP] 기업교육 세미나 전용** | K-HP 사업 제안서 |
| `steps` | roadmap.html | 연간 로드맵 | 장기 교육 계획 |
| `type: "bootcamp"` | bootcamp.html | 부트캠프 상세 커리큘럼 | 대학 부트캠프 |

**선택 팁**: 대부분의 기업·대학 교육은 `track` 템플릿이 적합합니다.

**가로(A4 Landscape) 버전**: content.json에 `"orientation": "landscape"`를 추가하면 `templates/base-landscape.css`가 자동 적용되어 가로 PDF로 출력됩니다 (커리큘럼 가독성용). 기존 세로 제안서에는 영향 없음. 가로 출력은 Chrome 필수 — Edge는 `@page` 설정을 무시해 세로로 나옵니다. 현재 track 템플릿으로만 시각 검증됨 (다른 템플릿은 사용 시 추가 튜닝 필요할 수 있음).

```json
{

  "subtitle": "한 줄 요약",
  "info": {

    "duration": "총 소요 일정"

  "intro": "과정 소개 (HTML 태그 지원)",
  "objective": "교육 목표 (<ul><li> 권장)",
  "tech_stack": ["도구1", "도구2", "..."],
  "infrastructure": ["인프라 항목1", "인프라 항목2"],

      "duration": "기간",
      "tools": ["도구1", "도구2"],
      "modules": [
        {
          "module_name": "모듈명",
          "duration": "시간",
          "items": [
            "<b>항목 제목</b> — 상세 설명",
```

### 선택 필드

| 필드 | 설명 |
|---|---|
| `use_simple_track_label` | `true`: "1", "2" / `false`: "TRACK 1", "TRACK 2" (권장: false) |
| `curriculum_title` | 섹션 05 제목 오버라이드 |
| `section_07_title` | 섹션 07 제목 오버라이드 |
| `design_framework` | track 템플릿에서 섹션 02 앞에 프레임워크 섹션 추가 (섹션 번호 자동 시프트) |

## 5. 도구 일관성 체크리스트

content.json에서 **3곳**의 도구가 서로 일치해야 합니다. 누락이 가장 많이 발생하는 항목입니다.

| 위치 | 설명 |
|---|---|
| `tech_stack` | 03 핵심 도구 — 모든 Track tools의 합집합이어야 함 |
| `tracks[].tools` | 각 Track별 도구 배지 — Track에서 실제 사용하는 도구만 |
| `modules[].items` | 본문 텍스트 — 언급된 도구가 tools에도 포함되어야 함 |

**검증 순서**:
1. 각 Track의 본문(`items`)에서 언급된 도구를 추출
2. `tracks[].tools`에 모두 포함되었는지 확인
3. `tech_stack`이 모든 Track tools의 합집합인지 확인

## 6. 빌드 명령어

```bash
# 전체 기업 제안서 빌드
PYTHONIOENCODING=utf-8 python build.py {기업명}

# 단일 제안서만 빌드
PYTHONIOENCODING=utf-8 python build.py {기업명}/제안서

# 전체 프로젝트 빌드
PYTHONIOENCODING=utf-8 python build.py --all
```

## 7. 트러블슈팅

### 7-1. 인코딩 에러

```
UnicodeEncodeError: 'cp949' codec can't encode character
```

**원인**: Windows 기본 인코딩(cp949)이 이모지/한글 처리 불가
**해결**: `PYTHONIOENCODING=utf-8` 환경변수 필수

### 7-2. PDF 파일명 중복

build.py가 폴더명을 기준으로 `제안서_제안서.pdf`로 생성합니다.

**해결**: 빌드 후 Python으로 rename
```python
import shutil
shutil.move('제안서_제안서.pdf', '{기업명}_AI교육_제안서.pdf')
```

### 7-3. Acrobat 파일 락

PDF가 열려있으면 rename/delete가 불가합니다.

**해결**:
```bash
taskkill //F //IM Acrobat.exe 2>/dev/null
```

### 7-4. 한글 파일명 mv 실패

bash `mv` 명령으로 한글 파일명 처리 시 인코딩이 깨집니다.

**해결**: bash mv 대신 Python shutil 사용

### 7-5. Track 라벨이 위첨자처럼 보임

`use_simple_track_label: true` 설정 시 번호가 10px로만 표시되어 위첨자처럼 보입니다.

**해결**: `use_simple_track_label: false`로 설정 → "TRACK 01" 표시

### 7-6. Track heading 간격이 좁음

base.css 기본값이 너무 타이트합니다.

**해결**: `templates/base.css`에서 아래 값 조정
```css
.track-label { margin-bottom: 8px; }      /* 기본값 4px */
.track-name { margin: 0 0 6px 0; }       /* 기본값 2px */
.track-meta { margin-bottom: 10px; line-height: 1.6; } /* 기본값 4px */
```

## 8. 견적서 작성

제안서와 별도로 markdown으로 작성합니다. content.json에 포함되지 않습니다.

**표준 항목**:
- 오프라인 강의료 (시간 × 단가)
- 온라인 콘텐츠 제공
- 부대비용 (교재, 수료증)
- VAT (10%)
- 결제 조건
