# Skill 1 Agent: 커리큘럼 MD → HTML 변환 가이드

## 개요

커리큘럼 Markdown 파일을 Modulabs 스타일 HTML 문서로 변환하는 파이프라인.
완성된 `.md` 파일 하나만 있으면, 원본 HTML과 동일한 디자인의 문서를 자동 생성합니다.

## 파일 위치

```
ai-education-proposal/
└── md_to_curriculum_html.py   ← 변환 스크립트
```

## 실행 방법

```bash
# 프로젝트 루트에서 실행
cd ai-education-proposal

# 기본 — 입력 파일과 같은 위치에 .html 생성
python md_to_curriculum_html.py projects/도쿄일렉트론코리아/기초교육_RAG_커리큘럼.md

# 출력 경로를 직접 지정
python md_to_curriculum_html.py 기초교육_RAG_커리큘럼.md -o 출력.html
```

## 입력 MD 형식

스크립트가 인식하는 Markdown 구조는 다음과 같습니다:

```markdown
# 기관명 — 과정명

> 부제목

설명 문단 (여러 줄 가능).

---

## 1단계: 단계명 (총시간H)

| 시간 | 모듈명 | 핵심 학습 내용 | 주요 실습 및 구현 스택 |
|------|--------|---------------|----------------------|
| 2H  | 모듈명 | - 항목1<br>- 항목2 | - 실습1<br>- 실습2 |
| 3H  | 모듈명 | - 항목1<br>- 항목2 | - 실습1<br>- 실습2 |

## 2단계: 단계명 (총시간H)

| 시간 | 모듈명 | ... | ... |
| ...  | ...   | ... | ... |

---

## 심화 과정으로 이관되는 항목 (선택 섹션)

| 항목 | 이관 사유 |
|------|----------|
| 항목명 | 사유 |

---

> * 하단 안내문 (선택)
```

### 구조 규칙

| 요소 | 형식 | 필수 |
|------|------|------|
| 제목 | `# 기관명 — 과정명` | O |
| 부제목 | `> 텍스트` | O |
| 설명 | 일반 문단 | O |
| 단계 | `## N단계: 이름 (XH)` | O |
| 표 | 4열 (시간, 모듈명, 내용, 실습) | O |
| 표 항목 | `- 텍스트<br>- 텍스트` | O |
| 이관 항목 | `## ...이관/제외...` + 2열 표 | X |
| 하단 안내문 | `> * 텍스트` | X |

### 특수 마커

표 셀 내부에 다음 마커를 사용하면 HTML에서 컬러 뱃지로 변환됩니다:

| 마커 | 변환 결과 |
|------|----------|
| `**[Trend]**` | 초록색 Trend 뱃지 |
| `**[Paradigm]**` | 빨간색 Paradigm 뱃지 |
| `**[Paradigm Shift]**` | 빨간색 Paradigm Shift 뱃지 |
| `**굵은 텍스트**` | `<strong>` 볼드 |

## 출력

- Modulabs 스타일 HTML (Tailwind CSS 기반)
- 네이비 헤더 + 그라데이션 장식
- Trend / Paradigm 컬러 뱃지
- 반응형 테이블 (rowspan 단계 구분)
- 심화 이관 항목 테이블 (있는 경우)
- 하단 인쇄 버튼 (PDF 변환 가능)

## 전체 워크플로우

```
1. 피드백 수렴 → 커리큘럼 MD 작성
2. python md_to_curriculum_html.py 커리큘럼.md
3. 브라우저에서 HTML 확인 / 인쇄 버튼으로 PDF 저장
```

## 예시

```bash
# 도쿄일렉트론코리아 기초 교육 커리큘럼
python md_to_curriculum_html.py \
  projects/도쿄일렉트론코리아/기초교육_RAG_커리큘럼.md

# 출력:
#   projects/도쿄일렉트론코리아/기초교육_RAG_커리큘럼.html
#   3단계 / 9모듈 / 심화이관 5건
```
