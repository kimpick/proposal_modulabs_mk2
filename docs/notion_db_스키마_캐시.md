### ⚠ `프로필 활용`은 게이트로 쓸 수 없다 (2026-09-04 확인)

179명 중 값이 기록된 사람이 **2명**뿐이다 (`동의` 1 · `확인 필요` 1 · **NULL 177**).
실제로 제안서에 실린 강사도 이 필드가 미기재 상태였다.

**차선 기준: `포괄 약정 = 완료`** 를 쓴다. 계약 관계가 확립된 강사라는 뜻이고 현행 관행보다 엄격하다.
이 필드를 실제 게이트로 운영하려면 DB 정비가 선행돼야 한다.

### 강사 후보 조회 예시

```sql
SELECT "이름", "경력(연차)", "소속/직무", "학력/전공", "강의 분야",
       CASE WHEN "이력서 (PDF)" IS NULL OR "이력서 (PDF)"='' THEN 'N' ELSE 'Y' END AS 이력서
FROM "collection://1d1137ef-edf6-811a-a786-000b9acd6dc0"
WHERE "구분"='주강사' AND "포괄 약정"='완료'
  AND ("강의 분야" LIKE '%업무 자동화%' OR "강의 분야" LIKE '%데이터분석/시각화%')
```

`강의 분야`는 multi_select라 SQL에서 JSON 배열 문자열로 들어온다 → `LIKE '%값%'` 로 매칭한다.

## 산출물 작성 시 지켜야 할 것

- **성명** — 마스킹(`홍*동`). `validate_content.py`의 `validate_compliance()`가 검사한다.
- **연락처·이메일·주소** — 산출물 금지. 조회 단계에서 아예 가져오지 않는다.
- **`메모`·`강의료(중앙값)`** — 내부 정보. 산출물 금지.
- **현재 소속** — 기관 유형으로 순화한다(예: `제조 대기업 사업본부`). 마스킹된 성명과 소속 실명을 함께 두면 개인 식별이 쉬워진다.
- **교육·활동 실적 기관** — 실명 유지 가능(설득 근거). 위 순화 대상과 구분할 것.
