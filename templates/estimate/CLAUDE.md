# 견적서 자동화

이 폴더는 견적서 자동화를 위한 참고 양식과 템플릿을 관리합니다.

## 폴더 구성

```
templates/estimate/
├── CLAUDE.md              ← 이 파일
├── references/            ← 참고할 견적서 양식 (여기에 파일 추가)
└── template.md            ← 자동 생성용 템플릿 (추후 작성)
```

## 데이터 소스

견적서 생성 시 다음 파일에서 데이터를 읽어옵니다:

| 소스 파일 | 제공 정보 |
|---|---|
| `projects/{기업명}/요구조건.md` | 고객 정보, 예산 범위, 일정 |
| `projects/{기업명}/제안서/content.json` | 트랙별 시간, 도구, 모듈 구성 |

## 사용법

참고 양식을 `references/` 폴더에 넣은 후 템플릿 작업을 진행합니다.
