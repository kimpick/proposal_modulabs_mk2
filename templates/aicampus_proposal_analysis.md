### 4.2 테이블 스타일 공통 규칙

- **헤더 행**: 진파랑(#203A7A) 배경 + 흰색 굵은 텍스트
- **데이터 행**: 흰색/옅은회색(#F2F2F2) 교차 (zebra striping)
- **병합 셀**: 심사절차, 직군 등 반복값은 병합
- **테두리**: 실선 1pt, 검은색
- **셀 패딩**: 상하 2pt
- **텍스트 정렬**: 헤더=가운데, 첫 열=가운데, 나머지=왼쪽

## 6. 반복 패턴 & 템플릿화 요소

### 6.1 관련문항 박스
- 모든 소절(1.1, 1.2, 2.1 …) 상단에 배치
- 연한 파랑(#D6E4F0) 배경
- `[1차]` / `[2차]` 태그로 심사 차수 표시
- 하단에 체크리스트 형태의 평가 요소 나열

### 6.2 체크리스트 제목 (□, ▶)
- `□` — 주요 항목 제목
- `▶` — 하위 단계/세부 항목
- `•` — 불릿 포인트 (본문 내)

### 6.3 "돌아가기(Ctrl+클릭)" 링크
- 각 소절 상단 관련문항 박스 내 배치
- PDF 내 하이퍼링크로 목차/참조표와 연결

### 6.4 과정별 반복 구조 (Ⅳ장)
6개 훈련과정이 동일 구조로 반복:
```
과정명 + 직군 + 교강사 요약표
→ 교과과정 상세 테이블 (모듈/교과목/시간/강사)
→ 주간 훈련 운영 계획표
```
