# 🚀 AI 제안서 생성 워크플로우

AI 에이전트가 새로운 교육 제안 요청을 받았을 때 수행하는 표준 절차입니다.

## Step 1. 컨텍스트 파악
- [ ] 루드 디렉토리의 `AGENT_GUIDE.md`를 읽고 기본 수칙을 숙지한다.
- [ ] `projects/<대상기업>/context.md`가 존재하는지 확인하고, 해당 기업의 비즈니스 배경과 제약 사항을 파악한다.
- [ ] (없을 경우) 사용자와 대화하여 필수 기업 정보를 수집하고 `context.md`를 먼저 생성한다.

## Step 2. 제안 타입 선정
- [ ] 제안 범위에 따라 적절한 템플릿 타입을 결정한다.
  - 전사적 계획 → `roadmap`
  - 직무별 워크샵 → `track`
  - 특정 기술 교육 → `module`
  - 정부지원 기초교육 → `literacy`

## Step 3. content.json 생성
- [ ] `schemas/` 폴더에서 선택한 타입의 `.example.json`을 읽는다.
- [ ] `context.md`의 내용을 반영하여 `projects/<기업명>/<과정명>/content.json`을 작성한다.
- [ ] [중요] 임의의 가공된 정보가 아닌, 확보된 요구사항에 기반한 실무적인 커리큘럼을 구성한다.

## Step 4. 빌드 및 검증
// turbo
- [ ] `python build.py <기업명>/<과정명>` 명령을 실행하여 HTML과 PDF를 생성한다.
- [ ] 생성된 HTML을 읽어 오타, 레이아웃 붕괴, 스키마 오류가 없는지 최종 확인한다.

## Step 5. 보고 및 저장
- [ ] 작업 완료를 보고하고, 변경 사항을 Git에 커밋/푸시한다.
