# 추천 강사 후보군 추가 스킬

이력서를 받아 제안서에 "추천 강사 후보군" 카드 섹션을 추가합니다. **핵심은 이력 나열이 아니라, 이 강사가 왜 이 교육 과정에 적합한지를 설명하는 것**입니다.

## 입력

1. **기업명** (args) — `projects/{기업명}/제안서*/content.json`이 대상. 제안서 폴더가 여러 개면 사용자에게 확인
2. **이력서** — 대화에 첨부된 PDF/이미지/텍스트, 또는 파일 경로
3. 이력서가 없으면 요청하고 중단

## 지원 템플릿

`instructors` 배열은 **module.html, track.html, guide.html**에서 렌더링됩니다. 대상 content.json이 seminars/steps/bootcamp 타입이면 지원되지 않음을 안내하고 중단하세요.

- 섹션 번호는 템플릿이 자동 처리 (강사 섹션이 들어가면 일정 협의 섹션이 한 칸 뒤로 밀림)
- 강사 1명당 1페이지 카드, 여러 명이면 `후보 01`, `후보 02`로 자동 넘버링
- 기존 instructors가 있으면 배열 끝에 **추가** (덮어쓰지 않음)

## 작성 절차

### 1. 과정 이해 (필수 선행)

대상 content.json을 읽고 다음을 파악:
- 과정 주제·핵심 기술 (tech_stack), 수강 대상 (info.target), 모듈 구성
- 이 과정에서 강사에게 요구되는 역량이 무엇인지 (예: 실습 코칭, 특정 도구 경험, 도메인 이해)

### 2. 이력서에서 적합성 근거 추출

이력서 전체에서 **이 과정과 연결되는 것만** 선별:
- 과정 주제와 직결되는 실무 프로젝트 (도메인 일치 > 기술 일치 > 일반 경력 순으로 우선)
- 강의 이력 (시간 수, 기관, 만족도 등 정량 지표 우선)
- 저서·역서·특허 등 권위 근거
- 과정과 무관한 경력은 과감히 제외 (예: 금융 모델링 경력은 금융사 대상 과정이 아니면 한 줄로 압축)

### 3. instructors 항목 작성

```json
{
  "category": "{과정 성격을 나타내는 짧은 배지 — 예: 콘텐츠 DB화 파이프라인 과정, RAG 챗봇 과정}",
  "name": "{성}*{끝글자}",
  "headline": "{전문성 요약 한 줄 — 'A·B / C 교육 전문' 형태}",
  "bio": "{4~5문장. ①현직/대표 경력 소개 ②과정 주제와 직결되는 실무 성과 ③그 경험이 본 과정 구조·대상과 어떻게 연결되는지 명시 ④수강 대상을 코칭할 수 있는 이유. 반드시 '본 과정'과의 연결을 문장으로 씀}",
  "expertise": ["{태그 5개 내외 — 과정 tech_stack과 겹치는 키워드 우선}"],
  "experience": [
    "{불릿 5개 내외, 각 100자 이내 — 정량 성과(시간 수·절감률·만족도) 포함, 과정 적합성 높은 순서로 배치}"
  ],
  "metrics": [
    { "value": "{숫자+단위 또는 짧은 단어}", "label": "{지표 설명 10자 내외}" }
  ]
}
```

**작성 규칙:**
- **실명 마스킹 필수**: "차성재" → "차*재" (3글자), "엄준호" → "엄*호". 4글자 이상은 가운데 모두 마스킹
- **bio가 스킬의 핵심**: 이력서 요약이 아니라 "왜 이 과정에 이 강사인가"의 논증. 과정의 커리큘럼 구조(예: 추출→구조화→저장→생성)나 수강 대상(예: 비개발·개발 혼합 조)을 직접 언급하며 연결
- **metrics 3개 고정**: 이력서에서 가장 임팩트 있는 정량 지표 3개 (강의 시간, 만족도, 성과 수치 등). 없으면 "N학기", "N과목" 등으로 구성
- 연락처·생년월일·주소 등 개인정보는 절대 포함하지 않음

### 4. 반영 및 빌드

1. content.json의 `"output"` 키 앞에 `instructors` 배열 삽입 (이미 있으면 배열에 항목 추가)
2. 검증: `PYTHONIOENCODING=utf-8 python3 scripts/validate_content.py {기업명}/제안서`
3. 빌드: `PYTHONIOENCODING=utf-8 python3 build.py {기업명}`
4. 결과 보고: 추가된 강사 카드 요약(배지·헤드라인·metrics) + PDF 경로 안내
