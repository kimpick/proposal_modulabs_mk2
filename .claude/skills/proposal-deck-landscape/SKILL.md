# 교육 제안서 → 가로 슬라이드 덱 변환 스킬

## 목적
세로 스크롤형 제안서(또는 대화·문서 안의 제안 내용)를 **16:9 가로 고정 슬라이드 덱**으로 변환한다.
각 슬라이드는 화면·프로젝터 크기에 맞춰 자동 스케일되고, 내용이 넘치면 자동 축소되어 잘리지 않으며, `Ctrl/⌘+P`로 A4 가로 PDF(슬라이드 1장 = 1페이지)로 저장된다.

## 언제 쓰나
- 기존 제안서 HTML(세로형)을 발표용 가로 덱으로 바꿀 때
- 커리큘럼·견적·실적이 대화/문서에 정리되어 있고 그걸 슬라이드로 옮길 때

---

## 작업 절차

### Step 1 — 원본 내용 파악
입력이 무엇이든(HTML 파일, 마크다운, 대화 맥락) 먼저 **슬라이드로 쪼갤 내용 단위**를 뽑는다.
전형적인 제안서 슬라이드 구성은 다음과 같다. 원본에 있는 것만 사용하고, 없는 건 만들지 않는다.

1. 표지 (고객사 × 모두연 / 제안 제목 / 범위·일자)
2. 배경 — 왜 지금인가 (인용·핵심 지표·로드맵 플로우·핵심 과제)
3. 실적 한눈에 (KPI 4개 + 로고 칩)
4. 대규모 사례 (사례 카드 2~3개, 지표 포함)
5. 실제 산출물 (MVP 카드)
6. 레퍼런스 (공공·대학 등 컬럼 리스트)
7. 적합성 매핑 (고객 과제 × 우리 역량 테이블)
8. 기대 효과 (Before/After)
9. 제안 커리큘럼 (트랙 표 + 단계 설계 + 왜 우리인가)
10. 견적 요약 (총액 배너 + 견적 테이블)
11. 맺음말 (핵심 메시지 + 담당자 서명)

### Step 2 — 브랜드 색상 결정
`assets/deck-template.html` 를 작업 폴더로 복사한 뒤 `:root` 의 색상 토큰을 확인한다.
기본값은 **롯데/모두연 레드**(`--primary:#EE3E4C; --primary-dk:#C92434`)다.
- 고객사 브랜드 색이 뚜렷하면 `--primary`, `--primary-dk`, 표지/맺음말 그라디언트 색만 교체한다.
- 확신이 없으면 기본 레드를 유지한다. (그래야 모두연 톤이 일관된다.)
- `--blue/--green/--purple/--amber` 등 보조색과 나머지 토큰은 건드리지 않는다.

### Step 3 — 슬라이드 채우기
템플릿의 예시 슬라이드 3개(표지·KPI·맺음말)를 참고해, Step 1에서 뽑은 각 단위를
`<section class="slide"> … </section>` 하나로 만든다.

**반드시 지킬 구조**
```html
<section class="slide">
  <div class="fit-frame">          <!-- 표지·맺음말은 class="fit-frame center" -->
    <div class="fit-content">
      <span class="sec-num">01 / 배경</span>
      <p class="kicker">왜 지금인가</p>
      <h2>슬라이드 제목</h2>
      <p class="lead">한 줄 리드 문장</p>
      <!-- 본문: 아래 컴포넌트 라이브러리에서 골라 배치 -->
      <p class="note">출처/각주</p>
    </div>
  </div>
</section>
```
- `.fit-frame > .fit-content` 구조를 절대 깨지 말 것. 이 구조 덕분에 내용이 720px를 넘으면 JS가 자동 축소한다.
- 원본 문구·수치는 **그대로 옮긴다**. 요약·창작하지 않는다.

### Step 4 — 슬라이드 밀도 규칙 (가장 중요)
가로 프레임은 세로보다 세로 공간이 적다. 한 장에 과하게 담으면 자동 축소로 글자가 작아진다.
- **표가 12행을 초과**하면 두 슬라이드로 분할한다. (예: 견적 테이블을 "교육비" / "재료·운영비+합계"로 분할)
- **카드가 6개를 초과**하면 두 슬라이드로 나눈다.
- 한 슬라이드는 "제목 + 리드 + 본문 블록 1~2개" 정도가 이상적이다.
- 분할한 슬라이드는 제목에 `(1/2)`, `(2/2)` 를 붙여 연속성을 표시한다.
- 표지·맺음말·인용 슬라이드는 여백을 살려 담백하게 둔다.

### Step 5 — 마무리
- 예시 슬라이드에 남은 플레이스홀더(`{{...}}`)와 주석은 모두 제거하거나 실제 값으로 교체한다.
- `<title>` 을 실제 제목으로 바꾼다.
- 파일을 `/mnt/user-data/outputs/{고객사}_{과정명}_발표덱_가로.html` 로 저장한다.
- `present_files` 로 사용자에게 전달하고, 조작법을 한 줄로 안내한다:
  "화살표 키(← →)로 넘기고, F로 전체화면, Ctrl/⌘+P로 A4 가로 PDF 저장."

## 컴포넌트 라이브러리 (본문 블록 선택표)

내용 유형에 맞는 클래스를 골라 `.fit-content` 안에 배치한다. 상세 마크업은 `assets/deck-template.html` 참고.

| 내용 유형 | 클래스 | 비고 |
|-----------|--------|------|
| 핵심 수치 4개 | `.grid.g4 > .kpi` (`.n`, `.n small`, `.l`) | 실적/성과 지표 |
| 고객사 로고 나열 | `.chips > .chip`(`.chip.big` 강조) | 텍스트 칩 |
| 인용구 | `.quote`(`.q`, `.by`, `.mark`) | 회장·임원 발언 등 |
| 단계 흐름 | `.flow > .step`(`.st`,`.sd`,`.ss`) | 로드맵·프로세스 |
| 아이콘 과제 카드 | `.grid.g4 > .task`(`.ti`,`.tt`,`.td`) | 4대 과제 등 |
| 대규모 사례 | `.case`(`.ctop`>`.co`/`.cat`, `.desc`, `.metrics`>`.metric`, `.taglist`) | 좌측 레드 라인 |
| 실습 산출물 | `.grid.g2 > .mvp`(`.mh`>`.idx`/`.mt`, `.row`>`.tag`/`.val`) | `.val.tech`/`.val.eff` 색 구분 |
| 레퍼런스 컬럼 | `.grid.g2/.g3 > .refcol`(`.refhd`, `ul>li>span`) | 공공/대학 리스트 |
| 과제×역량 매핑 | `.tbl`(`.task-c`, `.pill.b/.r/.g`) | 다크 헤더 표 |
| Before/After | `.ba-head` + `.ba`(`.task-name`,`.before`,`.arrow`,`.after`,`.gain`) | 5열 그리드 |
| 커리큘럼 표 | `.prop`(`.trk`,`.course`,`.core`,`.tgt`,`.hrs`,`tr.sumrow`, `.badge-*`) | 트랙별 |
| 트랙 카드 | `.track.t1~t4`(`.th`>`.tk`/`.tn`/`.tp`, `.tb`) | 색상 헤더 |
| 견적 | `.est-total`(`.big`,`.ko`,`.per`) + `.est`(`.cat`,`.item`,`.r`,`.memo`,`tr.sub`,`tr.total`) | 총액 배너 + 표 |
| 강조 다크박스 | `.why`(`h3`, `ul>li>b`) | "왜 우리인가" |
| 2단 레이아웃 | `.split`(1.2fr / 0.8fr) | 표+박스 나란히 |
| 각주 | `.note` | 출처·조건 |
| 배지 | `.badge.badge-red/blue/green/purple`, `.pill.b/r/g` | 상태·레벨 |

### 레이아웃 팁
- 좌우 2단이 필요하면 `.split`, 균등 분할은 `.grid.g2/.g3/.g4`.
- 표지·맺음말·순수 인용 슬라이드는 `.fit-frame center` 로 세로 가운데 정렬.
- 다크 배경 슬라이드(`.cover`, `.closing`)에서는 `.kicker` 가 자동으로 밝은색으로 바뀐다.

## 원칙
- **내용 보존**: 원본 수치·문구를 그대로. 슬라이드는 재배치일 뿐 재작성이 아니다.
- **1슬라이드 1메시지**: 넘치면 나눈다. 자동 축소는 안전망이지 밀어 넣는 핑계가 아니다.
- **브랜드 일관성**: 특별한 이유가 없으면 모두연 레드 유지.
- **가로 진짜 유지**: `.deck` 는 항상 1280×720. 이 값을 바꾸지 말 것.
- **출처 표기**: 사내 리서치/공개 보도 등 근거가 있으면 `.note` 에 남긴다.
