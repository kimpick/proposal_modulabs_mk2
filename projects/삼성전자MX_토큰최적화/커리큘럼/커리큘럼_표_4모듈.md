## 5차원 → 4모듈 매핑

기존 5차원 리서치 체계와 1:1로 대응합니다. 근거 문서는 그대로 유효합니다.

| 모듈 | 포함 차원 | 이 모듈이 답하는 질문 |
|---|---|---|
| 1. 토큰 소비 구조와 크레딧 런웨이 진단 | (전제 — 문제 정의) | 무엇이 크레딧을 태우고 있는가 |
| 2. 요청 설계와 컨텍스트 관리 | **프롬프트 + 컨텍스트** | 무엇을 넣을 것인가 |
| 3. 모델 라우팅과 실행 루프 설계 | **하네스 + 루프** | 어떻게 돌릴 것인가 |
| 4. 소비 가시화와 런웨이 운영 | **모니터링** | 어떻게 유지할 것인가 |

**설계 논리**: 진단 → 입력 → 실행 → 관제. 모듈 2가 개인이 오늘 바꿀 수 있는 영역이고, 모듈 3이 절감 폭이 가장 큰 영역이며, 모듈 4가 나머지 셋을 지속시키는 전제입니다.

## 운영 형태별 적용

| 형태 | 구성 |
|---|---|
| **임원 세미나** | 모듈 1의 문제 정의 + 모듈 2~4의 핵심 레버 각 1개 + 조직 결정 사항. 실습 제외 |
| **반나절** | 모듈 1·2·3 실습 유지, 모듈 4는 강의·데모로 축소 |
| **1일** | 4개 모듈 전체 + before/after 실측 완주 |

> ⚠️ 어느 형태든 **모듈 1의 기준선 측정과 모듈 4의 after 측정은 유지**해야 합니다. 이 둘을 빼면 실측형 과정이 아니라 일반 강의가 됩니다.
