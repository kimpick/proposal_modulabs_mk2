## 이 프로젝트의 피벗 요지

**두 개의 축이 맞물립니다.**

1. **크레딧 런웨이 (왜 지금)** — 고객 진술의 핵심은 "비용이 비싸다"가 아니라 **"월말에 크레딧이 소진돼서 일을 못 한다"**입니다. KPI를 비용 절감에서 **런웨이**(`남은 크레딧 ÷ 일 평균 소모`)로 전환.
2. **컨텍스트 품질 (줄여도 되나)** — 2026년 8월 기준, 최신 모델은 단일 사실 검색은 96~99%로 해결했지만 **여러 근거를 종합하는 실제 업무는 74~89%**이고 실효 컨텍스트는 광고 창의 **50~65%**입니다. **줄이는 것은 절제가 아니라 개선**이며, 크레딧 절감과 정답률 향상이 같은 방향입니다.
   ⚠️ 원 연구(Chroma "Context Rot")는 **2025-07 발표·이전 세대 모델** 대상 — 인용 시 세대 구분 필수. → [리서치/컨텍스트_품질_프레임.md](리서치/컨텍스트_품질_프레임.md) §2.3

→ 그 위에 흩어져 있던 사내 토큰 자료를 **프롬프트 / 컨텍스트 / 하네스 / 루프 / 모니터링 5차원**으로 재구성했습니다.

**세미나 논리 흐름**: "월말에 멈춘다"(문제) → "줄이면 품질도 좋아진다"(반론 차단) → "이렇게 줄인다"(5차원)
