# 현대자동차 2차 교육 — Agentic Security 진행 계획

현대자동차 차량사이버보안개발팀 · 2026년 6월 8일(월)~12일(금) · 1일 7시간 × 5일

## **개요**

사이버보안 실무진이 보안 점검을 자율적으로 수행하는 AI 에이전트를 직접 구축하는 5일 실습 과정입니다. 도구 사용법을 넘어, 에이전트가 안정적으로 동작하도록 통제하는 하네스(Harness) 엔지니어링의 5가지 구성 요소(시스템 프롬프트, 에이전트 루프, 컨텍스트 관리, 도구 설계, 안전장치)를 중심으로 진행합니다. 단일 에이전트를 하네스로 통제하는 것에서 시작해, 여러 에이전트를 조율하는 단계까지 다룹니다. RAG보다 MCP 활용에 무게를 두며, 보안 에이전트 설계(SAST)와 모의 해킹·방어를 실습합니다.

실습은 GitHub Codespaces 기반의 통일된 클라우드 환경에서 Claude Code, Codex를 사용해 진행하며, 수강생 전원이 동일한 환경에서 실습합니다.

## **전체 목표**

하네스 엔지니어링의 5가지 구성 요소를 이해하고, 이를 활용해 보안 점검을 자동화하는 에이전트를 구축한다.

## **Day별 진행**

### **Day 6 (6/8 월) — 2차 인트로 · Security by Design**

2차 과정의 방향을 정렬하고, 에이전트가 RAG와 어떻게 다른지부터 짚습니다. 하네스의 핵심 개념을 잡은 뒤, 시스템 프롬프트([CLAUDE.md](http://CLAUDE.md))에 사내 보안 정책을 주입해 에이전트의 행동을 정책 수준에서 통제하는 방법을 다룹니다. 이어 PR 단계를 가정한 보안 코딩 점검(SAST) 에이전트를 처음으로 구현합니다.

### **Day 7 (6/9 화) — OpenClaw 실행 자동화**

OpenClaw 샌드박스 환경에서 에이전트가 터미널과 도구를 자율적으로 제어하는 기초를 다룹니다. MCP 개념을 익히고, 기존 보안 스캐너 같은 도구를 MCP로 연결해 에이전트가 스스로 실행하고 그 결과 로그를 해석하도록 만듭니다.

### **Day 8 (6/10 수) — 중앙 통제소 · 검증과 안전장치**

여러 에이전트를 하나의 통제소가 지휘하도록 오케스트레이션을 설계합니다. 같은 점검을 반복해도 결과가 흔들리지 않도록 검증 루프를 걸고, 위험한 명령은 관리자 승인을 거치게 하는 안전장치(HITL)를 구현합니다. 승인 이력과 결정 사유는 감사 로그로 남깁니다.

### **Day 9 (6/11 목) — Threat Intelligence 결합**

타깃 시스템을 자동으로 정찰해 공격 표면을 식별하고, 수집한 정보를 CVE/KEV/EPSS 취약점 정보와 연결해 공격 시나리오를 추론합니다. 도출한 시나리오를 바탕으로 모의 해킹을 수행하며 공격자 관점의 점검 흐름을 체득합니다.

### **Day 10 (6/12 금) — 통합 PoC · 최종 리뷰**

5일간 다룬 요소를 하나의 보안 자동화 에이전트로 통합해 전체 점검 파이프라인을 실행합니다. 점검 결과를 보고서로 자동 생성하고 방어 방안까지 제안하도록 확장한 뒤, 각자의 부서 도메인에 적용해 봅니다. 마지막으로 산출물을 공유하고 개별 피드백과 종합 리뷰로 마무리합니다.
