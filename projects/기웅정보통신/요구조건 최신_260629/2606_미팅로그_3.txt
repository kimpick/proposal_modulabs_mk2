## 질문 사항

1. 총 교육
    1. 기초 /각 클래스별 30~35명 / 2개 분반
        1. 2개 클래스
        2. 21시간 / 3회 = 7시간씩 
        3. **1주일 1회 * 3시간 = 21시간 (화/목) = 46시간** 
    2. 심화 / 20명 이내
        1. 7시간 * 9회 
        2. 1주일에 2회 = 14시간
        3. **1달 과정으로 = 7시간 * 8회 = 56시간**
        4. 프로젝트 밀착된 교육
2. 교육 시작 예상 일자
    1. ASAP 
    2. 7월 중에 시작
        1. 기초 시작 하고 심화
3. 교육 총 예산
    1. 이전에 제안줬던 금액
    2. 시간당 70만원
4. 교육 대상
    1. 3개 회사의 교육대상자들, 회사에서도 고민중
    2. 직군 : 개발자 관련된 심화 내용들
        1. 도메인이 다 다름
        2. 플랫폼 회사 : 백엔드, 프론트엔드, 퍼블리셔
        3. 이지스 : 풀스택 개발자, ERP 솔루션 개발회사
        4. 3번째 회사 : 이지스와 플랫폼 회사의 중간
5. 교육장 
    1. 기초 : 회사 근처 교육장 섭외
    2. 심화 : 사내에서 가능
6. 제안 버전
    1. 교육 : 기초, 심화
    2. 컨설팅 : 어떤 것을

8. 대상자 선정 어려움
