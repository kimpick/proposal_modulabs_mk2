04 / 3단계

팀 업무 워크플로우 제작 · 12H

설계는 2단계에서 끝났다 — 첫 시간부터 제작

팀의 업무 흐름을 4단계로 절단해 팀원 1인이 1단계씩 담당. 마지막 회차는 차수 내 5팀이 같은 미션으로 겨루는 해커톤.

일차시간핵심
Day 1
조립 착수		4H업무 흐름 매핑 후 4단계 절단, 입출력 규격 확정(0.7H) · 메인 구성과 오케스트레이션 지시문(0.8H) · 단계별 구성 4개 병렬 제작 — 팀원 1인당 1단계(2H) · 1차 통합 실행과 실패 지점 기록(0.5H)
Day 2
완성·공유		4H실패 사례 기반 지시문 튜닝(1.5H) · 지식 소스 정비와 민감정보 제거 재점검(1H) · Launch·조직 공유 후 팀 외 1명 블라인드 테스트(1H) · 운영 문서 1p — 소유자·갱신 책임·넣지 말 것(0.5H)

3단계 설계의 전제

  • 차수 편성 — 부서 단위 18차수, 차수당 20명 5팀. 교육장 1개에서 오전·오후반 2슬롯, 약 27영업일 소화
  • 심사 기준 사전 공개 — 첫 회차에 공개한 항목 그대로 해커톤에 적용. 준비 방향이 흔들리지 않음
  • 운영 문서 필수 — 만들고 끝내지 않고 소유자·갱신 책임을 명시해 인계 가능한 상태로 종료
05 / 연결 구조

산출물이 다음 단계의 입력

단계마다 만든 것이 버려지지 않는다

각 단계의 산출물을 다음 단계가 그대로 받아 쓰도록 설계. 교육이 끝나면 조직에 자산이 남는 구조.

단계입력이 단계에서 만드는 것다음 단계로 넘기는 것

350명		1단계 기획서 초안 · 업무 맥락 문서개인 에이전트 350건(Launch·실업무 3건 통과) · 결과 보고서 · To-be 실측치팀 워크플로우 초안 90건개인 에이전트
3단계
90팀		개인 에이전트 · 팀 워크플로우 초안팀 업무 워크플로우 90건 · 운영 문서 1p · 해커톤 산출물선택 · 확장 과정선택 · IT 심화 A안

모든 산출물은 롯데e커머스 소유 · 교육 중에는 수강생 사내 PC에 저장하고 고객사가 지정하는 문서 저장소로 이관 · 모두의연구소는 산출물 사본과 사내 데이터를 보유하지 않음

06 / 선택 과정

선택 3종 · 채택 여부에 따라 차수와 견적 조정

IT 직군 2종 + 전사 확장 1종

IT·인프라·정보보안 150명은 1단계만 이수하고 2·3단계 대상이 아님. 이 직군의 후속 과정이 A안·B안.

A안과 B안 선택 기준

  • 사내 데이터·문서를 AI에 연결하는 것이 목표 → A안. 커넥터·MCP 서버를 직접 구현하는 개발 성격
  • 현업 지원과 GE 운영 정착이 목표 → B안. 코드 작성 없이 화면 안에서 완결
  • 두 과정은 대상이 같고 내용이 겹치지 않으므로 병행 편성도 가능
07 / 선택 · IT 심화 A안

사내 문서·데이터 연동 인프라 · 12H

비개발 직군이 사내 데이터를 쓸 수 있게 만드는 기반

1단계에서 나온 문서 500건을 검색 가능한 지식 베이스로 정규화하고, Gemini Enterprise에 연결해 운영까지 인계.

모듈시간핵심
문서·데이터 연결 설계4H에디션별 기능 경계 정리 · 커넥터 설계(연결 대상·인덱싱 범위·권한 상속 검증) · Agent Search 데이터스토어 구축 · 1단계 산출물 500건 정규화 — 문서 종류·출처 경로·태그 부여
커스텀 MCP 서버 구축4HMCP 아키텍처와 사내 시스템 연동 설계 · MCP 서버 구현 실습(DB·API·문서 저장소) · 인증·권한 위임 패턴 · 사내 문서 저장소 연결 — 커넥터 경로와 MCP 경로 비교
거버넌스와 확산 지원4H공유 시 데이터·지시문 동반 노출 통제 · 조직 에이전트 카탈로그(등록·승인·배포·폐기) · 쿼터·비용 모니터링과 운영 인계 · 문서 갱신·폐기 절차

이 과정을 권하는 이유

  • 산출물이 흩어지지 않는다 — 1단계 문서 500건은 현재 설계상 수강생 PC에 저장. 정규화·연결을 거쳐야 조직 자산이 됨
  • 2·3단계의 천장을 올린다 — 저장소 연결이 없으면 에이전트 지식 소스가 파일 업로드 범위로 제한
  • 범위는 저장소 구축이 아니라 저장소 위에 파이프라인을 얹는 것 — 저장소 자체는 보유하신 것을 전제. 어디에 둘지는 정보보안·인프라 정책 결정 사항

Snowflake 데이터를 Gemini Enterprise에 연결하는 커넥터·MCP 서버 제작 교육은 대상(데이터 사이언스·개발 직군)과 난이도가 달라 별건으로 분리해 별도 제안
