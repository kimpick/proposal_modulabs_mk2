### 3-3. 3단계 — 팀 멀티에이전트 워크플로우 해커톤

| 항목 | 내용 |
|---|---|

| 대상 | 350명 |
| 형태 | 오프라인, 차수당 20명 → **18차수** (350÷20=17.5) |
| 팀 | 차수당 5팀(4인), 전체 90팀. **부서 단위 확정** |
| 경쟁 | 차수 내 5팀 경쟁. 전사 통합 결선 없음 |
| 총 강의시간 | **216H** (18차수 × 12H) |
| 총 교육일 | **54 교육일** (18차수 × 3일) |
| 제거된 블록 | 지식관리 체계 구축 3H → 1단계로 이동 (3-1 참조) |

## 4. 도구 환경

> ### ⚠️ 확정 제약 — Google Workspace 미사용
> **고객사는 Google Workspace를 사용하지 않는다. 교육은 Gemini Enterprise에 포함된 도구만으로 구성해야 한다.** [사용자 확정 2026-08-24]
>
> 이에 따라 다음이 **전면 배제**된다:
> - **Google Workspace Studio** (구 Workspace Flows) — 유료 Workspace 구독 필수. 노코드 다단계 자동화 경로가 사라짐
> - Workspace Studio의 **"Ask a Gem" 스텝** — 유일하게 확인된 Gem 체이닝 경로였으나 사용 불가
> - **Gmail · Drive · Docs · Calendar 연동** 실습 및 커넥터
>
> **파급**: Gem의 지식 소스는 "업로드 파일 또는 Drive 파일"인데 Drive가 없으므로 **업로드 파일만** 남는다. 고객이 요구한 "Gems 중심 1인 1에이전트"가 GE 단독 환경에서 성립하는지 자체가 쟁점이 되며, 3단계 팀 워크플로우는 **GE Agent Designer**로 구현해야 한다. **검증 진행 중 (2026-08-24)**

  - ⚠️ **정확한 서술**: "GE에 Gems가 없다"까지는 사실이나, **"GE 라이선스로 Gems를 못 쓴다"는 확인되지 않았다.** GE 라이선스가 Gemini 앱 접근권을 포함하는지 FAQ는 답하지 않는다 → **고객·Google 확인 항목**
  - **도구 선택의 실질적 근거는 명칭이 아니라 3단계 연결이다.** Gems는 지시문+파일 구성의 개인 도구이고, 3단계 팀 워크플로우는 커넥터·다단계·조직 배포를 요구한다. 2단계를 Gems로 하면 3단계에서 자산을 다시 만들어야 하므로 **2단계부터 Agent Designer로 통일**한다
  - 우회 리스크: 직원이 개인 자격으로 Gemini 앱을 쓰려면 **개인 Google 계정** 접속 → 사내 데이터를 관리되지 않는 계정에 투입. **1단계 보안 세션에서 명시적 금지 안내**
- **Workspace Studio** — GE 1차 출처 4종에 등장하지 않음 **[1차]**. 유료 Workspace 전용
- **Agent Platform / Agent Studio / ADK / A2A 에이전트 반입** — FAQ 원문 `Is Gemini Enterprise Agent Platform included with Gemini Enterprise app? No. ... must be purchased separately` **[1차]** → **라이선스 자체가 없다.** IT 심화 트랙에서 "별도 라이선스 시 확장" 으로만 언급

- Standard와 Plus의 차이는 **어떤 1차 출처에서도 확인되지 않았다** — 제품 페이지·FAQ가 두 에디션을 한 카드로 묶어 서술

**운영 제약**
- **에이전트 생성 쿼터** — 개인 350 + 팀 90 + 반복분 = **450건 이상** 생성 발생. 쿼터 소진(`RESOURCE_EXHAUSTED`) 사례가 2026-06 개발자 포럼에 보고되었고 **콘솔 셀프 증액 불가** **[요약]** → 교육 4주 전 계정팀 **서면** 요청 필수
- **2단 게이트** — GE 기능은 GA여도 ① 프로젝트 허용목록 ② 관리자 토글을 통과해야 화면에 노출 **[요약]**. Agent Designer 미활성 시 2·3단계 전체가 성립 불가
- **공유 시 데이터 동반 노출** — `When you share an agent, you are also sharing access to all its associated data sources and files` **[요약]**. 지시문도 읽기 전용 열람 가능 → **실습은 더미·비민감 자료만**. 커리큘럼·안내문·구두 안내 3곳에 명시
- **예약 실행** — 자격증명 14일 만료(수동 갱신)·멀티리전 한정·타인 관여 액션 승인 대기 **[요약]** → **시연만.** 산출물 요건에 넣지 않음
- **한국 리전 없음** — 확인된 in-country 리전은 도쿄·런던·캐나다·인도·싱가포르 **[요약]**. ⚠️ **"국내 보관 가능"을 절대 서술하지 않는다.** 국내 유통 대기업 개인정보 심의에서 국내 보관을 요구하면 도입 승인이 교육 일정을 밀 수 있음 → 일정 완충 2주
- 파일 업로드 개수·용량 상한 — GE Agent Designer 고유 수치 미확인(검색 결과가 별개 제품 CX Agent Studio 값과 혼재) → **어떤 수치도 인용 금지.** "2~3개 규모로 시작" 운영 권고로만 표기

**3단계 구현 경로 — A안/B안 게이트**
- Agent Designer는 `single and multi-step agents`를 만들고 Flow 탭에서 `Add subagent`로 서브에이전트를 추가한다 **[요약]**. 서브에이전트는 각각 Name·모델·Description·Instructions·Data sources를 가짐
- **다만 "4인이 각자 소유한 에이전트를 하나의 워크플로우로 엮는" 노코드 기능은 공식 문서에서 발견되지 않았다.** 서브에이전트 구성은 **단일 소유자 자산 안에서** 이뤄지고, 공유받은 타인 에이전트에 대한 권한은 대화 + 읽기 전용 열람뿐 **[요약]**. → '불가'가 아니라 **'문서 없음'**
- **판정 게이트**: 교육 3주 전 강사가 고객 테넌트에 로그인해 ① Flow 탭 `Add subagent` 존재 ② `Add tools`에 조직 에이전트 항목 존재를 **스크린샷으로 확정**
  - **A안 (확인 시)**: 팀 1개 = 메인 1개 + 서브에이전트 4개의 단일 다단계 자산. 소유자 1명이 빌드, 팀원 4명이 각자 서브에이전트 1개를 설계·검증. 2단계 개인 에이전트가 그 프로토타입이 됨
  - **B안 (미확인 시)**: **핸드오프 체인** — 개인 에이전트 4개 + 인수인계 규격서 + 팀 운영 플레이북. 단계 출력 포맷을 다음 단계 입력 포맷에 일치시키는 것이 학습 목표. 노코드로 100% 성립, 산출물 건수도 팀당 1건 유지
  - **제안서는 두 안 모두를 만족하는 표현("업무 흐름을 4단계로 절단해 조립")으로 작성했다**

### 1단계 커리큘럼 재설계 (12H) — Gems 입문 + Agent Designer + 지식관리
