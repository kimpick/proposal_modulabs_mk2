# 롯데이커머스 AI 교육 요구조건

> **작성일**: 2026-07-20 | **담당자**: 최서율 | **경쟁 PT**: 패스트캠퍼스

## 1. 기업 배경

- **대상**: 롯데이커머스 (롯데그룹 e-commerce 계열사)
- **배경**: 롯데 계열사 전체 AI 업무 전환 (그룹 차원 에이전트 개발·공유 미션)
- **핵심 과제**: 각자 자신의 Agent 구축, 지속적 업데이트, 타 계열사 전파 가능 수준 도달
- **과거 이력**: 개발팀 교육 의뢰 (담당 최치영 차장) 무산 → 상무 추천으로 재접촉
- **경쟁 상황**: 상무 2명이 각각 모두의연구소 / 패스트캠퍼스 추천 → PT 경쟁

## 2. 교육 대상 및 현황

| 직군 | 인원 구성 | AI 숙련도 | 핵심 특성 |
|------|----------|----------|----------|
| **영업·MD·마케팅** | 핵심 타겟 (20~30%) | 낮음 | AI 저항감 높음, 프롬프트 작성 어려움 (대다수) |
| **HR·재무·경영지원** | 일부 | 낮음~중간 | '기타' 분류, 페인포인트 개별 파악 필요 |
| **IT (개발/인프라/정보보안)** | 일부 | 높음 | Claude/Codex 자체 사용 중, Gemini 단일화 우려 |

- **총 인원**: 약 500명
- **차수당 인원**: 최대 20명 (오프라인 1개 장소)
- **심화 과정**: 10명 단위 가능

## 3. 교육 목표

### 단계별 목표
- **최소 목표**: 영업/마케팅 직군이 "푸시앱 문자 문구 생성기" 수준 에이전트를 직접 구축
- **중간 목표**: "2시간 걸릴 일을 5분 만에" 작은 성공 경험 축적 (동기부여)
- **궁극 목표**: "AI 없으면 일 못한다" 수준의 업무 통합, 타 계열사 전파 가능 선례 창출

### 핵심 성과 지표
- 직군별 AI 활용 페인포인트 해결 (MVP 과제 도출)
- 부서별 MVP 리스트로 성과 측정
- As-is / To-be 업무 시간 변화 정량 측정

## 4. 교육 운영 형태

- **형태**: 오프라인 (전 직원 참여·집중도 향상)
- **방식**: 차수제 운영 (분반 아님, 주차별 직군 타겟팅)
- **시간**: **1일 4시간 × 3일 = 12시간** (차수 설계에 따라 변동 가능)
- **시작**: 8월 말 예정
- **추진 전략 후보** (협의 중):
  1. 전사 동시 확대
  2. 파일럿 (영업/MD) → 성과 검증 → 전사 확대

## 5. 사용 도구 환경

- **주력**: **Gemini Enterprise** (8월 초 전사 도입 확정, DLP 해결로 사내 데이터 활용 가능)
- **IT 직군**: Claude, Codex 병용 (자비로 이미 사용 중) → Gemini 단일화에 우려 표명
- **비-IT 직군**: Claude 거의 사용 안 함 (수요조사 결과 반영)
- **클로드 전사 도입 여부**: 목요일(7/23) 대면 미팅에서 확인 예정 (미확정)

## 6. 직무별 페인포인트 (영업·마케팅)

### 핵심 페인포인트
- 단순 반복 운영 업무에 시간 과다 소요
- 생산성 기획 업무에 집중할 시간 부족
- 그룹 차원 AI 활용 독려에도 변화 더딤 → 의무 교육으로 확대 압박

### 영업 MD 주요 업무
- 상품 상세 페이지 관리
- 매출/재고 관리
- 기획안 작성
- 리뷰 요약 및 랭킹 관리

### 과거 AI 인턴 활용 과제 (레퍼런스)
- 생성형 AI 활용 배너 이미지 제작 (e-commerce 특성상 가장 인기)
- 트렌드 검색 에이전트
- 커뮤니티별 특성 맞춤 바이럴 문구 생성

## 7. 제안 방향 (사용자 확정)

### 3개 트랙 선택형 카탈로그 구조

| 트랙 | 대상 | 시간 | 비고 |
|------|------|------|------|
| **트랙 1: AI Agent 기반 AX 워크숍** | 직무 무관, 팀 단위/유관부서 그룹 권장 | 12H (4H×3일) | 전사 공통 기반 |
| **트랙 2: 직무별 AI 활용 교육** | MD, 영업, 마케팅, HR, 재무, 경영지원 (6+ 직군) | 12H (4H×3일) | 직군별 별개 과정, MD 사례 가장 뾰족하게 |
| **트랙 3: IT/개발자 심화 교육** | 개발, 인프라, 정보보안 | 12H (4H×3일) | 하네스/루프 엔지니어링 + MCP 서버 + GW MCP 연동 |

- **선택형**: 부서/개인이 상황에 맞게 선택
- **1인 1트랙 이수**: 각 트랙이 별개 대상 (중복 이수 X)
- **PDF 차등 상세**:
  - 트랙 1: 상세
  - 트랙 2: 직군별 요약표 + MD 직군 1개 샘플 상세
  - 트랙 3: 개요만

### 트랙 3 (IT 심화) 핵심 내용
- 하네스 엔지니어링 (에이전트 기반 개발 기초)

- MCP 서버 구축 → 사내 데이터 연동
- Google Workspace MCP 연동 → 에이전트 파이프라인 구축
