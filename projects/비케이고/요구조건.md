## 1. 고객 정보

- **기업명**: 비케이고(BKGO)
- **사업**: 스포츠·e스포츠 라이브스코어 앱 '이스코어' 운영사
- **현황**: 클로드 맥스(Claude Max) 전사 도입 완료. 다만 활용이 "각자 잘 묻는" 챗 수준에 머물러 있음
- **교육 목적**: 반복 업무를 AI 위에 시스템으로 올리는 것 — 직군별 자동화 워크플로 구축과 업무 자산화

## 3. 트랙 구성

### Track 1 — Claude 업무 시스템 구축 (비개발자, 10H / 3일)

- Day 1 (3H): 클로드 맥스 핵심 기능(Projects·Artifacts·커넥터) 이해 + 내 업무의 AI 위임 구조 설계
- Day 2 (3H): 데이터·문서 자동화 공통 패턴(Claude in Excel 포함) + 직무 데이터 적용 실습(직무별 실습 키트)
- Day 3 (4H): 스킬 구조 이해와 첫 스킬 제작 + 1인 1스킬 완성·업무 자산화

### Track 2 — Claude Code 실무 활용 (개발자, 10H / 3일)

- Day 1 (3H): CLAUDE.md 컨텍스트 설계 + 반복 작업의 슬래시 커맨드 표준화
- Day 2 (3H): AI 페어 개발 패턴(파악→수정→검증) + 사내 코드베이스 실전 적용
- Day 3 (4H): Hooks·워크플로 자동화(서브에이전트·MCP 시연) + 팀 표준(CLAUDE.md·훅·스킬) 확정·자산화

## 4. 직무별 실습 키트 (Track 1 Day 2)

키트 = ① 샘플 데이터 + ② 프롬프트 템플릿 + ③ 완성 예시 (강사 제공)

- **재무·정산**: 가상 월간 정산 엑셀(매출·수수료·이상치) + 리포트 템플릿 → 이상치 탐지·월간 리포트 초안
- **CS·운영**: 이스코어 스토어 리뷰 각색 세트 + 응대 톤 가이드 템플릿 → 유형별 응대 초안
- **기획·영업**: 경쟁 라이브스코어 앱 3종 공개 정보 패키지 + 분석 프레임 템플릿 → 경쟁 분석·제안 문서 초안

## 5. 필요 인프라

- Claude Max 플랜 계정 (수강생 전원 — 고객사 기보유)
- 개발 트랙: Claude Code 실행 환경(터미널·Git, 기설치 전제), 사내 코드베이스 접근 권한 또는 강사 제공 실습용 레포
- 비개발 트랙: 직무별 실습 키트 3종(강사 제공), 커넥터 연동용 업무 계정(Gmail·Drive·Slack·Notion 중 사용 중인 것)
- 공통: 1인 1노트북, 인터넷 가능 교육장

## 6. 산출물 목표

- 1인 1스킬 — 담당 업무 기반 자동화 스킬 (예: 월간 정산 리포트 스킬, 리뷰 응대 스킬)
- 업무별 전용 Project — 지침·지식베이스가 세팅된 반복 업무 위임 시스템
- 팀 공용 개발 표준 자산 — 합의된 CLAUDE.md·훅·스킬 세트
