# 사내AX 자율 에이전트 보안 3주 심화 — 표준 제안서

## 배경
- 팀이 만든 자율 에이전트를 사내에 공유·재사용하려는 니즈 확산
- 동시에 (a) 개인 Claude Max/Codex Pro 계정 공유 = TOS 위험, (b) 과도한 권한 = 동료 실수·프롬프트 인젝션·데이터 노출 위험 발생
- 1일~1주 집중 교육은 단기 기억에만 머물어 1개월 후 retention 20% 이하. **분산+반복+현업 적용**이 내재화의 길

## 목표 (Goal)
- 3주(분기 분산) + 6주 현업 적용 사이클로 팀 AX 역량 내재화
- G1: 팀 에이전트 5~10개 운용 (Langfuse 가시화)
- G2: 4대 통제(visibility/authz/sandbox/audit) 적용
- G3: agent author별/사용자별 사용량 dashboard로 기여도 측정
- G4: 팀 내 Red Team/Blue Team 역할 분담 + on-call runbook 완성
- G5: 다음 분기 타 팀 확장용 패키지 산출

## 대상
- 단일 팀 ~ 다수 팀 파일럿 (5~12인)
- 팀 AX 챔피언 후보
- 사전 요건: Claude Code/Codex CLI 기본 사용 경험

## 핵심 설계 — 학습-적용-회고 사이클
- Month 1: [Week A 강의 5일] → [현업 적용 3주]
- Month 2: [Week B 강의 5일] → [현업 적용 3주]
- Month 3: [Week C 강의 5일] → [분기 review + Q2 준비]
- 총 105시간 교육 + 6주 현업 적용

## 트랙 구조
- Track A (Month 1): 기초 + 도구 통제 + 첫 에이전트 (5일 × 7h)
- Track B (Month 2): 관측 + 다중 에이전트 + 사내 확장 (5일 × 7h)
- Track C (Month 3): 심화 + Red Team + 운영化 (5일 × 7h)

## 예상 예산
- 월 ~$130 (Claude Team Standard 5석 + Langfuse Cloud)
- 또는 월 ~$210 (Builder 구성: Premium 1 + Standard 4)

## 의사결정 요청
- D1. 분기 분산 3주 일정 확정 (Month 1/2/3 각 1주, 5일 × 7h)
- D2. Team plan 가입 승인 + 3개월 예산
- D3. Langfuse host 서버 또는 Cloud 승인
- D4. 현업 적용 주를 공식 업무 일정에 배정
- D5. 분기 종료 후 다음 분기 타 팀 확장 검토
