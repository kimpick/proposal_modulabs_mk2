## 교육 방향
- 비개발자 실무자가 코딩 경험 없이도 AI 기반 업무 자동화 도구를 직접 만들어보는 2시간 실전 워크샵을 제안한다.
- 워크시트 기반 업무 자기진단, Claude Code 및 Codex 기반 자동화 도구 초안 제작, AI Agent와 MCP 기반 외부 도구 연계 구조 이해를 포함한다.
- 수강생이 교육 당일 자신의 반복 업무를 소재로 자동화 흐름을 설계하고, 향후 내부 개발팀과 협력해 개인 슬랙봇 등 자동화 봇을 구현할 수 있는 기획 역량과 자동화 스펙 작성 능력을 확보하는 것을 목표로 한다.

## 대상 및 AX 단계
- 권장 대상: 코딩 경험 없이 AI 기반 업무 자동화 도구를 직접 만들어보고 싶은 비개발자 실무자
- 주요 직군: 기획, 마케팅, 운영, 경영지원
