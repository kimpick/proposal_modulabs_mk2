## 1. FT 양성 개요

### 1.1 목표

| 항목 | 내용 |
|------|------|
| **양성 대상** | 사내 FT 50명 + 예비 FT 10명 (이탈 대비 20% buffer) |
| **양성 목표** | 워크숍 독립 운영 가능 수준 (자립형 FT) |
| **인증 기준** | 3일 교육 이수 + 모의 운영 평가 통과 |
| **양성 기간** | 사전 온라인 학습(4시간, LMS 연동) + 3일 집중 교육 (21시간) × 2기수 |

### 1.2 FT 선발 제안

```
[권장 선발 구조]

기존 사내강사 풀: 40명 (운영 경험 있음)
신규 보완:       10명 (AI 관심 직원, IT 부서 추천 등)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
총계:            50명

배치 전략:
- 거제 사업장: 30명 (75개반 담당)
- 서울 사업장: 20명 (35개반 담당)
- A급 FT: 전 차수 가능 인력 (다차수 투입)
- 일반 FT: 주 2~3회 운영
```

### 1.3 FT 역량 정의

성공적인 FT가 갖춰야 할 5대 역량:

1. **게이미피케이션 운영력** — 미션 진행, 시간 관리, 에너지 리딩
2. **Copilot 활용력** — M365 Copilot 기본 조작, 실습 지원
3. **퍼실리테이팅력** — 질문 유도, 디브리핑, 참여 촉진
4. **돌발 대응력** — 기술 이슈, 참가자 저항, 시간 지연 대처
5. **데이터 취합력** — Problem Pool 폼 운영, 결과 정리

### 3.2 퍼실리테이팅 팁북 (요약)

```
🎯 FT 퍼실리테이팅 10계명

1. 에너지가 전부다 — FT의 열정이 참가자의 몰입도를 결정한다
2. "정답"이 없다 — 참가자의 답을 존중하라
3. 시간을 보여줘라 — 타이머가 긴장감과 몰입을 만든다
4. 침묵을 두려워 말라 — 3초만 기다리면 누군가 말한다
5. 디브리핑이 핵심이다 — 체험보다 "해석"이 더 중요하다
6. "일단 한 번 해보세요" — 저항하는 참가자를 위한 마법의 문장
7. 동료 효과를 활용하라 — 옆 사람과 비교하게 만들어라
8. 기술 이슈도 콘텐츠다 — "이것도 AI의 현실"로 전환하라
9. 웃으면서 진행하라 — 긴장을 풀어야 학습이 된다
10. L-ZERO 선서식은 감동으로 — 분위기 연출이 중요하다
```

## 4. FT 운영 지원 체계

### 4.1 운영 중 HOTLINE 구조

```
[참가자] → [FT (사내)] → [FT 리드 (사내 5명)] → [수행사 지원]
                                                  (월 1회 미팅)
```

- 초기 2주: 수행사가 현장 파견 동행 (옵션)
- 이후: FT 자립 운영 + 월 1회 정기 체크인 미팅
- 긴급 이슈: Teams 채널을 통한 실시간 Q&A 지원

### 4.2 FT 품질 관리

| 시점 | 항목 | 방법 |
|------|------|------|
| 교육 직후 | 역량 평가 | Micro-teaching 평가 (5점 척도) |
| 1차 운영 후 | 참가자 만족도 | 워크숍 만족도 설문 (5점) |
| 월 1회 | FT 자체 평가 | 자가 진단 체크리스트 |
| 분기 1회 | 품질 리뷰 | 수행사 참관 + 피드백 세션 |

## 5. FT 인증 체계

### 5.1 인증 레벨

| 레벨 | 명칭 | 기준 | 권한 |
|------|------|------|------|
| **Lv.1** | Assistant FT | 교육 이수 | 보조 운영 |
| **Lv.2** | Certified FT | Micro-teaching 평가 통과 (3.5점+) | 단독 운영 |
| **Lv.3** | Master FT | 10회 이상 운영 + 만족도 4.0점+ | 다른 FT 멘토링 |

### 5.2 인증 혜택 (제안)
- Certified FT 인증서 (사내 포트폴리오 활용)
- Master FT: 사내 강사 수당 또는 인센티브 (한화오션 내부 규정에 따름)
- FT 커뮤니티 우선 참여 권한
