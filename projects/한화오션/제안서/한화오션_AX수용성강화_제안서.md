# [모두의연구소] 한화오션 AX 수용성 강화 워크숍 제안서

> **제출일**: 2026년 6월 25일 | **제출처**: 한화오션 기업문화혁신팀 박찬욱 책임

## 1. 제안 개요

### 1.1 제안 배경 및 이해

한화오션은 글로벌 조선해양 산업의 리더로서 디지털 전환(DX)을 넘어 AX(AI Transformation) 시대로의 도약을 선도하고 있습니다. 2026년 현재 AI 기반 생산관리 시스템 도입, 거제 조선소 디지털 전환 가속화 등 전사적 AX 추진이 진행 중이며, 그 성공의 열쇠는 **전직원의 AI 수용성(Acceptance)**에 있습니다.

전직원 4,500명의 AI 수용성을 높이기 위해, 본 제안서는 **"교육"이 아닌 "경험"을 통해 AI에 대한 공감과 체화를 이끌어내는 워크숍**을 제안합니다.

> **L-ZERO (Legacy Zero)**: 기존 반복적·수작업 업무를 AI로 전환하겠다는 개인 서약 프로그램. 본 워크숍의 핵심 산출물.

### 1.2 변화관리 프레임워크: ADKAR 모델 적용

본 워크숍은 한화오션 AX 변화관리의 **Awareness(인지) + Desire(욕구)** 단계를 담당합니다. 단순한 "AI 교육"이 아닌, 조직 변화 전략의 첫 걸음입니다.

```
ADKAR 변화관리 모델
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[A] Awareness    ← 본 워크숍 담당
    "AI가 내 업무를 어떻게 바꾸는가?" 체감

[D] Desire       ← 본 워크숍 담당  
    "AI를 써보고 싶다"는 자발적 동기 (L-ZERO 서약)

[K] Knowledge    ← 후속 교육 (사내 자체)
    Copilot 활용법 심화 학습

[A] Ability      ← 후속 적용
    실무에 AI 적용 → Problem Pool 해결

[R] Reinforcement ← 사내 FT + LMS로 지속
    성과 측정, 우수 사례 전파, 레벨 유지
```

### 1.3 과업 요약

## 2. 과업 이해도 및 추진 방향 (평가 20점)

### 2.1 과업 구조 이해: 3단계 전파 모델

```
┌─────────────────────────────────────────────────────────────┐
│                    [1단계] 수행사 역할                       │
│            워크숍 콘텐츠 설계 + FT 50명 양성                │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                    [2단계] 사내 FT 역할                      │
│            50명의 FT가 자립적으로 워크숍 운영                │
│     거제 사업장: FT 30명 / 약 75반                          │
│     서울 사업장: FT 20명 / 약 35반                          │
│     (반당 40~45명, 총 약 110반 / 4,500명 커버)             │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                   [3단계] 전직원 확산                        │
│            4,500명 / 약 110반 워크숍 수혜                  │
│            → 개인별 Legacy 업무 발굴 → L-ZERO 서약          │
│            → 전사 Problem Pool 데이터 자산화                │
└─────────────────────────────────────────────────────────────┘
```

**FT 가동 산출 근거**:
- FT 1인당 평균 2~3반 운영 (주 2회 가동 기준)
- 50명 FT × 주 2회 × 6주 = 600반/월 가용 → 110반은 충분히 커버
- FT 예비율 20% 확보 (10명 buffer로 본무업/휴가 대체 인력 확보)

### 2.2 핵심 설계 원칙

1. **"교육"이 아닌 "경험"** — 강의식이 아닌 게이미피케이션을 통한 자발적 체험. 2026년 "생성형 AI + 게이미피케이션 융합"이 글로벌 기업 교육 핵심 트렌드.
2. **3단계 점진적 AI 체화** — 아날로그 체감 → MS 도구 전환 → Copilot 마스터로 자연스러운 단계 상승
3. **FT 자립성 확보** — 수행사 의존도를 최소화, 3일 집중 양성 + 인증 체계 + 가이드북으로 사내 자체 운영 가능 구조
4. **데이터 기반 AX 추진** — 워크숍 결과(Problem Pool)를 전사 AX 추진의 데이터 자산으로 활용

### 2.3 대상별 이원화 전략

전직원은 **리더 트랙**과 **구성원 트랙** 두 가지로만 구분하여 운영합니다. 직군·수준에 관계없이 동일한 커리큘럼을 적용하며, 트랙별로 시간과 초점만 달리합니다.

| 구분 | 리더 트랙 | 구성원 트랙 |
|------|-----------|------------|
| **과정명** | AX 전환 리더십 (Leader's AX Sponsorship) | AX 업무 실전 (AI Work-Skill & L-Zero) |
| **시간** | 2.5시간 (150분) | 3.5시간 (210분) |
| **참여자** | 전사 직책자 및 리더급 | 전사 실무 구성원 |
| **핵심 초점** | 리더 스폰서십 확립 + 팀 레거시 발굴 | 개인 업무 PoC + 개인 L-Zero 등록 |
| **레거시 발굴 단위** | 팀 단위 M/M 분석 → 팀 병목 추출 | 개인 주간 업무 → 개인 페인포인트 |

## 4. 워크숍 콘텐츠 설계안 (평가 40점 — 핵심)

> 상세 커리큘럼: `트랙별_상세_커리큘럼.md`

### 4.1 워크숍 설계 원칙

본 워크숍은 직군·수준 구분 없이 **동일한 4단계 흐름**으로 운영합니다. 리더 트랙과 구성원 트랙은 시간 배분과 레거시 발굴 단위(팀/개인)만 다르며, 구조와 핵심 도구(M365 Copilot)는 동일합니다.

```
공통 4단계 흐름
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [1단계]           [2단계]        [3단계]                [4단계]
  Gamification     디브리핑       레거시 업무             AX 활용
  체험                            발굴 & M365 매핑        다짐

  프롬프트 릴레이  →  결과 분석  →  개인/팀 업무 진단  →  L-Zero 서약
  워크플로우 배틀     AI 효율 체감   M365 Copilot 매핑     Problem Pool

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**설계 핵심 원칙**
1. **"교육"이 아닌 "경험"** — 프롬프트 릴레이·워크플로우 배틀 등 게이미피케이션으로 자발적 체험 유도
2. **M365 Copilot 중심** — 조직에서 이미 사용 중인 Excel, Word, PPT, Teams, Outlook, BizChat으로 즉시 적용 가능
3. **실무 PoC 보장** — 샘플 파일이 아닌 본인 실제 업무 파일로 Copilot 효과 직접 확인
4. **데이터 자산화** — 워크숍 결과(Problem Pool)를 전사 AX 추진의 데이터 자산으로 연결

### 4.2 리더 트랙 상세 (2.5시간 / 150분)

**과정명**: 한화오션 AX 전환 리더십 (Leader's AX Sponsorship)

| 00:40~01:00 | 모듈 2: 디브리핑 | 리더 지시역량 = AI 지시역량 / 스폰서십 | 20분 |

#### 모듈별 핵심 내용

**[모듈 1] Gamification 체험: 프롬프트 릴레이** (40분)
- M365 Excel 공동 접속 → 역할·맥락·출력 조건을 조별 릴레이로 덧붙여 프롬프트 고도화
- 완성된 프롬프트를 M365 BizChat 또는 Word Copilot에 입력 → 조별 결과물 퀄리티 비교
- 체감 포인트: 명확한 지시(Prompt)가 AI 출력 품질을 결정한다

**[모듈 2] 디브리핑: 리더의 지시와 압도적 효율** (20분)
- 결과물 비교를 통해 **프롬프트 구조화 = 리더의 업무 지시 역량**임을 확인
- AX 변화관리에서 리더 스폰서십의 역할: 구성원에게 심리적 안전감 제공

**[모듈 3] 팀 레거시 발굴 및 M365 매핑** (60분)
- 팀 업무 진단 캔버스로 주요 과업별 M/M 수치화 → 병목 구간 특정
- 병목 업무별 M365 앱 솔루션 매핑 (Teams / Outlook / Excel / BizChat·Word Copilot)
- 발굴된 레거시를 샘플 파일로 직접 Copilot 실증(PoC)

**[모듈 4] AX 활용 다짐** (30분)
- 팀 L-Zero 과제 확정 → 사내 폼으로 Problem Pool 등록 (M365 앱, 프롬프트 시나리오, 절감 리소스 포함)
- 리더 스폰서십 선언으로 클로징
