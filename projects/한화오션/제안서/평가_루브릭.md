# 평가 루브릭: 한화오션 AX 수용성 강화 워크숍

> 4,500명 전직원의 AX 역량을 다차원으로 평가하기 위한 루브릭.
> 워크숍 설계(4모듈 구조)와 사후 이행(L-ZERO 서약) 모두를 측정.

---

## 1. 루브릭 구조 개요

### 1.1 두 축: 차원(Dimension) × 수준(Level)

- **5개 차원**: AI 역량의 서로 다른 측면을 평가
- **4개 수준**: 체험 → 이해 → 적용 → 내재화의 발달 단계
- **2개 적용 모드**: 참가자 평가(4,500명) + FT 역량 인증(50명)

### 1.2 4모듈 구조와의 루브릭 수준 매핑

| 워크숍 모듈 | 루브릭 수준 | 의미 |
|------------|------------|------|
| 모듈 1: 프롬프트 릴레이 + 워크플로우 배틀 | **Level 1: 체험** | 가이드 따라, M365 Copilot 첫 경험 |
| 모듈 2: 디브리핑 | **Level 2: 이해** | AI 효율 인지, "내 업무에도 쓸 수 있다" 확신 |
| 모듈 3: 레거시 발굴 & M365 매핑 + PoC | **Level 3: 적용** | 실무 적용, 산출물 생성, L-ZERO 서약 준비 |
| 모듈 4: L-ZERO 서약 + Problem Pool 등록 | **Level 3~4 전환** | 서약 기반 변화 실행 선언 |
| 사후 1~3개월 이행 | **Level 4: 내재화** | 일상화, 동료 코칭, Problem Pool 기여 |

> 루브릭 수준 4는 워크숍 자체보다 **사후 1~3개월**에 도달 가능. FT는 양성 과정에서 Level 3 이상 도달 목표.

## 2. 5개 역량 차원 상세 루브릭

### 차원 1: AI 인식 (AI Awareness)

> AI에 대한 거부감 해소, 가치 체감, 자발적 동기 형성 정도

| 수준 | 행동 지표 | 산출물 증거 |
|------|----------|------------|
| **L1 체험** | AI를 "어려운 것"으로 인식, 가이드 없이 불가 | 모듈 1 프롬프트 릴레이 참여 완료 |
| **L2 이해** | AI의 가능성/한계를 구분, "한 번 써보겠다"는 호기심 | 모듈 2 디브리핑 발언, M365 Copilot 첫 대화 완료 |
| **L3 적용** | 자신의 업무에서 AI 가치를 구체적으로 설명 | 모듈 3 레거시 발굴 완료, 시간 단축 수치 기재 |
| **L4 내재화** | 동료에게 AI 가치를 전파, "안 쓰는 게 손해"라는 신념 | Problem Pool 3건+ 기여, 팀 내 AI 전도 행동 |

### 차원 2: 도구 활용 (Tool Proficiency)

> M365 Copilot 앱(Excel, Word, PPT, Teams, Outlook, BizChat)의 조작 능력

| 수준 | 행동 지표 | 산출물 증거 |
|------|----------|------------|
| **L1 체험** | M365 Copilot 한 가지 앱을 가이드와 함께 사용 | 모듈 1 워크플로우 배틀 참여 완료 |
| **L2 이해** | 2개 이상 M365 앱의 용도를 구분, 상황별 선택 | Excel → Word → PPT 연계 워크플로우 실행 |
| **L3 적용** | 3개 이상 M365 앱을 자유롭게 전환, 실무에 적용 | 모듈 3 레거시 발굴 시트에 M365 앱별 활용 방안 명시 |
| **L4 내재화** | M365 앱 간 연계 파이프라인 자체 설계, 동료에게 전수 | Problem Pool에 다중 앱 워크플로우 제안 |

> **도구 선택 원칙**: M365 Copilot (Outlook, Teams, Excel, Word, PPT, BizChat)을 기본축으로 활용. 사내 라이선스 확보 범위 안에서 최대한 활용.

### 차원 3: 문제 발굴 (Problem Discovery)

> 자신의 실무에서 AI가 가치를 더할 수 있는 지점을 스스로 찾는 능력

| 수준 | 행동 지표 | 산출물 증거 |
|------|----------|------------|
| **L1 체험** | 제시된 예시로만 수행, 스스로 발굴 못함 | 모듈 3 강사 가이드 따라 1개 레거시 작성 |
| **L2 이해** | 가이드 질문으로 Legacy 1~2개 발굴 | 개인 업무 진단 캔버스 1~2행 작성 |
| **L3 적용** | 업무 Top 5를 독립적으로 분석, AI 가능성 평가 | 개인 업무 진단 캔버스 5행 완성 + L-ZERO 서약 1건 |
| **L4 내재화** | 팀/부서 관점에서 Legacy를 구조화, 우선순위 제안 | Problem Pool 3건+ 등록, 팀 AX 개선 로드맵 |

### 차원 4: AI 협업 (Human-AI Collaboration)

> 효과적인 프롬프팅, 결과 검증, AI와의 대화 품질

| 수준 | 행동 지표 | 산출물 증거 |
|------|----------|------------|
| **L1 체험** | 단문 질문, 첫 응답을 그대로 수용 | 모듈 1 프롬프트 릴레이 1회 참여 |
| **L2 이해** | 컨텍스트(역할, 제약, 형식)를 포함한 프롬프트 작성 | 모듈 2 디브리핑에서 프롬프트 개선 사례 공유 |
| **L3 적용** | 반복 개선(iteration), 출력 검증, 할루시네이션 감지 | 모듈 3 PoC 산출물에서 프롬프트 개선 흔적 |
| **L4 내재화** | 고급 프롬프트 기법(역할 지정, 형식 제어, 예시 제공) 자체 설계 | Problem Pool 해결안에 프롬프트 패턴 문서화 |

### 차원 5: 변화 실행 (Action & Commitment)

> L-ZERO 서약 이행, Problem Pool 데이터 기여, 동료 코칭

| 수준 | 행동 지표 | 산출물 증거 |
|------|----------|------------|
| **L1 체험** | 서약서 작성만, 이행 미약 | 모듈 4 L-ZERO 서약서 제출 |
| **L2 이해** | 서약 업무 1개를 부분적으로 AI 활용 | 워크숍 후 2주 LTE 점검 시 AI 사용 흔적 |
| **L3 적용** | 서약 업무를 정기적으로 AI 처리, 시간 절감 측정 | 워크숍 후 1개월 시간 절감 리포트 |
| **L4 내재화** | 팀원 1명+에게 접근법 코칭, Problem Pool 3건+ 추가 | 워크숍 후 3개월 동료 코칭 사례, 우수 사례 전파 |

## 3. 도구 활용 매트릭스

### 3.1 트랙 × 모듈 × M365 Copilot 앱

> 워크숍에서 **공식적으로 노출**하는 도구. 참가자가 이후 자율 선택.

| 모듈 | 구성원 트랙 | 리더 트랙 |
|------|-----------|---------|
| **모듈 1: Gamification 체험** | M365 Excel (공동 편집 릴레이) + BizChat / Word Copilot | M365 Excel (공동 편집 릴레이) + BizChat / Word Copilot |
| **모듈 1: 워크플로우 배틀** | Excel Copilot → Word Copilot → PPT Copilot (연계) | — (리더 트랙은 릴레이만 진행) |
| **모듈 2: 디브리핑** | (도구 사용 없음, 강의) | (도구 사용 없음, 강의) |
| **모듈 3: 레거시 발굴** | 개인 페인포인트에 맞는 앱 자율 선택 | 팀 병목 업무에 맞는 앱 자율 선택 |
| **모듈 3: PoC** | Outlook / Teams / Excel / Word / BizChat 중 택1~2 | Teams / Outlook / Excel / BizChat 중 택1~2 |
| **모듈 4: L-ZERO 서약** | Problem Pool 폼 (M365 Forms) | Problem Pool 폼 (M365 Forms) |

### 3.2 도구 선택 원칙

1. **과제 성격 우선**: 도구를 먼저 정하고 과제를 끼워맞추지 말 것
   - 회의록 요약 / 액션아이템 추출 → Teams Copilot
   - 긴 이메일 스레드 파악 / 답장 초안 → Outlook Copilot
   - 데이터 취합 / 추세 분석 → Excel Copilot
   - 보고서 / 제안서 초안 작성 → Word Copilot + BizChat
   - 발표 자료 변환 → PowerPoint Copilot

2. **M365 Copilot 단일 기본축**:
   - 전직원(리더/구성원) 공통: M365 Copilot (한화오션 4,500석 확보 전제)
   - 앱 선택은 개인/팀의 실제 레거시 업무 유형에 따라 결정

3. **라이선스 현실성**:
   - **M365 Copilot**: 전직원 4,500석 (한화오션 확보 전제)
   - 사내 보안 정책상 외부 AI 서비스 사용이 제한될 수 있으므로 M365 생태계 내에서 운영

### 3.3 M365 Copilot 앱별 핵심 학습 포인트

| 앱 | 워크숍에서 강조할 점 | 대표 활용 시나리오 |
|------|------------------|--------------|
| **BizChat (M365 Chat)** | 사내 문서·이메일 검색 연동, 대화형 초안 생성 | 보고서 초안, 사내 정보 검색 |
| **Outlook Copilot** | 긴 스레드 즉시 요약, 답장 초안 생성 | 글로벌 협력사 메일 처리 |
| **Teams Copilot** | 회의 자동 요약, 액션아이템 추출 | 회의록 정리, 후속 업무 배분 |
| **Excel Copilot** | 데이터 추세 분석, 수식 자동 생성 | 정산/취합 반복 작업 제거 |
| **Word Copilot** | 초안 생성, 문서 리라이팅 | 보고서/기획서 초안 작성 |
| **PowerPoint Copilot** | Word 문서 → 슬라이드 자동 변환 | 발표 자료 빠른 제작 |

## 4. FT 역량 인증 루브릭 (별도 기준)

> FT 50명은 워크숍 참가자 기준보다 한 단계 높은 역량 필요.

| 역량 | 참가자 통과 기준 | FT 인증 기준 |
|------|---------------|------------|
| 도구 활용 | L2 (이해) | **L3 (적용)** + 2개 직군 도구 시연 |
| AI 협업 | L1 (체험) | **L3 (적용)** + 프롬프트 패턴 3개+ 설명 |
| 문제 발굴 | L2 (이해) | **L3 (적용)** + Problem Pool 5건+ 큐레이션 |
| 변화 실행 | L1 (서약) | **L2 (이해)** + 워크숍 운영 1회+ |
| 퍼실리테이팅 | (해당 없음) | **L3** + Micro-teaching 3.5점/5점 이상 |

> FT 인증 = 5개 역량 모두 기준 달성 + Micro-teaching 통과.

## 5. 평가 방법 및 도구

### 5.1 사전/사후 설문 (AX 수용성 지수)

- **사전 (워크숍 1주일 전)**: 10문항, AI 태도/사용 빈도/거부감 측정
- **사후 (워크숍 직후)**: 동일 10문항 + 만족도 + L-ZERO 서약 여부
- **사후 1/3개월**: 이행도, Problem Pool 기여도, 동료 코칭 여부

### 5.2 산출물 기반 평가 (자동화 가능)

| 산출물 | 평가 차원 | 측정 방법 |
|-------|---------|---------|
| 모듈 1 프롬프트 릴레이 참여 | 인식 L1 | FT 현장 확인 |
| M365 Copilot 대화 로그 | 협업 L1~2 | (옵션) 익명 샘플링 |
| 워크플로우 배틀 산출물 (Excel/Word/PPT) | 도구/협업 L2~3 | 체크리스트 기반 자가 평가 |
| 개인 업무 진단 캔버스 (Legacy 발굴 시트) | 발굴 L2~3 | FT 리뷰 + 정성 평가 |
| L-ZERO 서약서 | 실행 L1 | 100% 제출 여부 |
| Problem Pool 데이터 | 발굴/실행 L3~4 | 데이터베이스 쿼리 (수량/품질) |

### 5.3 정성 평가 (FT 관찰)

워크숍 중 FT가 관찰하는 참가자 행동 지표:
- 적극성 (질문 빈도, 미션 시도 횟수)
- 협력 (팀원과 공유, 도와주기)
- 회복 탄력성 (실패 시 대응, 도구 오류 대응)
- 확장성 ("이걸 내 업무에 어떻게 쓸까" 질문)

## 6. 루브릭 활용 로드맵

### 6.1 워크숍 설계 단계 (7월 W1~W2)

- 각 모듈(1~4)의 활동이 해당 루브릭 수준에 도달하는지 매핑 검증
- 부족한 차원(예: AI 협업 프롬프트 심화) 보강 활동 추가

### 6.2 워크숍 운영 단계 (7월 W4 ~ 9월 W3)

- 사전/사후 설문으로 각 차원별 점수 변화 추적
- FT가 현장에서 정성 평가 (샘플링)
- L-ZERO 서약 → 1개월/3개월 이행도 추적

### 6.3 사후 데이터 분석 (9월 W4)

- 부서별/직군별 루브릭 점수 heatmap
- Problem Pool 품질 평가 (루브릭 기반)
- 우수 사례 발굴 → 사내 전파 콘텐츠화
