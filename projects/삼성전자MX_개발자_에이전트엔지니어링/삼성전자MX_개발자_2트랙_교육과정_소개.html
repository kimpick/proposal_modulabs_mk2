01 / 커리큘럼 개요

한눈에 보는 2트랙

에이전트 활용의 두 축, AI 팩토리와 지식그래프

02 / 트랙 1

트랙 1 · 개발 워크플로우

AI 팩토리 구축 — 루프·하네스·그래프 종합

루프(원자)·하네스(벽)·그래프(제어 흐름)를 오전에 각각 구축하고, 오후에 합쳐 이슈 티켓 1건 완주.

대상
MX 개발자 (선행 과정 불필요)
교육 시간
8H · 1일
실습 환경
구독 계정만 · API 키 불필요
필수 도구
Claude Code CLI · LangGraph · Langfuse
STEP 1 · 오전
루프와 하네스 레이어 구축
4H
M1 · 1HAI 팩토리 개관 — 루프(원자)→하네스(벽)→팩토리(조직) 3단 스택과 닫힌 루프, [워크숍] 내 워크플로우 팩토리 지도
M2 · 1.5H루프 레이어(원자) — AORR 상태 머신, Self-Correcting TDD, 종료 가드레일, [실습] claude -p 자율 수정 루프
M3 · 1.5H하네스 레이어(벽) — Agent = Model + Harness, 가이드·센서 이중 통제, [실습] 룰·린터 폐쇄형 제약 사이클
STEP 2 · 오후
그래프 제어 흐름과 팩토리 조립
4H
M4 · 2.5H그래프 레이어(제어 흐름) — State·Node·Edge·종료 4요소, LangGraph 제어 평면, [실습] Supervisor 그래프와 승인 게이트
M5 · 1.5HAI 팩토리 조립 — Langfuse 트레이스 연결, [통합 실습] 루프+제약+그래프를 합쳐 이슈 티켓 완주
의도적 실패와 라이트 스위치 — 트레이스 진단, 종료 엣지 수습, 무인화 판정표, 사람이 맡는 바깥 루프
산출물
HITL 가드레일 자율 수정 루프가이드·센서 하네스 템플릿LangGraph Supervisor 그래프Langfuse 트레이스 · 라이트 스위치 판정표팀별 AI 팩토리 청사진
03 / 트랙 2

트랙 2 · 개인 지식 기반

세컨 브레인 구축 — LLM Wiki·지식그래프·비서 자동화

기존 AI 세션과 개인 문서를 지식 포맷으로 재편하고 그래프로 조직한 뒤, 그 위에서 움직이는 비서 에이전트까지 하루에 완성.

대상
MX 개발자 (선행 트랙 불필요)
교육 시간
8H · 1일
실습 데이터
각자의 AI 세션 · 개인 프로젝트 자료
필수 도구
Claude Code CLI · Google OKF · SMTP 발송
STEP 1 · 오전
지식 재편과 지식그래프 구축
4H
M1 · 1H세컨 브레인 개관 — 재편→그래프→에이전트→연동 4단 구성, LLM Wiki 패턴과 Google OKF 규격, [워크숍] 내 AI 자산 인벤토리
M2 · 1.5H지식 재편 — OKF frontmatter·번들·신뢰 신호, 세션 선별 기준, [실습] 내 AI 세션을 OKF 문서로 재편
M3 · 1.5H지식그래프 구축 — 상호 링크와 Mermaid 검증, AGENTS.md 컨텍스트 파이프라인, [실습] 출처 추적 질의 사이클
STEP 2 · 오후
자율 에이전트와 비서 자동화
4H
M4 · 2H자율 에이전트 기반 — 지식그래프를 읽는 claude -p 워커, 질문 회귀 가드레일, [실습] 자료 생성 에이전트
M5 · 2H내 비서 에이전트 — 지시 접수 → 자료 생성 → 업무 메일 발송(SMTP) 파이프라인, [통합 실습] E2E 완주
선택 실습과 확장 과제 — 텔레그램 원격 지시(선택 실습), OpenClaw 자율 에이전트 런타임(확장 과제 자료)
산출물
OKF 개인 지식 문서 번들Mermaid 개인 지식그래프AGENTS.md 컨텍스트 파이프라인자료 생성 자율 에이전트지시→생성→메일 발송 E2E 파이프라인

05 / 운영 안내

운영 · 실습 전제

사내 실무와 동일한 환경에서 실습

두 트랙 모두 엔터프라이즈 구독 계정만으로 동작. API 키를 쓰지 않아 교육에서 만든 파이프라인을 현업에서 그대로 재현할 수 있습니다.

무API 구독 인증 설계
구독 계정만으로 전 실습 수행

  • 제어 평면(LangGraph)·관측(Langfuse)은 LLM API 불필요
  • 실습 전 API 키 환경변수 정리 가이드 배포

  • 구독 로그인 허용 확인 · 설치 가이드 배포
  • 트랙 2는 SMTP 발송 계정 준비 (텔레그램 봇은 선택)
  • 실습 데이터는 각자의 AI 세션·개인 자료
