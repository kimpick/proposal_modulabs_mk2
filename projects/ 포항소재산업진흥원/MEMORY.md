- **결정**: 총 시간을 16H로 줄이되 v1(32H)을 삭제하지 않고 확장안으로 보존
  **왜**: 예산·일정이 확보되면 32H안을 그대로 제시할 수 있어야 함
  **출처**: 사용자 지시 (2026-08-25) — "복사한 뒤 버전 업"

- **결정**: GUI를 직접 개발하지 않고 **제공 Python 뷰어 활용**으로 변경
  **왜**: 16H에서 GUI 개발까지 넣으면 검증 시간이 사라짐. GUI 스택 경험이 강사 필수 요건에서 빠지므로 후보 풀도 넓어짐 (v1의 GUI 보조강사 분리 옵션이 불필요해짐)
  **출처**: 4일 압축 운영안 참고자료

- **결정**: 그래프 엔지니어링·장시간 운전 테스트·CI 연동을 v2 범위에서 제외
  **왜**: 하네스와 루프까지만으로도 현업 적용이 가능. 제외 항목은 v2 문서에 표로 명시해 협의 때 확장 근거로 사용
  **출처**: 16H 축소 판단

- **결정**: **강사는 미확정.** 참고자료를 제공한 후보를 전제하지 않음
  **왜**: 사용자가 명시적으로 지시 — 커리큘럼 구성만 참고할 것
