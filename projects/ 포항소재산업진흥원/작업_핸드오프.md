## 2. 커리큘럼 구조 (요약)

8차수를 **두 축의 교차**로 설계함.

| 축 | 1차 | 2차 | 3차 | 4차 | 5차 | 6차 | 7차 | 8차 |
|---|---|---|---|---|---|---|---|---|
| 임베디드 | 환경 구축 | 센서 | 실시간 | RS-485 | Modbus | GUI | 통합 | 캡스톤 |
| AI 협업 | 가이드 | 검증 장치 | 루프 | 통신 검증 | 회귀 루프 | 그래프 | 오케스트레이션 | 자산화 |

각 차수 4H, 모듈 3~4개. 시간 합계는 차수별로 정확히 4H로 맞춰 검증 완료.

## 3. 의사결정 기록

### D1. 차수를 8로 잡은 이유

5차수는 센서·RS-485·GUI를 각 1차수씩만 다루게 되어 실습 깊이가 얕아짐. 10차수는 예산·일정 부담. 8차수면 3개 주제를 각 2차수씩 + 통합·캡스톤 2차수로 균형이 잡힘.

### D2. harness / loop / graph를 별도 차수로 빼지 않음 ⭐

세션 중 사용자가 이 세 개념 리서치 후 반영을 요청. **별도 이론 차수로 묶으면 "좋은 얘기지만 우리 일과는 다르다"로 끝난다**고 판단해, 각 개념이 실제로 필요해지는 시점에 배치함.

- **가이드**(하네스) → 1차수, 프로젝트를 처음 열 때
- **검증 장치**(센서) → 2차수, 첫 드라이버를 확인할 때
- **루프** → 3차수, 반복 검증이 지겨워질 때
- **그래프** → 6차수, GUI라는 다른 스택이 병렬로 들어올 때

리서치 근거는 md 하단 참고 자료 5건. 핵심 출처는 martinfowler.com 「Harness engineering for coding agent users」(Birgitta Böckeler, 2026.04).

### D3. HIL(Hardware-in-the-Loop)을 커리큘럼 뼈대로 삼음 ⭐

Fowler가 하네스 중 **"행동(behaviour) 하네스"**, 즉 기능이 의도대로 동작하는지 검증하는 부분이 가장 미해결이라 지적. 임베디드는 여기가 더 심함(컴파일·테스트 통과해도 보드에서 타이밍·통신이 깨짐). 그래서 실물 보드 물린 자동 검증 루프를 3·5차수 중심에 놓음.

**이 판단이 커리큘럼 전체의 근거이자 강사 요건의 핵심.** 바꾸면 3·5차수와 강사 필수 요건이 같이 흔들림.

### D4. 견적 제외

공고에도 "비용: 협의를 통해 확정"으로 되어 있음. 커리큘럼 확정 후 별도 견적서로 붙이는 게 자연스러움. 대신 12번 슬라이드에 **착수 전 확정할 6개 항목**을 넣어 다음 미팅 안건이 되도록 함.

### D5. 기대효과에 정량 수치를 넣지 않음

근거 없는 숫자를 넣으면 검증 요청이 들어올 때 곤란. 정성 표현으로 두고, 각주에 "정량 목표가 필요하면 착수 전 기준선을 함께 측정" 이라는 여지를 남김.

### D6. 커리큘럼 슬라이드를 3장 → 4장으로 재분할

폰트를 20~25% 키웠는데, 덱의 `fitContent()` 자동 축소 때문에 **글자만 키우면 도로 줄어듦**. 한 장에 담는 양(2차수씩)을 줄여야 실제로 커짐. 향후 내용 추가 시 이 제약 유의.

### D7. 6차수 GUI 보조강사 분리 옵션

임베디드 + RS-485 + Modbus + AI 코딩 + GUI를 모두 갖춘 강사는 희소. 6차수만 분리하면 후보 풀이 넓어짐. 주강사 1~5·7~8차수 / GUI 강사 6차수 구조를 md에 권고로 명시.

### D8. 번역체 제거

명사 나열형을 동사형으로 전환. 주요 교정:

| 이전 | 이후 |
|---|---|
| 자기수정 신호로 전환 | 스스로 고칠 신호로 바꾸기 |
| 오케스트레이터–워커 조직으로 배선 | 지휘자와 작업자로 나눠 맡기기 |
| 실행 계보(execution lineage) | 실행 이력 |
| 판정 가능한 신호로 정형화 | 합격·불합격 판정이 가능한 형태로 정리 |
| 열화를 조기 검출 | 문제를 일찍 잡기 |
| 컨텍스트 부재 / 검증 신호 부재 | 매번 처음부터 설명 / 돌려봐야 안다 |

Before/After 표의 열 이름도 "Before·After" → "지금·수료 후"로 변경 (발표 시 그대로 읽히도록).
