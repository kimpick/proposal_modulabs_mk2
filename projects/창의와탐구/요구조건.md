# 창의와탐구 AI 교육 요구조건

## 버전 이력

| 버전 | 일자 | 주요 변경 | 출처 |
|---|---|---|---|
| v1 | 2026-07-28 | 초기 요구조건 (커리큘럼 확정안 기반) | 담당자 전달 커리큘럼 |

## 고객 정보

- **고객사**: 창의와탐구 (와이즈만 영재교육)
- **업종**: 교육 (영재교육 콘텐츠 — 26년 축적 교재·문항·실험 콘텐츠 보유)
- **교육 대상**: 콘텐츠 자동화 TF — 비개발 직군(교재개발·교수설계·출판) + 개발자 혼합 팀
- **작성자**: 이은경

## 교육 배경 및 목표

- 학령인구 감소와 교육업계 AX 경쟁 속에서 보유 콘텐츠 자산의 AI 재활용 역량 확보가 핵심 과제
- 26년간 축적된 교재·문항·실험 콘텐츠(한글/PDF/스캔)의 **DB화** 및 **신규 콘텐츠 제작 자동화**를 TF가 직접 구축·운영할 수 있는 역량 확보
- 목표 산출물: 추출→구조화→저장→생성 전 구간이 작동하는 **콘텐츠 DB화 파이프라인 프로토타입** + 전체 콘텐츠 이관 로드맵

## 교육 개요

| 구분 | 내용 |
|---|---|
| 과정명 | AI 에이전트로 완성하는 콘텐츠 DB화·자동 제작 파이프라인 구축 |
| 키워드 구분 | 자동화/에이전트 |
| 상세 키워드 | AI 에이전트, Gemini API, Google AI Studio, Structured Output, RAG, ChromaDB, 멀티모달 문서 추출 |
| AX 단계 | Level 2 |
| 소요 시간 | 16시간 (8시간 × 2일) |
| 교육 형태 | 오프라인 실습 중심 (온/오프 혼합 조정 가능) |
| 운영 구조 | **조별 통합 실습형** — 비개발+개발 혼합 2~3개 조, 강사 1명 조별 순회 밀착 코칭 |

## 커리큘럼 구조 (확정안)

### Day 1 · 공통 — 콘텐츠 자동화 설계 (8H)

| 모듈 | 시간 |
|---|---|
| 과정 소개 및 학습 목표 정렬 | 0.5H |
| AI 에이전트 개념과 콘텐츠 자동화 파이프라인 | 1.5H |
| Gemini·Gems 기반 콘텐츠 프롬프트 실습 | 2H |
| 콘텐츠 DB화 유즈케이스 정의 워크숍 | 2H |
| 콘텐츠 스키마 설계·검증 실습 (AI Studio Structured Output) | 2H |

### Day 2 · 조별 통합 실습 — 파이프라인 구축 (8H)

| 모듈 | 시간 |
|---|---|
| 조 편성 및 실습 목표 브리핑 | 0.5H |
| 조별 실습 ① 추출·구조화 파이프라인 구축 (Gemini API 멀티모달) | 3H |
| 조별 실습 ② DB 적재와 자연어 검색 (정형 DB + ChromaDB) | 2H |
| RAG 생성 에이전트 완성과 조별 데모 | 1.5H |
| 운영 거버넌스와 확장 로드맵 | 1H |

## 운영 방식 요구사항

- **협업 설계**: 프롬프트·스키마 담당(비개발)과 구현 담당(개발)이 한 조에서 실시간 협업 — 비개발 담당이 AI Studio에서 검증한 프롬프트를 개발 담당이 즉시 파이프라인에 이식하는 실제 업무 흐름 그대로 실습
- **자율 진행 지원**: 단계별 체크포인트가 담긴 조별 실습 가이드 사전 제작·배포
- **성과 확인**: Day 2 종료 시 조별 엔드투엔드 데모(원본 투입→DB화→신규 콘텐츠 초안) 및 상호 리뷰

## 필요 인프라

- 개발 환경: Python, VS Code
- API/모델: Gemini API **유료 API 키 필수** (Google Cloud 결제 계정 연결 — 무료 티어는 입력 데이터가 모델 학습에 활용될 수 있어 콘텐츠 IP 보호 불가, 전원 동시 실습에도 한도 부족)
- 유료 플랜: Gemini API 유료 티어(AI Studio에서 동일 키 사용), Claude 구독(개발자 코딩 보조, 고객사 기보유)
- 데이터: 사내 교재·문항·실험자료 샘플 3~5건 (NDA 하 사전 공유, 한글 HWP 원본은 PDF 변환 후 투입)
- 툴/라이브러리: ChromaDB, Gemini Python SDK(신규 통합 SDK google-genai 기준)

## 교육 준비 요청사항 (고객사)

| 항목 | 내용 |
|---|---|
| Google Cloud 결제 계정 + API 키 | AI Studio·Gemini API 유료 티어 발급 (모두연이 발급 가이드 제공) |
| Workspace 관리자 설정 확인 | 조직 계정의 Google AI Studio 접근 허용 여부 사전 점검 |
| 샘플 콘텐츠 3~5건 | 교재·문항·실험자료의 실제 형태(한글/PDF/스캔) 확인 — 스키마 설계와 실습 난이도 확정에 필수, NDA 하 공유 |
| 개발자 실습 환경 | VS Code + Python 설치, Claude 구독 계정(기보유) 확인 |

## 산출물 예시

- 사내 콘텐츠 메타데이터 스키마(JSON) 및 검증 완료 구조화 프롬프트 세트
- 원본 투입→DB화→신규 콘텐츠 초안 생성까지 작동하는 파이프라인 프로토타입
- 콘텐츠 IP 보호 정책 및 전체 콘텐츠 이관 로드맵
