비개발자 / Business Track 초급 · 20H · 5주 과정

AI를 ‘쓰는 사람’에서, AI를 ‘만드는 사람’으로.

KCB 비개발 직군이 코드 한 줄 쓰지 않고 사내 Qwen Code로 데이터 정리, 보고서 초안, 반복 업무 자동화까지 직접 만듭니다. 5주 뒤, 본인 업무 옆자리에 둘 ‘나만의 AI 비서’ 한 개를 손에 쥡니다.

01 / Overview
과정 소개 · 왜 이 과정인가

‘ChatGPT 잘 쓰는 법’이 아니라, ‘내 업무에 끼워넣는 법’을 배웁니다.

A
손에 잡히는 업무 자동화

엑셀 정리, 회의록 요약, 보고서 초안, 사내 문서 검색 — 실제 KCB 업무에서 매주 반복되는 작업을 Qwen Code에게 넘기는 구체적인 워크플로우를 다룹니다. 일회성 시연이 아니라 다음 날 바로 쓸 수 있는 형태로.

B
코드 없이도, 내 손으로 만든다

‘바이브 코딩’의 정신을 폐쇄망에서 실현합니다. CLI나 프로그래밍 지식 없이, 자연어 지시만으로 Qwen Code가 코드와 결과물을 대신 만들어 주는 흐름을 익혀 자기 업무용 AI 비서까지 직접 구축합니다.

Before · 지금 우리 모습
AI는 들었는데, 막상 내 업무에는…
  • “ChatGPT는 써봤는데 회사에서는 못 써요”
  • 매주 비슷한 보고서·정리 작업을 손으로 반복
  • AI 자동화 사례는 알지만 어디서 시작할지 모름
  • 코드 얘기만 나오면 멀어지는 거리감
→
After · 5주 뒤의 모습
AI를 옆자리에 앉혀 일하는 사람
  • 사내 Qwen Code로 데이터·문서를 정리하고 요약함
  • 반복 업무에 쓰는 시간이 주당 2~3시간 단축
  • 코드 없이도 자기 업무용 미니 AI 비서를 운영함
  • 팀에 ‘AI 활용 사례’를 가장 먼저 소개하는 사람
02 / Goals
교육 목표 · 5주 후 손에 남는 것

과정이 끝날 때, 이 네 가지가 손에 남습니다.

01
AI의 ‘말귀를 잘 알아듣게 하는’ 프롬프트 감각

‘좋은 질문’과 ‘쓸 만한 답변’을 분리하는 능력. 할루시네이션을 줄이는 멀티턴 대화법, 비즈니스 메일·문서 톤앤매너 조정 등 실무 즉시 활용 가능한 프롬프트 패턴을 익힙니다.

02
데이터·문서를 자동으로 정리하는 워크플로우

엑셀(CSV)의 비정형 데이터를 구조화하고, 회의록·사내 문서를 요약하고, 핵심 조항만 뽑아내는 ‘읽고 정리하는 시간’을 절반으로 줄이는 자동화 패턴을 손에 익힙니다.

03
코드 한 줄 없이, Qwen Code로 도구 만들기

자연어 지시만으로 Qwen Code에게 업무용 미니 스크립트·도구를 만들게 합니다. ‘코딩’이 아니라 ‘시키는 법’을 배우는 과정. 한번 만들면 매번 다시 만들 필요가 없습니다.

04
자기 업무용 AI 비서 1개를 들고 나간다

마지막 주, 본인 업무 시나리오 기반으로 ‘나만의 AI 비서’를 직접 기획·구축·발표합니다. 교육 종료 시점에 다음 주부터 시범 운영 가능한 결과물을 손에 쥡니다.

03 / Stack
활용 도구 · 폐쇄망에서 돌아가는 셋

도구는 적게, 제대로 깊게 다룹니다.

AI Partner
Qwen Code

사내 폐쇄망에서 동작하는 AI 파트너. 모든 실습의 중심. ‘말 거는 방법’과 ‘일 시키는 방법’을 집중적으로 다룹니다.

Workspace
노트북 + 브라우저

별도의 개발 환경 설치 없이, 사내 표준 노트북과 브라우저만으로 진행합니다. 엑셀·워드 등 익숙한 도구와 자연스럽게 연결합니다.

Method
Vibe Workflow

‘기획 → 지시 → 검수 → 반영’의 짧은 사이클로 결과물을 만드는 작업 방식. 코드가 아니라 일하는 방식을 배웁니다.

04 / Infrastructure
필요 인프라 · 폐쇄망 기준

준비물은 최소한입니다.

1인 1대 실습용 사내 노트북
사내 Qwen Code 접근 권한
실습용 샘플 엑셀·문서·회의록 세트
참가자별 본인 업무 시나리오 1건 (마지막 주 활용)
강의자료·실습 가이드 사내 공유 공간
발표 세션용 스크린·프로젝터 환경
폐쇄망 운영 메모. 본 과정은 외부 도구(ChatGPT·Gemini·Midjourney 등) 접근이 불가능한 환경을 전제로 합니다. 사내 Qwen Code 하나만으로 ‘문서 자동화 → 업무 도구 제작 → 개인 AI 비서’ 흐름을 모두 다룰 수 있도록 모듈을 재설계했습니다. 외부 도구 활용이 필요한 영역(이미지 생성 등)은 사내에 도입 가능한 대안이 있을 경우 사전 협의 후 추가 다룰 수 있습니다.

07 / Deliverables
예상 산출물

들고 나가는 것은 강의 PDF가 아니라 작동하는 도구입니다.

01

업무 자동화 프롬프트 라이브러리

데이터 정리·문서 요약·메일 작성 등 자기 업무에 맞춘 재사용 가능한 프롬프트 모음 1세트. 매번 새로 짤 필요 없이 꺼내 쓸 수 있는 형태입니다.

02

Qwen Code 기반 업무 자동화 스크립트

본인 반복 업무 1건을 자동화한 실제 작동하는 스크립트. ‘코드 없이 만들었지만 코드로 돌아가는’ 결과물 형태로 손에 남습니다.

03

나만의 AI 업무 비서

본인 업무 스타일과 양식을 기억하는 개인용 AI 비서 1식. 교육 종료 다음 주부터 자기 자리에서 시범 운영 가능합니다.
