개발자 / Developer Track 중급 · 20H · 5주 과정

교육이 끝나면, 곧장 일을 시작하는 Agent를 만듭니다.

KCB 개발 실무자가 사내 Qwen Code 환경 위에서 RAG 시스템과 멀티 도구 Agent를 직접 설계·구축합니다. 5주 뒤, 본인 자리에서 그대로 동작하는 Agent 한 개를 손에 쥐고 돌아갑니다.

01 / Overview
과정 소개 · 왜 이 과정인가

프롬프트로 시작해, 실제 운영되는 Agent로 마무리합니다.

A
개발 워크플로우에 자연스럽게 들어오는 5주

LLM 기초·프롬프트 엔지니어링부터 RAG, Function Call, Llama Index 기반 멀티 Agent까지 — 각 모듈이 본인 개발 업무의 한 부품이 되도록 구성했습니다. 코드 리뷰, 사내 문서 검색, 반복 작업 자동화에 다음 주부터 적용 가능한 형태입니다.

B
폐쇄망 + Qwen Code 환경에 맞춰 설계된 실습

외부 API에 의존하지 않습니다. 사내 Qwen Code 환경 위에서 동작하는 RAG 파이프라인과 Agent 패턴을 다룹니다. 교육에서 작성한 코드가 종료 후에도 그대로 사내에서 살아 움직이게 만드는 것이 목표입니다.

02 / Goals
교육 목표 · 5주 후 손에 남는 것

과정이 끝날 때, 이 네 가지를 할 수 있습니다.

01
LLM·RAG·Agent의 구조를 다시 설명할 수 있다

토큰 / 임베딩 / VectorDB / Function Call / Agent Loop의 작동 원리를 코드 레벨에서 이해하고, 팀 동료에게 한 장의 다이어그램으로 다시 설명할 수 있는 수준에 도달합니다.

02
Qwen Code 위에서 RAG 시스템을 구축할 수 있다

사내 문서·코드베이스를 임베딩하고, 벡터 검색과 Qwen 호출을 연결한 폐쇄망용 RAG 파이프라인을 직접 만들고 검색 품질을 튜닝합니다.

03
Llama Index 기반 멀티 도구 Agent를 구현한다

Function Call과 Llama Index Agent를 조합해 여러 도구를 호출하는 워크플로우를 구축하고, 분기·재시도·로깅까지 운영 가능한 형태로 다듬는 법을 익힙니다.

04
자기 업무용 Agent 1개를 들고 나간다

마지막 주, 본인 업무 시나리오를 기반으로 미니 Agent를 직접 기획·구현·발표합니다. 교육 종료 시점에 사내에 즉시 배치 가능한 결과물을 손에 쥡니다.

03 / Stack
핵심 기술 스택

도구 셋, 각자의 역할이 있습니다.

LLM Runtime
Qwen Code

사내 폐쇄망에서 동작하는 코드 특화 LLM. 모든 실습의 추론·생성 엔진으로 사용하며, 호출 패턴과 프롬프트 최적화를 집중적으로 다룹니다.

Retrieval
VectorDB + Embedding

Chroma 등 경량 VectorDB로 사내 문서·코드 임베딩 인덱스를 구축하고, RAG 검색 품질을 끌어올리는 청크 전략을 실습합니다.

Orchestration
Llama Index

Agent · Tool · Workflow 추상화를 활용해 멀티 단계 Agent를 구성합니다. Function Call과 결합한 도구 사용 패턴을 익힙니다.

04 / Infrastructure
필요 인프라 · 폐쇄망 기준

외부 의존성 없이 동작합니다.

1인 1대 실습 PC · Python 3.10+, Jupyter
사내 Qwen Code 호출 권한 · API endpoint
VectorDB(Chroma 권장) 사내 설치 환경
Llama Index · LangChain 등 사내 패키지 미러
실습용 샘플 데이터셋·사내 문서 일부
코드 공유용 사내망 도구 · Confluence·GitLab 등
폐쇄망 운영 메모. 외부 모델(GPT·Claude 등 API)이나 외부 패키지 저장소 접근이 불가능한 환경을 기본 전제로 합니다. 모든 실습은 사내 Qwen Code 및 사내 미러 환경에서 재현 가능하도록 설계되며, 필요 라이브러리 목록과 설치 가이드는 사전 협의 단계에서 함께 정리해 드립니다.
