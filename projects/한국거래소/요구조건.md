# 한국거래소 (KRX) AI 교육 요구조건

## 기업 기본 정보
- **기업명**: 한국거래소 (KRX)
- **담당자**: 김승한 ([고객담당자 이메일 비공개])

## 교육 개요
- **대상**: IT 관리직 비개발자 20명
  - 시스템 운영 관제
  - 보안 관제
  - 계약 운영 관리
- **수준**: 전공자 수준 기본 지식 보유, 실제 개발 경험 없음
- **총 시간**: 20시간 (4시간 × 5일)
- **시작 시점**: 2026년 6월 중순 예정

## 교육 환경
- **장소**: 한국거래소 사내 교육장
- **네트워크**: 교육 시 사외망 사용 가능 (평소는 망분리)

## 교육 목적 및 기대 결과물
- **목적**: 관리자가 실무 병목이 되지 않도록 AI 역량 확장
- **주제**: Agent 교육
- **기대 결과물**: 반복 업무 자동화 Agent 직접 제작
- **활용 예시**:
  - 보안 뉴스 모니터링 Agent
  - 상위 기관 공지사항 수집·알림 Agent

## 예산
- 시간당 100~200만원

## 도구 구성 (확정)
- 생성형 AI 플랫폼 (Claude, ChatGPT)
- 노코드 Agent 빌더 (n8n 또는 Dify)
- Google Workspace (스프레드시트, Docs)

## 특이사항
- 망분리 환경이므로 교육 당일 사외망 확인 필요
- 개발 경험 없는 IT 관리자 대상 → 노코드 중심 커리큘럼
- 5일 과정 중 4, 5일차는 Agent 직접 구현에 집중
