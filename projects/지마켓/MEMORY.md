## 결정과 근거

- **결정**: Qoder 교안 예시 21장·부록 3장을 본 제안 커리큘럼에 맞춰 재작성하지 않고, **"본 사업 범위 밖의 확장 로드맵(향후 제안)"임을 표지·부록 첫 장에 명시**
  **왜**: 교안 21장 중 13장이 Qoder IDE/CLI(개발자 영역)이고 3단계 시수(3H/7H/7H)가 본 제안(3H/5H/4H)과 다름. 재작성보다 위치 규정이 자료 가치를 살림
  **출처**: 2026-09-01 사용자 결정

- **결정**: 직원 과정(4H)은 **1일 2차수(오전·오후)** 운영을 기본안으로 확정. 임원(3H)·리더(5H)는 1일 1차수 유지
  **왜**: S32(2차수 권장)와 S37(1차수 원칙)이 상충했고 사용자가 2차수로 확정. 5H 과정을 하루 2회 돌리면 10시간이라 비현실적이므로 4H 직원 과정에만 적용
  **파급**: 직원 교육 실행 구간 25일 → **13일**(10/20~11/5), 확보한 2주를 11/9~11/13 예비일 + 11/16~11/20 보강 구간으로 배정. 최종 성과보고 11/30 → **11/27**
  **강사 정합**: 오전·오후를 서로 다른 트랙에 배정해 주강사 1인당 1일 1차수·주 최대 3차수(S39 부하 기준)를 유지. 부족분은 주강사 풀 7인의 검증 백업 강사가 교대
  **출처**: 2026-09-01 사용자 결정

- **결정**: 사업 기간은 **교육 실시 9~11월 / 사후관리·성과보고 ~12월 초**로 분리 표기
  **왜**: S12는 "3개월"인데 간트는 12월 초까지 가 모순이었음. 간트를 줄이지 않고 표기만 정확히 함
  **출처**: 2026-09-01 사용자 결정

- **결정**: 구 S38~S41(4단계 관리 체계 / 표준 운영 런북 / 인력 배치 / 역할별 업무) 네 장을 **2장으로 병합**
