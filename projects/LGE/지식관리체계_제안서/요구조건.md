## 검토 조정 사항 (NotebookLM 초안 → 제안서)

초안은 기술적으로 정확하고 최신(OKF·APEX-MEM 모두 실재·2026년 자료 검증 완료)이나, 아래를 조정하여 제안서화:

1. **[Flow · 실습비중] 이론 축소, 실습 전면 배치** — 초안 Day 1(전일 이론/설계)을 이론 40% + 핸즈온 60%로 재구성. 배운 온톨로지를 즉시 본인 문서에 적용.
2. **[원 요청 복원] 개인 LLMwiki 핸즈온** — 최종 초안에서 흐려진 "개인 지식체계 핸즈온"을 Day 1 온램프로 복원 후 팀 단위로 확장.
3. **[운영 리스크] 환경 세팅 병목 방지** — uv·FastMCP·Python 설치는 6월 교육에서 지적된 PATH/패키지 충돌 재발 위험. 사전 가이드 배포 + **Day 2 도입부 1시간 동시 세팅** + 트러블슈팅 내장 + 보조강사 배치.
4. **[선행학습] 선수조건 명시** — Python 기초 이상, CLI·Git 경험 (LGE 개발자 대상이라 충족 가능).
5. **[교안 품질] 명령어 한 줄 설명 원칙** — 명령어 나열식 지양, 모든 명령어에 맥락 설명 병기 (운영 안내에 명시).
6. **[일정] 집중/분산 옵션 제시** — 5일 연속(집중) 또는 주 1~2회(분산, 회차 간 사내 문서 적용 과제).
