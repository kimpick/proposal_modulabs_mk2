### 개념 최신화

- **하네스 엔지니어링** (OpenAI 2026-02 공식): "특정 코드베이스에서 고정 모델이 신뢰할 수 있는 결과를 낼 수 있도록, 코딩 에이전트 주변의 설정 표면을 설계하는 학문". Context Engineering의 상위 개념 (세션 단위 → 코드베이스 단위).
  - 핵심 6요소: Repository-as-Doc(AGENTS.md/docs), Architectural Constraints, Agent Feedback Loop, Entropy Management, Memory & Context, Sandbox & Guardrails
- **루프 엔지니어링** (Boris Cherny 2026, Addy Osmani 블로그 2026-06): "프롬프트 지시에서 루프 작성으로" 전환. Stage 1(직접 프롬프팅) → Stage 2(병렬 수동) → Stage 3(자율 루프).
  - AORR (Act-Observe-Reason-Repeat) 상태 머신
  - Self-Correcting TDD, Maker-Checker 분리
  - Auto-Compact 방어 + Git-backed 영구 메모리
  - HITL 가드레일, 무한 루프 탈출 알고리즘
- **마스터-워커 하이브리드**: Orchestrator(capable model) + N workers(cheaper model) — 비용 효율적 오케스트레이션

### Agentic Coding 패러다임 핵심 통찰 (2026 Anthropic Trends Report)

> "에이전트 코딩은 코딩을 작성하는 활동에서 에이전트를 오케스트레이트하는 활동으로 이동"

- 단일 에이전트 + 툴셋이 대부분의 워크로드에 충분
- 멀티 에이전트는 진정으로 분리 가능한 하위 문제가 있을 때만 (단일 대비 90.2% 개선이나 15배 토큰 비용)
