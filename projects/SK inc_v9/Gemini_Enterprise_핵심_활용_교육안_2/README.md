# Gemini Enterprise 핵심 활용 교육안 작업 지침

## 파일명 네이밍 컨벤션

최종 산출물 파일명은 아래 형식을 따른다.

```text
[모두의연구소]SK inc_AI 교육 제안서_Gemini_Enterprise_핵심_활용_교육안_vN.pdf
```

- 기본 파일명은 현재 산출물 기준인 `[모두의연구소]SK inc_AI 교육 제안서_Gemini_Enterprise_핵심_활용_교육안`을 유지한다.
- 같은 작업물에 수정을 넣어 새 산출물을 만들 때마다 파일명 끝에 버전을 표기한다.
- 버전 표기는 `_v2`, `_v3`, `_v4`처럼 언더스코어와 소문자 `v`, 숫자를 붙인다.
- 기존 버전 파일은 덮어쓰지 않고 보관한다.
- 새로 생성하는 파일은 현재 폴더의 가장 높은 버전 번호 다음 번호를 사용한다.
