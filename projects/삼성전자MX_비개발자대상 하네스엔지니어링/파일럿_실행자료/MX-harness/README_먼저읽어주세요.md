# 점검 키트 사용법

이 폴더는 8/21 파일럿 교육 전 환경 점검용입니다.

## 1. 이 폴더를 어디에 두나요
`문서` 폴더 안에 `MX-harness` 라는 이름으로 통째로 두시면 됩니다.

## 2. 무엇을 확인하나요
앱이 이 폴더의 파일을 **읽을 수 있는지**, 그리고 이 폴더에 파일을 **만들 수 있는지** 두 가지입니다.

## 3. 읽기 확인
앱에 이 폴더를 연결한 뒤 아래를 그대로 입력하세요.

    _check.md 파일 내용을 읽어줘

답변에 "환경 준비 완료" 라는 문장이 나오면 통과입니다.

## 4. 쓰기 확인
이어서 아래를 그대로 입력하세요.

    knowledge 폴더에 test-node.md 파일을 만들고, 맨 위에 title과 type을 넣어줘

그 다음 탐색기로 knowledge 폴더를 직접 열어 파일이 실제로 생겼는지 확인하세요.
앱이 "만들었습니다"라고 답해도 실제로는 생기지 않는 경우가 있습니다.

## 5. 네 가지 앱 모두 같은 방식으로
Claude / Codex / Antigravity / Gemini 순서로 3번과 4번을 반복하시면 됩니다.
쓰기 확인 전에 knowledge 폴더의 test-node.md 를 지우고 다음 앱으로 넘어가 주세요.

## 폴더 설명
- knowledge : 앱이 파일을 만들 위치 (쓰기 확인용)
- source, input, output, skills : 실제 교육에서 사용할 폴더. 지금은 비어 있습니다.
