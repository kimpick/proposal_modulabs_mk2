## 5. 핵심 교육 콘셉트 — 하네스 엔지니어링

> *"Agent를 만드는 것보다, Agent가 제대로 일할 환경(Harness)을 설계하는 것이 더 중요하다."*

비개발자 대상이므로 **비즈니스 하네스** 개념으로 치환하여 교육:

### 하네스 3대 요소 (비개발자 버전)

| 요소 | 개념 | 비개발자 적용 예시 |
|---|---|---|
| **Context** | Agent가 참조할 정보 제공 | 사내 규정, 업무 가이드, 과거 레퍼런스 문서화 |
| **Constraints** | Agent가 잘못된 행동을 못하게 제한 | 업무 SOP, 템플릿 강제, 보안·윤리 룰 명시 |
| **Entropy** | Agent가 만든 결과물 정기 정리 | 생성 파일 주기적 정리 프로세스 구축 |

### 하네스를 위한 필수 문서 구성

수강생이 직접 자신의 Agent 폴더에 아래 문서를 만들고 관리하는 것을 실습 목표로 삼음:

```
내_Agent_프로젝트/
├── AGENTS.md              ← Agent에게 주는 핵심 지시서
│                              (역할, 금지사항, 업무 범위, 출력 형식)
├── ETHICS_SECURITY.md     ← AI 윤리/보안 사용 가이드
│                              (사내 보안 규정, 개인정보 처리 금지, 승인 URL 목록)
├── context/
│   ├── sop.md             ← 업무 표준 운영 절차 (SOP)
│   └── references.md      ← 참조 문서 목록 및 설명
└── templates/
    └── output_template.md ← Agent 결과물 출력 형식 템플릿
```

### AGENTS.md 핵심 항목 (교육 내용)
- Agent의 역할 및 목적 정의
- 절대 하지 말아야 할 것 (사내 보안 정보 외부 전송 금지 등)
- 업무 범위 및 권한 경계
- 출력 포맷 및 언어 규칙

### ETHICS_SECURITY.md 핵심 항목 (교육 내용)
- 사내 보안망 내 사용 가능한 URL/서비스 목록
- 개인정보 및 기밀 데이터 입력 금지 원칙
- AI 생성 결과물 검토·승인 절차 (Human-in-the-loop)
- 저작권 및 출처 표기 원칙
- LG전자 그룹 AI 사용 정책 준수 명시
