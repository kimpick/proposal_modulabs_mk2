## 2. 고객 요청 커리큘럼 (총 21H, 4영역)

> 원문은 4영역을 한 표에 묶어 전달했고, 일부 항목에 취소선(제외 의사)이 표기되어 있었습니다. 아래는 영역별로 분해한 구조입니다.

### 영역 A. 검색 고도화 및 프롬프트 엔지니어링 (8H)

- **고급 프롬프트 엔지니어링 (2H)**
  - 프롬프트 구조별 검색 품질 차이
  - Few-shot / Chain-of-Thought
  - RAG 파이프라인 내 최적화
- **하이브리드 검색 및 Re-ranking (3H)**
  - 키워드 + 시맨틱 결합
  - Cross-Encoder Re-ranking
  - Reciprocal Rank Fusion (RRF) 구현
- **Query Transformation (3H)**
  - Trend Query Rewriting
  - HyDE (Hypothetical Document Embeddings)
  - Semantic Routing
  - LLM Query 분해 / 재작성 파이프라인

### 영역 B. 인덱싱 고도화, 평가 및 온톨로지 기초 (8H)

- **Multi-Representation 인덱싱 (3H)**
  - Paradigm Multi-Vector Retriever
  - 계층적 인덱싱
  - BM25 Sparse + Dense 결합
- **RAG 성능 측정 및 정량적 평가 (3H)**
  - RAG 핵심 5대 지표 분석
  - LLM-as-a-Judge
  - RAGAS / TruLens 실습
- **온톨로지 / 지식그래프 기초 (2H)**
  - 지식 그래프 개념
  - Entity / Relation 추출 기초
  - 소규모 실습
- **Langfuse 활용 검색 품질 트레이싱 테스트** (시간 추가 배정)

### 영역 C. 하이브리드 벡터화 고도화 (6H, 기존 8H에서 -2H)

- **온톨로지 스키마 설계 & 엔티티 자동 추출 (3H)**
  - Core 도메인 특화 온톨로지 설계
  - LLM 기반 대규모 Entity / Relation 자동 추출
  - 장비 매뉴얼 적용
- **온톨로지-LLM 하이브리드 벡터화 (3H)**
  - Core 지식 그래프 반영 하이브리드 임베딩
  - 메타데이터 활용 검색 정확도 향상
  - Graph + Vector 하이브리드 인덱스
- ❌ **제외: 대규모 데이터 적재 및 인덱스 최적화 (2H)**
  - 원래 내용: 배치 처리 파이프라인, Incremental Index 갱신, 벡터 DB 성능 튜닝
  - 사유: 기초/심화 범위 외 (엔터프라이즈 인프라 영역)

### 영역 D. 고도화된 검색 파이프라인 (2H, 기존 5H에서 -3H)

- ❌ **제외: Agentic RAG & 자가 성찰 (3H)**
  - 원래 내용: Paradigm Shift Agent 구조, CRAG (Corrective RAG), Self-RAG, LangGraph 순환형 파이프라인
  - 사유: 3시간 내 깊이 있게 다루기 어려움 → 개념·적용방법 간단 실습 + 참고자료 제공으로 대체
- **검색 품질 End-to-End 평가 — 경진대회 (2H)**
  - 단계별 병목 진단
  - A/B 테스트 개선 사이클
  - RAGAS 심화 평가

## 3. 주요 논의사항

- **커리큘럼 조정**: 기존 커리큘럼에서 일부 내용(기초 첫날, 심화 마지막 날, GraphRAG 일부)을 제외하고, **온톨로지 부분을 강화**하는 방향으로 1차 조정.
- **신규 콘텐츠 추가**: 수강생의 실질적 역량 향상을 위해 **고급 프롬프트 엔지니어링**, **LangFuse 활용 End-to-End 평가**, **미니 경진대회 형식 실습** 추가 제안.
- **교육 난이도 설정**: 개발자 + 일반 업무 담당자 혼합 수강 → **중간 수준**으로 설정.
  - 온톨로지 기초까지 공통 이해 가능한 수준
  - 하이브리드 벡터화 등 심화 내용은 프로젝트 담당자 중심으로 진행
- **실습 자료 준비**: 미니 경진대회용 약 60~70페이지 한글 문서 필요.
  - 외부 공개 가능한 문서 + 수강생 개별 준비 내부 문서 병행

| 구분 | 준비 주체 | 내용 |
|---|---|---|
