RAG 심화 교육 과정 (제안용 초안)

총 24시간 | 기초 과정 이수자 대상

기초에서 구축한 RAG 파이프라인을 바탕으로, 온톨로지 + LLM 하이브리드 벡터화를 핵심으로 데이터를 잘 벡터화하고, 잘 적재하고, 잘 검색하는 엔드-투-엔드 파이프라인을 완성합니다. 최종적으로 사용자가 자연어로 질의하고 정확한 결과를 얻는 검색 경험까지 구현합니다.

단계 시간 모듈명 핵심 학습 내용 주요 실습 및 구현 스택
1단계
하이브리드 벡터화 고도화
(8H)
3H온톨로지 스키마 설계 & 엔티티 자동 추출
  • [Core] 도메인 특화 온톨로지 스키마 설계 방법론
  • LLM 기반 Entity / Relation 대규모 자동 추출
  • 기초에서 다룬 개념을 실제 장비 매뉴얼 데이터에 적용
  • Neo4j / NebulaGraph 스키마 모델링
  • 장비 매뉴얼 기반 Entity/Relation 추출 파이프라인
3H온톨로지-LLM 하이브리드 벡터화
  • [Core] 지식 그래프 구조를 반영한 하이브리드 임베딩 전략
  • 단순 텍스트 벡터를 넘어 의미 관계를 포함하는 벡터 구성
  • 온톨로지 노드/엣지 메타데이터를 활용한 검색 정확도 향상
  • Graph + Vector 하이브리드 인덱스 구축
  • 메타데이터 기반 필터링 검색 실습
2H대규모 데이터 적재 및 인덱스 최적화
  • 대용량 문서(수천 건 매뉴얼 등) 배치 처리 파이프라인
  • 인덱스 갱신 전략 (Incremental vs. Full Rebuild)
  • 벡터 DB 성능 튜닝 및 샤딩 기초
  • ChromaDB / Qdrant 대규모 적재 실습
  • 배치 임베딩 파이프라인 구축
2단계
고도화된 검색 파이프라인
(8H)
3HGraphRAG 기반 관계망 추론
  • Paradigm Shift지식 그래프의 다단계 Hop을 활용한 맥락 검색
  • 벡터 검색 + 그래프 순회 결합 검색 전략
  • 파편화된 장비 정보 간 연관성 자동 발굴
  • Neo4j Cypher 쿼리 + Vector 검색 하이브리드
  • Multi-Hop 추론 기반 답변 생성
3HAgentic RAG & 자가 성찰 (Self-Reflect)
  • Paradigm ShiftLLM이 스스로 검색 필요성을 판단하고 Tool을 호출하는 Agent 구조
  • CRAG(Corrective RAG): 검색 결과 품질 평가 후 재검색
  • Self-RAG: 생성된 답변의 자체 검증 루프
  • LangGraph 기반 순환형(Cyclic) 파이프라인 구축
  • Tool-calling Agent 설계 실습
2H검색 품질 고도화 및 End-to-End 평가
  • 기초에서 학습한 RAGAS 지표를 심화 파이프라인에 적용
  • 벡터화 → 적재 → 검색 → 생성 각 단계별 병목 진단
  • A/B 테스트 기반 검색 품질 개선 사이클
  • RAGAS / TruLens 심화 평가 실습
  • 파이프라인 단계별 성능 프로파일링
3단계
사용자 검색 경험 및 프로덕션 배포
(8H)
3H사용자 검색 인터페이스 설계
  • [Core] 자연어 질의 → 의도 분석 → 검색 → 결과 렌더링 전체 흐름
  • 검색 결과 UI 패턴: 요약 카드, 출처 표시, 관련 문서 추천
  • 대화형 검색 (Follow-up Question) 설계
  • FastAPI 기반 검색 API 엔드포인트 구현
  • Streamlit / Gradio 검색 데모 UI 구축
3H사내 인프라 통합 (Azure Databricks)
  • Azure Databricks 환경에 RAG 파이프라인 배포
  • Telnuat 플랫폼 연동 아키텍처 매핑
  • 사내 데이터 소스(DB, 문서 저장소)와의 연결
  • Databricks Notebook 기반 배포 실습
  • 사내 REST API 연동 설계 리뷰
2HAI Guardrails & 운영 체계
  • 환각(Hallucination) 방지 가드레일 적용
  • 민감 데이터(사내 기밀) 유출 차단
  • 검색 로그 모니터링 및 품질 지표 대시보드 기초
  • NeMo Guardrails 적용 실습
  • 검색 품질 모니터링 대시보드 설계

* 본 과정은 기초 교육 이수자를 대상으로 하며, 사내 인프라(Databricks) 환경에 맞춘 실습을 포함합니다.
