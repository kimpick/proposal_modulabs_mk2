01과정 소개
본 과정은 특정 벤더에 종속되지 않는 오픈소스 프레임워크(LangChain 등)를 기반으로, RAG 파이프라인의 기본 작동 원리부터 GraphRAG, Agentic RAG까지 엔드-투-엔드로 다룹니다. 1일차에서 RAG 기본 구조와 고급 프롬프트 엔지니어링으로 이론적 기반을 확립하고, 2일차에서 검색 고도화와 GraphRAG를 실습하며, 3일차에서 평가·Agentic RAG를 다루고 미니 경진대회로 학습 내용을 종합 적용합니다.
02교육 목표
RAG 파이프라인 핵심 구조 이해 및 구현: 임베딩, 벡터 검색, 청킹의 원리를 이해하고 직접 구현. 고급 프롬프트 엔지니어링: 프롬프트 구조 설계, 컨텍스트 주입, Grounding, Citation으로 LLM 제어 역량 확보. GraphRAG 실무 적용: 지식그래프 기반 검색, Multi-Hop 맥락 검색, Neo4j 실습. Agentic RAG 기초: CRAG, Self-RAG 개념 습득 및 LangGraph 실습. 정량적 평가 역량: RAGAS/TruLens 기반 RAG 성능 측정 및 개선.

06상세 커리큘럼 (24H)

목표: RAG 파이프라인의 핵심 구조를 이해하고 직접 구현. 고급 프롬프트 엔지니어링으로 LLM 제어 역량 확보. GraphRAG, Agentic RAG 기초 개념 습득. RAGAS 기반 정량적 평가 역량 확보.

1일차
RAG 기초 및 프롬프트 엔지니어링
  • RAG 패러다임 & LangChain 기본 (1.5H): Naive RAG 한계, Advanced RAG 진화, LangChain 기본 구조 + 간단한 Chain 실습
  • 프롬프트 엔지니어링 고급 (2H): 프롬프트 구조 설계(System/Context/Instruction), 컨텍스트 주입, Grounding, Citation, Few-shot/Chain-of-Thought를 활용한 답변 품질 제어
  • 벡터 검색 / 임베딩 핵심 개념 (2.5H): 임베딩 변환 원리(Dense/Sparse), 코사인 유사도, ChromaDB/Qdrant 벡터 DB 구축 및 인덱싱
  • 비정형 데이터 파싱 & 시맨틱 청킹 (2H): TrendVision LLM 기반 PDF 파싱, Contextual & Semantic Chunking, 메타데이터 추출
8H
2일차
검색 고도화 및 Graph RAG
  • 하이브리드 검색 및 Re-ranking (2.5H): 키워드+시맨틱 결합, Cross-Encoder Re-ranking, Reciprocal Rank Fusion(RRF) 구현
  • Query Transformation (2.5H): TrendQuery Rewriting, HyDE, Semantic Routing, LLM Query 분해/재작성 파이프라인
  • Graph RAG (3H): Paradigm지식 그래프 개념, Entity/Relation 추출, Multi-Hop 맥락 검색, 그래프 순회+벡터 결합 검색, Neo4j 실습
8H
3일차
평가, Agentic RAG 및 미니 경진대회
  • Multi-Representation 인덱싱 (2H): ParadigmMulti-Vector Retriever, 계층적 인덱싱, BM25 Sparse+Dense 결합
  • RAG 성능 측정 및 정량적 평가 (2H): TrendRAG 핵심 5대 지표 분석, LLM-as-a-Judge, RAGAS/TruLens 실습
  • Agentic RAG 기초 (2H): Paradigm ShiftCRAG(Corrective RAG), Self-RAG 개념, LangGraph 순환형 파이프라인 미니 실습
  • RAG 미니 경진대회 (2H): 교육 전체 내용 종합 적용, 팀별 RAG 파이프라인 구축 경쟁, 결과 발표 및 피드백
8H
07예상 산출물

  • GraphRAG 기반 지식그래프 검색 실습 결과물
  • RAG 미니 경진대회 팀 프로젝트 산출물
