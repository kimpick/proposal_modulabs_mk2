## 교육 내용 요구사항

### 1·2차 — 평가기획 (평가실 7인, 바이브코딩)
**"바이브코딩 실습(프로토타입 도출까지) 위주의 교육"** — 평가실 수요 2가지를 모두연 가용시간을 고려해 커리큘럼에 반영:

1. **평가기획 단계 효율화** — 표준화 수준이 높은 업무의 자동화
   - 사업 기본계획 문서 → 표준화된 '평가계획' 문서 골격 자동 생성 (반복·정형 업무)
   - 실습용 샘플: 사업 기획 문서 + 평가 기획 문서 쌍 **3세트 제공 가능** (HWP → PDF 변환 가능)
2. **평가산출물(보고서) 대외서비스 이용 활성화** — 평가결과 이용/조회를 용이하게
   - 현행 '평가 정보 플랫폼'은 HTML 웹페이지·PDF 아카이브 중심, 교훈 조회 기능 불편
   - 지식 관리 체계(PDF → AI 친화적 md 변환·연결) + 검색 가능한 대시보드 **프로토타입** 제작 (예: 보고서 ~100개 처리 후 사업성 검토 → 정식 과업 확장)

미팅에서 합의된 방향:
- 참가자 7인이 **각자 업무 기반 MVP를 발굴·제작**하는 워크숍형 (작년 '아이펠톤'의 발전형)
- 흐름: ① AI를 에이전트로 다루는 기초 역량 → ② 개인별 MVP 제작
- **Claude Code + 하네스 개념** 교육, **GitHub에 작업 파이프라인 관리** → 로컬 서버 24시간 초기화 제약에도 업무 누적·팀 역량 표준화
- 구독제 기반 비용 효율 운영 방안 (API 과금 대비) 안내 포함

### 3차 — 평가방법론 (외부 평가자 20인, FGI)
- **실습 위주의 FGI 방법론 교육** — AI 활용 FGI 워크플로우 (설계 → 전사 → 분석 → 보고)
- v1 요구조건의 FGI 교육 내용을 4시간 단일 회차·평가자 대상으로 재구성
- OECD-DAC 평가기준 연계, 데이터 윤리·비식별화 원칙 포함

## 기술 환경 · 제약 (미팅 확인)
- 업무망 분리, 외부 클라우드 접근 제한, 업무 PC 프로그램 설치 불가 (현재 웹 기반 Genspark만 사용)
- 로컬 서버 24시간 주기 초기화 → 작업물 누적 안 됨 (GitHub 파이프라인으로 대응)
- **교육 시 보안 미적용 교육용 노트북 대여 사용** — 데스크탑 AI 설치·클라우드 접속 자유
- 실습 데이터: 비식별·샘플 데이터 원칙

## 별도 트랙 (교육 외 — 참고)
- **AI 품질검토 툴 컨설팅**: 평가실 민성 전임이 개발한 AI 품질검토 툴(Genspark 에이전트 + 루브릭 프롬프트) — 팀 전체 교육이 아닌 **담당자-전문가 1:1 별도 컨설팅**으로 진행 합의. 교육 실습 과제로 연계 고도화 가능성 있음.
