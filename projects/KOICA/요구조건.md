### 교육 내용 (7/22 회의 논의 중심)

평가실 수요 2가지를 **하나의 통합 흐름**으로 묶음 (회의 합의: 비용 절감 + 주제 간 연계 학습 효과):

1. **평가기획 단계 효율화** — 표준화 수준이 높은 업무의 자동화
   - 사업 기본계획 문서 → 표준화된 '평가계획' 문서 골격 자동 생성
   - 실습 샘플: 사업기획 + 평가기획 문서 쌍 **3세트 제공 가능** (HWP → PDF 변환)
2. **평가산출물(보고서) 대외서비스 이용 활성화** ← **최종 수렴 산출물**
   - 지식 관리 체계: PDF 보고서 → AI 친화적 md 변환·메타정보·연결성 부여 (예: 보고서 ~100개 프로토타입 → 사업성 검증 후 정식 과업 확장)
   - 그 위에 **평가결과·교훈 검색 대시보드 프로토타입** 구축

회의 합의 방향:
- 참가자 7인이 **각자 업무 기반 MVP를 발굴·제작**하는 워크숍형 (작년 '아이펠톤'의 발전형)
- 흐름: ① AI를 에이전트로 다루는 기초 역량 → ② 업무 자동화 도구(MVP) 제작
- **Claude Code + 하네스·스킬 개념** 교육, **GitHub 파이프라인 관리** → 로컬 서버 24시간 초기화 제약에도 업무 누적·팀 표준화
- 구독제 기반 비용 효율 운영 (API 종량 과금 대비) 안내 포함

## 예산 · 운영 조건
- 고객 제시 예산 상한 ₩10,000,000은 **당초 3회(FGI 포함) 기준** — FGI 분리에 따른 예산 배분은 협의 필요
- 교육 다과비, 보조인력 1~2인(단순 행사진행 지원) 포함 요청
- 미팅 시 논의 단가 레벨: 강사비 시간당 40~50만원, 과정 설계비 과정당 30만원 (참고)
