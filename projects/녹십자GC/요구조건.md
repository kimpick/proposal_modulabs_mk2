- **담당자**: 노상연 ([고객담당자 이메일 비공개])
- **PM**: 강은숙(모두연) / 연구원: 영광 김

## 배경
- 4월 AX Unit 신설 (기존 디지털혁신팀 소속 → 독립)
- 플랫폼팀도 신설, 1차 프로토타입 이후 내부 고도화 가능
- 작년: 단타성 교육으로 종료, 사례가 개인 차원에 머무름
- 올해: 멤버십 형태로 지속적 운영, 조직적 차원의 성과 도출 목표
- 사내 AI 도구: HeyGC (GWS 비즈니스 모델)
- 환경: MS 365, 사내 보안

## 교육 요청 (3개, 각각 개별 PDF)

### ① 임원 대상 AX 교육 (module 템플릿)
- **형태**: 3시간 × 3회, 워크샵 형태
- **일정**: 6월말(1회) → 7~8월(2회) → 10~11월(3회)
- **도구**: Codex Desktop
- **대상**: 대표 포함 임원진
- **핵심 니즈**:
  - 의사결정자에서 거버넌스로 확장되는 여정
  - 1회차: AI 전환 인식 + 바이브코딩 맛보기 + 본인 업무 문제 정의 워크샵
  - 2회차: 멤버십 산출물 리뷰 + 본인 업무용 AI 도구 고안 워크샵
  - 3회차: 해커톤 결과 리뷰 + 실제 활용 거버넌스 수립
- **실습 비중**: 시연/실습 너무 높으면 안 됨. 워크샵 형태 (본인 문제 정의, 업무 정의)
- **강사진**: 2~3분 추천 필요

### ② AX 멤버십 교육 (module 템플릿)
- **형태**: 7시간 × 4회
- **일정**: 6~7월(1~2회) + 9월(3~4회)
- **도구**: OpenCode, OhMyAgent
- **대상**: 30명 (129명 지원 중 과제로 선발), 각 실/본부 대표
- **필수 포함**:
  - 1회차 앞부분: 디자인씽킹 4시간 (유닛장 필수 요청)
  - 4회차: 미니 해커톤 4시간
- **과제 방향**: 자동화, 데이터 취합, 파이썬, 사내 AI 챗봇, 루틴 작업
- **환경**: MS 365 (구글 시트 불가)
- **산출물**: 실제 사용 가능한 AI 도구/솔루션
- **연계**: 30명 → 10월 전사 해커톤 코치 → 연말 결과물 발표

### ③ 전사 해커톤 (module 템플릿)
- **형태**: 1일 / 8시간
- **일정**: 10월
- **코치**: 멤버십 30명 + 보조코치 2인
- **형태**: 팀 단위 아이디어빌딩 → MVP → 발표

## 연계 구조 (핵심)
```
임원 1회차 (6월말) → AI 인식 + 바이브코딩 맛보기 + 문제정의
    ↓ 영감/방향 제시
멤버십 1~2회차 (6~7월) → 디자인씽킹 + AI 심화
    ↓ 산출물 공유
임원 2회차 (7~8월) → 멤버십 산출물 리뷰 + 업무용 도구 고안
    ↓ 
멤버십 3~4회차 (9월) → 바이브코딩 + 미니해커톤
    ↓ 30명이 코치로 투입
전사 해커톤 (10월)
    ↓ 결과 공유
임원 3회차 (10~11월) → 해커톤 결과 리뷰 + 거버넌스 수립
    ↓
연말 결과물 발표
```
