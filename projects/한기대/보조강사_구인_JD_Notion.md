## 🤝 보조강사 역할 (퍼실리테이터 중심)

### 핵심 미션: **"낙오자 없는 실습장"**

1. **먼저 다가가는 질의응답**
   - 손을 들기 전에 먼저 다가가서 "지금 잘 따라오시고 계신가요?"를 묻습니다.
   - 뒤쪽 자리·조용히 계신 분을 우선적으로 챙깁니다.
   - 같은 질문이 반복돼도 동일한 친절함을 유지합니다.

2. **실습 환경 세팅 선제 지원**
   - 구글 계정 로그인 · Gemini / NotebookLM / Google AI Studio 접속 이슈 대응
   - 브라우저·권한·확장프로그램 트러블슈팅
   - 바이브코딩 실습 도구(Cursor, Claude Code 등) 설치·실행 지원
   - **주강사가 본 강의 흐름에 집중할 수 있도록**, 환경 이슈는 보조강사가 흡수

3. **실습 진행 서포트**
   - 실습 타임마다 자리를 돌며 진도 지연자 발굴
   - 프롬프트 작성 · Gem 설계 · HTML 슬라이드 제작 산출물 즉석 코칭
   - 4일차 교육용 웹앱 개발 구간에서 코드 리뷰 및 디버깅 지원

4. **조별 프로젝트 멘토**
   - 3~5인 1조 단위 프로젝트(강의 슬라이드 · 교육용 웹앱) 멘토링
   - 5일차 최종 발표 피드백 제공

> 💡 키워드 한 줄: **"강의자가 아니라, 실습장을 함께 살리는 퍼실리테이터."**

## ✅ 자격 요건 (필수)

1. **생성형 AI 실무 사용 경험**
   - Gemini / ChatGPT / Claude 등 주요 생성형 AI를 일상적으로 사용
   - 프롬프트 엔지니어링의 기본 개념(역할 부여, 컨텍스트 설계, Few-shot 등)을 이해하고 있을 것

2. **웹 개발 기초**
   - HTML / CSS / JavaScript 수준의 코드를 읽고 수정할 수 있을 것
   - 바이브코딩(Cursor, Claude Code, v0 등 AI 코딩 도구 활용) 경험 또는 학습 의지

3. **퍼실리테이터 마인드셋** ★가장 중요
   - **먼저 다가가는主动性** — 기다리지 않고 먼저 질문을 건넬 수 있을 것
   - 낙오자를 민감하게 포착하고 다가갈 수 있는 관찰력
   - 비개발자/교사 대상에게 친절하고 명확하게 설명할 역량

4. **일정 커밋**
   - **5일 전일정(07.20 ~ 07.24) 참석 가능** 필수
   - 사전 OT(07월 중 1회, 1~2시간) 참석 가능자
   - 강남 출근 가능자

## 💡 왜 이 교육이 의미 있을까요?

- **직업계고 교사 30여 명에게 직접 AI를 전파**하는 자리입니다. 교사 한 명이 수백 명의 학생으로 뻗어나가는 파급력.

- 모두의연구소가 자랑하는 **QA-Prompting · Gem 운영 설계 · 바이브코딩** 노하우를 실전에서 가르치는 자리.
- 강사 네트워크에 합류하시면 이후 다른 기업교육·스터디·콘텐츠 제작 기회도 함께 열립니다.
