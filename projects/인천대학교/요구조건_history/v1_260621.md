## 교육 철학
- **바이브코딩 중심** — 자연어로 AI에게 코딩을 지시하는 방식을 모든 과정의 핵심으로
- **AX 기초역량 프레임워크** 기반 설계
  - 프롬프트 엔지니어링 → 컨텍스트 엔지니어링 → 하네스 엔지니어링 진행
- 이론 + 실습 + 프로젝트 기반 학습
- 대상별 난이도 차등 적용 (학부생: 입문, 대학원생: 심화+풀스택)
- **LangChain 실습 연계**: 프롬프트 엔지니어링 기법을 LangChain으로 구현하는 실무 체험
- **도구 레벨링**: 초급(UI) → 중급(IDE/에이전트) → 고급(CLI) 단계적 도구 승격 (A안)
- **개발 레이어 누적**: AI핵심 → 프론트엔드 → 백엔드 → DB → 보안, 하나씩 레이어를 더해가며 풀스택 앱 완성 (캠프)
