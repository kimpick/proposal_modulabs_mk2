## 프로그램 구성 (2개 제안서)

### 제안서 1: 학부생 세미나 — 바이브코딩 입문 (가을학기, 캡스톤 연계)
- **대상**: 비전공자 1학년 30명 (동북아국제통상물류학부, 4~6명 × 6~8팀)
- **형태**: 캡스톤 형식 강의(1학점 15시간) 중 모두연 담당 **3시간 × 2회 = 총 6시간**
- **일정**: 9월 1일 개강 / 9월 8~10일 주간 중 요일 확정, 16~19시 (최대)
  - 1회차(3H): 2~4주차 — Toy Project
  - 2회차(3H): 8~10주차 — Advanced Project (6주차에 확정된 캡스톤 주제 데이터로 실습)
- **커리큘럼 방향**:
  - **1회차 (3H)**: 대학생 버전 바이브코딩을 위한 **핵심 기술 레이어 실습** — Codex 원턴(플랜→자동모드→실행→커밋)으로 웹 서비스(프론트·백엔드) 제작, Cloudflare 배포, GitHub 푸시
  - **2회차 (3H)**: **데이터 분석 특화 바이브코딩** — MySQL 기반 DB 실습, 물류 데이터(자전거 공유 데이터 등)·Kaggle 데이터셋 분석 → 보고서 작성
- **제외**: 앱 서비스 제작(시간 부족으로 패스)
- **견적**: 총 330만원 협의 (모두연 계획안 기준으로 산출, 두 벌 제출)

### 제안서 2: 대학원생 캠프 — 기초 + 심화 (여름방학)
- **대상**: 대학원생 (전공 무관, 최대 30명)
- **형태**: **기초 6시간 + 심화 6시간 = 총 12시간** (각 과정 독립 운영 가능, 강의계획서 2벌)
- **일정**: 8월 18일 ~ 24일 중 (방학 중, 기숙사 학생 참여 가능)
- **커리큘럼 방향**:
  - **기초 (6H)**: 활용 실습 중심 — 바이브코딩을 위한 **핵심 기술 레이어**를 6시간 다루고, 풀스택 원턴(프론트→백엔드→DB→배포)을 돌며 **본인만의 실습 결과물** 완성 (기초 웹서비스 기반)
  - **심화 (6H)**: 바이브코딩 결과물의 **서비스 레벨** 고도화 — 로그인·회원 관리, 백엔드 구조화, 데이터베이스, 보안, 결제 붙이기
- **제외**: LangChain (회의에서 제거 확정), 해커톤식 결과 경쟁 (원턴 반복 경험이 목적)
- **견적**: 각 과정 330만원 (세금 포함) × 2 = **총 660만원** (송상화 교수 330만원/과정 승인)

## 교육 철학
- **바이브코딩 중심** — Codex 원턴 워크플로우(플랜→자동모드→실행→커밋)를 모든 과정의 뼈대로
- **기술 허들은 낮추되 경험은 넓게** — 난이도를 낮추고 풀스택 전 과정을 원턴으로 도는 경험 우선
- **요소 기술 명시 교육** — GitHub, 배포, DB 등은 문제 해결 과정이 아닌 요소 기술로 직접 가르침 (SK 그룹 워크숍 경험 반영: 비전공자는 기본 개념 인식이 관건)
- 대상별 차등: 학부생(입문·캡스톤 연계) / 대학원생(풀스택 경험 + 서비스 레벨 심화)

## 예산 범위
- 제안서 1 (학부생 세미나): 총 330만원 협의 (6H)
- 제안서 2 (대학원생 캠프): 과정당 330만원(세금 포함) × 2 = 660만원 (12H)
- 강사비 + 설계비 + 운영비 포함 기준

## 참고사항
- 강의계획서는 기본/심화 각 6시간으로 나눠 별도 작성 (대학 내부 입력 마감: 3주 이내)
- 유연학기제 몰아치기(3시간×3주 연속)는 불가 — 기본 틀 내 운영
- 학부생 6주차: 캡스톤 프로젝트 주제가 확정되면 모두연에 공유 → 해당 주제 데이터로 2회차 DB 실습 구성
- 해커톤(구 제안서 3)은 올해 보류 — 캠프 수료자 대상으로 대학 자체 운영 가능하다는 의견
