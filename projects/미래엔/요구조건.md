→ **Claude Code Agent 중심으로 확정**

**근거**:
- 미래엔이 이미 Claude Max를 실무에서 사용 중 → 즉시 활용 가능

**제외 도구**: Cline, OpenClaw, NanoClaw (오픈소스 대안은 필요 시 짧은 사례 스터디로만 언급)
