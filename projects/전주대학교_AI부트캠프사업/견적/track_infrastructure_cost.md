# 전주대학교 AI 부트캠프 트랙별(ND1, ND2, ND5) 상세 인프라 비용 산출안

기획 문서(`context.md`)에 명시된 트랙별 구성 모듈을 분석하여, 각 교육 과정의 실제 기술적 요구사항에 맞춘 차등화된 인프라 자원 및 재료비를 산출했습니다. (기준: 수강생 30명, 모듈당 15시간 $\times$ 4개 = 총 60시간)

---

## 1. ND1: 피지컬 AI 핵심 기초
**구성 모듈:** ① LLM 기초 / ⑦ 로봇공학 기초 / ⑧ ROS2 실습 / ⑬ 물리시뮬레이션 기초
**인프라 특징:** 기초 개념과 경량 실습 위주. 고사양 GPU보다는 안정적인 공통 실습 환경(Web-IDE)과 가벼운 단위의 시뮬레이션 환경이 필요합니다.

### 항목별 범주화 및 비용 산출
*   **클라우드 사용료 (기본 Web-IDE 및 경량 가상머신):** 
    *   단가: 시간당 약 1,000원
    *   비용: 1,000원 $\times$ 60시간 $\times$ 30명 = **1,800,000원**
*   **AI 툴 사용료 (기초 API 실습):**
    *   단가: 인당 10,000원 (LLM 기초 호출용)
    *   비용: 10,000원 $\times$ 1식 $\times$ 30명 = **300,000원**
*   **기타 구독료 (AI Augmented Coding 등 학습보조):**
    *   기준: 인당 월 30,000원
    *   비용: 30,000원 $\times$ 1개월 $\times$ 30명 = **900,000원**
*   **총 예상 인프라 재료비: 3,000,000원**

---

## 2. ND2: 합성 데이터 및 멀티모달 데이터셋 구축
**구성 모듈:** ⑭ Isaac Sim 입문 / ⑯ 합성데이터 파이프라인 / ⑨ 로봇 비전·인지 / ④ 멀티모달 LLM(VLM)
**인프라 특징:** NVIDIA Isaac Sim 구동 및 비전 AI 훈련을 위해 **가장 높은 사양의 GPU(RTX 4090/A6000 이상)** 환경이 집중적으로 요구되며, 대규모 합성 데이터 생성을 위한 스토리지 연동이 필수적입니다.

### 항목별 범주화 및 비용 산출
*   **클라우드 사용료 (고성능 GPU VDI 및 스토리지 연동):** 
    *   단가: 시간당 약 4,000원 (고사양 인스턴스)
    *   비용: 4,000원 $\times$ 60시간 $\times$ 30명 = **7,200,000원**
*   **AI 툴 사용료 (멀티모달 오픈 API 일부 활용):**
    *   단가: 인당 15,000원
    *   비용: 15,000원 $\times$ 1식 $\times$ 30명 = **450,000원**
*   **기타 구독료 (AI Augmented Coding 등 학습보조):**
    *   비용: 30,000원 $\times$ 1개월 $\times$ 30명 = **900,000원**
*   **총 예상 인프라 재료비: 8,550,000원**

## 3. ND5: 로보틱스 LLM 에이전트 구축
**구성 모듈:** ② Prompt Eng & RAG 심화 / ④ VLM & Grounding / ⑥ 에이전트·플래닝 / ⑫ LLM·로봇 시스템통합
**인프라 특징:** 복잡한 에이전트 파이프라인 구축을 위해 **대규모 상용 LLM API(OpenAI/Claude) 크레딧이 가장 많이 소모**됩니다. 실물 로봇 연계 전 시뮬레이터를 돌리기 위한 중상급 GPU 런타임이 필요합니다.

### 항목별 범주화 및 비용 산출
*   **AI 툴 사용료 (대규모 LLM API 크레딧 - 핵심 재료):**
    *   단가: 인당 60,000원 (RAG, 에이전트 무한루프 테스트 대비)
    *   비용: 60,000원 $\times$ 1식 $\times$ 30명 = **1,800,000원**
*   **클라우드 사용료 (서빙 클러스터 및 중급 GPU 인스턴스):** 
    *   단가: 시간당 약 2,500원
    *   비용: 2,500원 $\times$ 60시간 $\times$ 30명 = **4,500,000원**
*   **기타 구독료 (AI Augmented Coding 등 학습보조):**
    *   비용: 30,000원 $\times$ 1개월 $\times$ 30명 = **900,000원**
*   **총 예상 인프라 재료비: 7,200,000원**
