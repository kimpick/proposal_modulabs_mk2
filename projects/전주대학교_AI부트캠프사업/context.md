## 2. 피지컬 AI 교육 철학 (대면평가 자료 핵심)

### 3축 구조
```
LLM (Brain: 이해·계획·검증)
Robot (Body: 지각·제어·통합)  
Simulation (World: 검증·학습·전이)
```

### 기업이 요구하는 교육 방향 (p.8)
1. **기업 요구사항을 끝까지 달성하는 역량** 중심 교육
2. **기업이 선호하는 산출물 중심** 교육
3. **기업 리스크(환각·안전·지연·재현성)를 직접 다루는** 교육
4. **초급-중급-고급 구조**로 기업이 바로 활용할 수 있는 인재 양성
5. **교육-실증-채용**으로 이어지는 연계 구조

## 6. 산출물·평가 기준 체계 (p.23, p.24)

### 기업 관점 핵심 4요소 (산출물 통일 기준)
1. **재현 가능성**: 버전·설정값·실행 절차 정리 → 제3자 동일 재실행 가능
2. **성능 지표**: 정확도/시간/지연 등 수치 비교로 결론 확인
3. **문제 해결 과정 체계**: 로그·실험 기록 기반 원인 분류 → 반복 방지
4. **운영 안정·안전**: 폴백 동작·안전 점검·모니터링·운영 절차서 마련

### 역량 인증 체계 (Lv1~Lv5)
| 레벨 | 명칭 | 판정 기준 |
|------|------|---------|
| Lv1 | 기초 | 개념 이해, 실행은 가능하나 결과 증빙 미흡 |
| Lv2 | - | 기능 구현/개선 경험, 비교분석 및 성능지표 측정 기준 설정 |
| Lv3 | 현장형 | 재현/디버깅, 오류 원인 설명 가능 (재현 절차 포함) |
| Lv4 | - | 실험 설계·단독 완수, 운영 가능한 제품 수준 |
| Lv5 | - | 성능지표 개선·운영 위험요인 통제, 재사용/확장 가능한 체계 구축 |

> **기업 채용 기준**: Lv3(기본) 이상, Lv4(P+) 이상 인증 → 채용 전형 서류/1차 면제 또는 가점

## 10. 모두의연구소 담당 패키지 방향

### 확정 구조 (엑셀 기준)
```
[AI 기초] 초급, 45H — 모듈 ①⑦⑧⑬
  → ① LLM/Transformer 기초 (20H) — 핵심 확대
  → ⑦ 로봇공학 기초 (10H) — 맥락 이해 수준
  → ⑧ ROS2 실습 (10H) — 통신 구조 이해 수준
  → ⑬ 물리시뮬레이션 기초 (5H) — 개론 수준

[ND5] 고급, 90H — 모듈 ②④⑥⑫ (AI 기초만 이수하면 직행 가능)
  → ② Prompt Engineering & RAG 심화 (18H)
  → ④ 멀티모달 LLM(VLM) & Grounding (20H)
  → ⑥ 에이전트·플래닝·정렬(RLHF/Preference) (22H)
  → ⑫ LLM·로봇 시스템통합: Task→Skill→Safety (30H) — 캡스톤 포함
```

### 모두연 담당 스토리라인
> **"LLM을 처음 배우고(AI 기초), LLM으로 로봇을 움직이는 데까지(ND5)"**  
> 피지컬 AI 부트캠프의 시작(초급)과 완성(고급)을 모두의연구소가 담당하는 구조  
> AI 기초에서 ND5로 퍼널 없이 직행 — 수강생 유입 허들 최소화

### ND5 직행 설계 핵심 전략
- **①(LLM/Transformer 기초)에 20H 투자**: ②④⑥을 위한 선수 역량 완전 확보
- **⑦⑧⑬은 "맥락 이해" 수준으로 압축**: 로봇 전문가 양성 아닌 LLM-로봇 연결 이해
- **ND5 내부 난이도 점층적 설계**: ②(RAG 심화) → ④(VLM) → ⑥(에이전트) → ⑫(통합) 순서로 자연스러운 난이도 상승
- **산출물 중심 학습**: 각 모듈마다 Git 포트폴리오급 산출물 → 역량 인증 Lv3~Lv4 달성

### 선택 근거
- **LLM 역량 직결**: 모두연 핵심 교육 영역 (LLM, RAG, 에이전트)과 완전 일치
- **레퍼런스 연결**: 한국공학대 4일차 커리큘럼 (VLA, SmolVLA, LLM-로봇 통합)과 직접 연결
- **기업 수요 최상위**: 기업 필요도 조사에서 ②④⑥⑫ 모두 상위권
- **ND5 선택 이유**: 소프트웨어/LLM 중심으로 모두연 강점 최대 활용 (하드웨어 집약적 ND 제외)
