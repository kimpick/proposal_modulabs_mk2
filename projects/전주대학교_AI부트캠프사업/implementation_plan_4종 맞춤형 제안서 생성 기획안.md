# 4종 맞춤형 제안서 생성 기획안 (종합 / ND1 / ND2 / ND5)

기존 통합본 `content.json` 하나에서 **종합 제안, ND1 단독 제안, ND2 단독 제안, ND5 단독 제안** 등 총 4개의 맞춤형 제안서를 시스템적으로 분리(Extraction)하여 추출해 내는 파이프라인 기획안입니다. 

## User Review Required
> [!IMPORTANT]
> - 4개의 제안서를 개별 수작업으로 만들게 되면 나중에 커리큘럼이 1개라도 수정될 경우 4곳을 동시에 고쳐야 하는 불상사가 생깁니다.
> - 따라서 하나의 마스터 `content.json`을 유지하되, **파이프라인 스크립트(`generate_proposals.py`)가 1. 마스터 데이터 로드 ➔ 2. 각 시나리오별 불필요 정보 필터링 및 서사(기승전결) 치환 ➔ 3. 템플릿 주입 ➔ 4. 4개의 PDF 자동 생성** 과정을 단번에 수행하도록 구성하고자 합니다. 이 방식에 동의하시나요?

## 🚀 제안서별 시나리오 고도화 전략 (Data Extraction Logic)

### 1. 종합 제안서 (기본값)
- **Target**: 마스터 플랜(180H) 전체 조망을 원하는 핵심 의사결정권자.
- **Data**: 현재 완성된 `content.json` 마스터 데이터를 로드. 
- **⚠️ 중요 변경사항**: 종합 제안서에서는 지루한 세부 커리큘럼 표(tracks 모듈 테이블)를 통째로 숨깁니다. 대신 **[ND1 핵심 플로우], [ND2 핵심 플로우], [ND5 핵심 플로우] 등 3개의 시각화된 시나리오 파이프라인 블록**을 새롭게 추가하여 전체 커리큘럼의 스토리를 압도적으로 전달합니다.

### 2. [ND1] 피지컬 AI 핵심 기초 단독 제안서
- **Target**: 물리/하드웨어 기초와 오픈소스 로보틱스 생태계(ROS2, MuJoCo) 핵심 역량을 습득하려는 입문/중급자.
- **데이터 필터링 지침**:
  - `Tracks`: ND1 배열 데이터 1개만 노출.
  - `ND Flow`: **ND1 전용 학습 흐름표(LLM ➔ 기구학 ➔ ROS2 ➔ 시뮬레이션 E2E)**만 노출.
  - `Info`: 총 기간 "60H", 대상 "입문자/비전공자", 키워드 "ROS2 / 로봇 기구학 / 파인튜닝".
  - `Intro`/`Objective`: ND1만의 기승전결(LLM ➔ 시뮬레이션 환경 제어 단대단) 완결성 부여.
  - `Hidden Data`: ND2, ND5 전용 Flow 시각화표 및 타 트랙 데이터 자동 파괴 (HTML 렌더에서 숨김).

### 3. [ND2] 합성 데이터 및 시각 인지 단독 제안서
- **Target**: 로봇 하드웨어 없이 PC 환경에서 고품질 데이터 파이프라인(SDG)과 시각 인식(VLM, Object Detection) 역량을 쌓으려는 데이터/컴퓨터비전 지향 학습자.
- **데이터 필터링 지침**:
  - `Tracks`: ND2 배열 데이터 1개만 노출.
  - `ND Flow`: **ND2 전용 학습 흐름표(Isaac Sim 구축 ➔ 합성 라벨링 파이프라인 ➔ 비전 파인튜닝 ➔ VLM 접목)**만 노출.
  - `Info`: 총 기간 "60H", 키워드 "합성 데이터(SDG) / YOLO11 / VLM 공간지능 / Isaac Sim".
  - `Intro`/`Objective`: 소프트웨어(가상 공간 데이터 생성) 기반 데이터 연금술 파이프라인 소개.
  - `Hidden Data`: 타 과정 데이터 파괴.

### 4. [ND5] 로보틱스 LLM 에이전트 구축 단독 제안서
- **Target**: LLM을 활용한 다단계 플래닝(Agent System)이라는 고수익 하이엔드 아키텍처를 마스터하고픈 고급 학습자.
- **데이터 필터링 지침**:
  - `Tracks`: ND5 배열 데이터 1개만 노출.
  - `ND Flow`: 기존에 잘 구축된 `nd5_flow` (M2 ➔ M4 ➔ M6 ➔ M12) 시각화표만 노출.
  - `Info`: 총 기간 "60H", 대상 "AI 기초/LLM 활용 유경험자", 키워드 "LLM Agent / LangGraph / RAG".
  - `Hidden Data`: `design_logic` 등의 타 과정 비교 논리표 파괴.
