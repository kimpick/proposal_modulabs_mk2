AI 업무 활용 & 자동화

사내 비개발자 대상 (프로그래밍 경험 불필요)

엑셀·회의록·보고서 등 반복 업무를 자연어 지시로 Qwen Code에 넘기고, 나만의 AI 업무 비서를 완성

04

예상 산출물

교육 종료 후 즉시 사내 적용 가능한 결과물

개발자 트랙

  • 사내 시스템 연동 MCP 서버 — 소속 팀에 이식 가능한 구조
  • 멀티 도구 Agent 코드베이스 — 도구 라우팅 스키마와 로깅 포함
  • 개인 업무 자동화 Agent 1건 — 종료 후 즉시 시범 적용

비개발자 트랙

  • 업무 자동화 프롬프트 라이브러리 — 재사용 가능한 프롬프트 모음
  • Qwen Code 기반 자동화 스크립트 — 직접 코딩 없이 작동하는 결과물
  • 개인 AI 업무 비서 — 본인 업무 스타일·양식 반영, 즉시 시범 운영
05

회의 협의 · 다음 단계

오늘 함께 확정하면 좋을 항목

1
개강일 확정

KCB 일정에 맞춰 개강일을 협의·확정합니다. (화·수 15:00–17:00, 3주 5회차 기준)

2
트랙 구성 · 정원

개발자 / 비개발자 트랙별 운영 여부와 회차당 인원(40–50명)·총 정원을 확정합니다.

3
실습 인프라 점검

Qwen Code 호출 권한·API endpoint, 1인 1PC(Python 3.10+), MCP 런타임, 사내망 공유 도구(Confluence·GitLab 등)를 점검합니다.

4
강사 구성

트랙별 메인 강사 + 보조 강사 1명 구성을 확정합니다. (비개발자는 초급 대상 운영 권장)

5
견적 · 계약 일정

확정된 트랙·인원 기준으로 견적서 및 계약 일정을 협의합니다.

※ 상기 일정은 강사 섭외 상황에 따라 조정 가능하며, 교육 전 사전 공지드립니다. 모든 실습은 외부 API·클라우드 의존 없이 사내 Qwen Code 폐쇄망에서 재현 가능하도록 설계되었습니다.
