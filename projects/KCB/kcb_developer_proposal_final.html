01과정 소개
본 과정은 LLM 기본 원리와 프롬프트 엔지니어링부터 시작해 Function Call, MCP 서버·Plugin 연동, 멀티 도구 Agent 구축까지 실무 중심으로 다룹니다. 1주차에서 LLM 기초와 프롬프트 엔지니어링으로 기반을 다지고, 2주차에서 MCP 서버 구축과 멀티 도구 Agent를 실습하며, 3주차에서 본인 업무 기반 미니 Agent를 직접 기획·구현·발표합니다. 모든 실습은 사내 Qwen Code 환경과 폐쇄망에서 재현 가능하도록 설계되었으며, 외부 API나 클라우드 의존성 없이 동작합니다.
02교육 목표
  • LLM·Agent·Tool 구조 이해: 토큰, Function Call, MCP Protocol, Agent Loop의 작동 원리를 코드 레벨에서 이해하고 설명할 수 있는 수준에 도달합니다.
  • MCP·Plugin 연동 능력: MCP 서버를 구성하고 Plugin 아키텍처로 사내 시스템·DB·API를 Qwen Code가 직접 호출하는 도구로 연동하는 방법을 익힙니다.
  • 멀티 도구 Agent 구현: Function Call과 MCP·Plugin을 조합해 여러 도구를 호출하는 워크플로우를 구축하고, 분기·재시도·로깅까지 운영 가능한 형태로 완성합니다.
  • 개인 업무 Agent 산출: 본인 업무 시나리오를 기반으로 미니 Agent를 직접 기획·구현·발표하여, 교육 종료 후 즉시 배포 가능한 결과물을 만듭니다.
