## 3. 교육 목적

마이스터고 **학생 교육을 위한 교사 역량 강화** — 정보컴퓨터 전공 교사들이 학생에게 가르칠 수 있도록 본인이 먼저 익혀야 하는 차세대 SW 개발 패러다임 학습.

> 핵심: "교사가 먼저 써봐야 학생을 가르친다" — 단순 시연이 아닌 **실제 프로젝트를 끝까지 만드는 경험**이 필요.

## 4. 희망 주제 (3개 영역, Claude 생태계 단일 도구로 진행)

1. **바이브코딩 (Vibe Coding)** — Claude + Claude Code로 자연어 협업 코딩 마스터
2. **고급 프롬프트 엔지니어링 (Advanced Prompt Engineering)** — Claude 단일 도구로 깊이 있는 프롬프트 설계
3. **하네스 엔지니어링 (Harness Engineering)** — Claude Code + MCP로 에이전트 환경 직접 구성

## 5. 대상 분석 (정보컴퓨터 교사 특성)

| 강점 | 약점/니즈 |
|---|---|
| 프로그래밍 기초 탄탄 (변수·함수·OOP·자료구조 이해) | AI 코딩 도구 실무 사용 경험 부족 |
| Git·CLI 등 개발 환경 익숙 | 프롬프트 설계를 "스킬"이 아닌 "감"으로 사용 |
| 학생에게 "왜 이렇게 동작하는가"를 설명해야 함 → **원리 이해 깊이 필요** | 하네스 엔지니어링 같은 최신 패러다임 노출 부족 |
| 학생들이 이미 AI 코딩 도구를 쓰고 있어 따라잡아야 함 | 학교 환경(인터넷·계정·교실)에서 적용 가능한 실습 설계 필요 |

→ **개발자 트랙의 깊이 + 교실 적용성** 동시 필요.

## 6. 도구 정책: Claude 생태계 단일화 (v2)

본 과정의 모든 실습은 **Anthropic Claude 생태계**로 단일화합니다.

### 사용 도구
| 도구 | 용도 |
|---|---|
| **Claude (Sonnet 4.6 / Opus 4.7)** | 대화형 코드 생성·리뷰·디버깅 |
| **Claude Artifacts** | 풀스택 웹앱·HTML/SVG·React 컴포넌트 즉시 미리보기 |
| **Claude Code (CLI)** | 터미널 에이전트, 코드베이스 직접 수정, 자동화 |
| **Claude Projects** | 컨텍스트 누적 (수업 자료·코드베이스 사전 주입) |
| **CLAUDE.md** | 프로젝트별 규칙·지식을 에이전트에 주입 |
| **Slash Commands** | 반복 작업을 슬래시 커맨드로 자동화 |
| **Claude Skills** | 재사용 가능한 작업 패키지 |
| **MCP (Model Context Protocol)** | 외부 도구·시스템 연결 표준 (Anthropic 발표) |

### 단일화의 근거
- **깊이 우선:** 한 도구를 깊게 마스터하면 다른 도구로의 전이가 쉽다. 20시간을 여러 도구에 흩뿌리지 않음.
- **표준 환경:** MCP는 Anthropic이 발표한 개방 표준 — 하네스 엔지니어링 학습에 가장 정합적.
- **학교 운영성:** 학교 IT 입장에서 라이선스·계정·보안 정책 관리가 단순해짐 (1개 벤더로 통일).
- **에이전틱 코딩 정렬:** Claude Code는 현재 에이전틱 코딩의 표준 CLI 중 하나 — 학생 교육에도 동일 도구로 확장 가능.

## 7. 산출물 방향

교사 1인당 다음을 본인 손으로 완성:

1. **바이브코딩 MVP** — Claude Artifacts로 만든 수업 보조 도구 (퀴즈 자동 채점기, 학생 진도 트래커 등)
2. **개발자용 고급 프롬프트 라이브러리** — 코드 리뷰·리팩토링·디버깅용 Claude 프롬프트 템플릿 세트
3. **하네스 셋업** — Claude Code 에이전트 환경 (CLAUDE.md, 슬래시 커맨드, MCP 연결)
4. **교실 적용 시나리오** — 본교 학생에게 어떻게 가르칠지 미니 수업 설계안
