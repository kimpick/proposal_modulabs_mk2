## 3. 교육 목적

마이스터고 **학생 교육을 위한 교사 역량 강화** — 정보컴퓨터 전공 교사들이 학생에게 가르칠 수 있도록 본인이 먼저 익혀야 하는 차세대 SW 개발 패러다임 학습.

> 핵심: "교사가 먼저 써봐야 학생을 가르친다" — 단순 시연이 아닌 **실제 프로젝트를 끝까지 만드는 경험**이 필요.

## 4. 희망 주제

1. **바이브코딩 (Vibe Coding)** — AI와의 자연어 협업으로 코드를 만드는 새로운 개발 방식
2. **프롬프트 엔지니어링 (Prompt Engineering)** — 개발자 관점의 고급 프롬프트 설계
3. **하네스 엔지니어링 (Harness Engineering)** — AI 에이전트가 실제로 일하도록 환경/도구/컨텍스트를 설계하는 신생 개발자 역량

## 5. 대상 분석 (정보컴퓨터 교사 특성)

| 강점 | 약점/니즈 |
|---|---|
| 프로그래밍 기초 탄탄 (변수·함수·OOP·자료구조 이해) | AI 코딩 도구(Cursor·Claude Code 등) 실무 사용 경험 부족 |
| Git·CLI 등 개발 환경 익숙 | 프롬프트 설계를 "스킬"이 아닌 "감"으로 사용 |
| 학생에게 "왜 이렇게 동작하는가"를 설명해야 함 → **원리 이해 깊이가 필요** | 하네스 엔지니어링 같은 최신 패러다임에 대한 노출 부족 |
| 학생들이 이미 AI 코딩 도구를 쓰고 있어 따라잡아야 함 | 학교 환경(인터넷·계정·교실)에서 적용 가능한 실습 설계 필요 |

→ **비개발자용 "AI 활용 입문"이 아니라, 개발자 트랙의 깊이 + 교실 적용성**이 동시에 필요.

## 6. 산출물 방향 (제안)

교사 1인당 다음 4종 산출물을 본인 손으로 완성:

1. **바이브코딩 MVP** — 본인 수업 보조 도구 (퀴즈 자동 채점기, 학생 진도 트래커 등)
2. **개발자용 고급 프롬프트 라이브러리** — 코드 리뷰·리팩토링·디버깅용 프롬프트 템플릿 세트
3. **하네스 셋업** — Claude Code/Cursor 에이전트 환경 구성 (CLAUDE.md, 슬래시 커맨드, MCP 연결)
4. **교실 적용 시나리오** — 본교 학생에게 어떻게 가르칠지 미니 수업 설계안
