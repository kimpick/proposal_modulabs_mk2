제조 DX·AI 교육
데이터 인프라 이해에서 AI 활용 판단까지

진행 중인 과제의 성패를 가르는 데이터 인프라의 상태를 진단하는 것에서 시작해, 예측 모델의 원리와 AI의 한계를 이해하고, 사내 문서와 데이터를 AI가 활용할 수 있는 형태로 구조화해 업무에 적용하기까지를 하나의 흐름으로 학습합니다.

작성 · 모두의연구소 기업교육팀 일자 · 2026.08.13 범위 · 임원 53명 · 오프닝세션 1회 + 본교육 16회 (총 17회 34시간)
01 / 배경

과제 인식

진행 중인 과제의 성패는 데이터 인프라가 가릅니다

제조 현장의 데이터는 설비·공정·품질 시스템에 나뉘어 축적됩니다. 어떤 데이터가 어떤 형태로 남아 있는지 확인되지 않으면, 추진 중인 AI 과제가 실행 가능한지 판단할 근거가 생기지 않습니다.

모델을 논하기 전에, 우리 데이터의 상태를 먼저 진단합니다.
데이터 레이크를 선행 이해 대상으로 두는 이유입니다. 보유 데이터의 상태가 확인되어야 시계열 분석·가상계측 같은 과제가 계획으로 성립합니다.
데이터의 소재를 모름
설비 로그와 품질 검사 결과가 어느 시스템에 어떤 형태로 남는지 조직별로 파악되지 않습니다
과제 성패가 안 보임
추진 중인 과제가 데이터 요건을 충족하는지 판단할 기준이 없어 투자 결정이 미뤄집니다
AI의 경계가 모호함
무엇이 가능하고 무엇이 아직 어려운지 구분되지 않아 기대와 현실의 간극이 생깁니다
문서 지식이 흩어짐
공정 표준서와 설비 이력이 담당자별로 관리되어 AI가 참조할 수 있는 형태가 아닙니다
02 / 접근

과정의 뼈대

진단에서 시작해 업무 적용까지 네 단계로 완주

앞 단계의 산출물이 다음 단계의 입력이 되도록 설계했습니다. 모델을 직접 구현하지 않고, 데이터와 문서를 판단하는 작업으로 끝까지 따라갈 수 있게 구성했습니다.

STEP 1 · DIAGNOSE
데이터 진단
제조 데이터의 유형과 저장 구조를 이해하고 보유 데이터가 과제를 지탱하는지 판별합니다.
STEP 2 · DEFINE
문제 정의
담당 과제를 회귀·분류 문제로 변환하고 예지보전 시나리오에 필요한 데이터 요건을 도출합니다.
STEP 3 · BOUNDARY
경계와 구조화
ML·DL·LLM의 차이와 한계를 구분한 뒤, 사내 지식을 지식 그래프 초안으로 구조화합니다.
STEP 4 · APPLY
업무 적용
구조화한 지식을 입력으로 분석·리포트 절차와 대시보드를 구성하고 조직 과제로 정리합니다.
도달점은 모델 구현이 아니라 투자와 실행의 판단입니다
각 조직이 예측 모델의 원리·적용 조건·한계를 이해하고, 과제의 실행 가능성을 스스로 판단할 수 있는 상태를 목표로 합니다.

04 / 학습 여정
