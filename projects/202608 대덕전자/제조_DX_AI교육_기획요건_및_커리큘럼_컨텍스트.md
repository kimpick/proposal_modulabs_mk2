## 2. 교육 구조

### 2-1. 오프닝세션

- **1회 / 2시간 / 53명 전원**
- **실습 없음** (강사 시연만)
- 기술 교육이 아닌 **전략적 관점** 세션
- 핵심 메시지: 데이터 레이크의 중요성 + 전사 DB 구축 시 수행 가능한 미래 과제
- 임팩트는 강사 시연으로 확보

> **경위**: 고객은 당초 임원 대상 '실습 바이브코딩'으로 생성형 AI의 자동 데이터 분석 시연을 원했으나, 짧은 시간 내 기술 강의는 비효율적이라는 김영광 연구원 의견에 따라 전략 관점으로 전환 합의.

### 2-2. 본교육

- **4분반 × 4회 = 16회 / 회당 2시간**
- 분반당 10~15명
- **분반 구분 기준 없음 → 4개 분반 모두 동일 커리큘럼 반복**
- 구성 비중: 데이터분석 2회 : AI활용 2회 (**50:50**)
- 이론:실습 = **6:4**

### 2-3. 대상자

**오프닝세션과 본교육의 수강생은 동일 집단(53명)** — 이경주 프로 재확인 사항.
※ 8/11 통화 로그에는 "임원 대상 오픈세션"으로 기록되어 있으나, 이후 재확인으로 대체됨.

## 3. 교육 목표 및 필수 주제

### 목표
각 팀·부서가 **자체적으로 ML/DL 모델의 방향성을 설정**할 수 있게 하는 것.
모델 구현이 아닌 **통계 기반 분석에 대한 이해도 증진**이 도달점.

### 필수 포함 주제
1. **데이터 레이크** (선행 이해 대상)
2. **예지보전**
3. **회귀분석 모델**
4. **Classification 모델**

> 고객 논지: 제조업 특성상 통계적 분석이 중요하며, 이를 위해 데이터 레이크에 대한 선행 이해가 필수. 데이터가 축적되었을 때 예지보전·회귀·분류 모델 수행이 가능해짐.

### 온톨로지 관련
김영광 연구원의 당초 구상(Ontology 기반 데이터셋 구성)이었으나, 고객이 데이터 레이크·통계분석 중심으로 방향 전환 요청 → **축소**. 잔존 여부 미확정.

**네이밍 변경 내역**

- 트랙 "AI활용 2회" → "AI 분석 자동화 실전"

### 설계 근거
- 본교육 8개 모듈 = 1개 분반의 4회차. 이를 4개 분반이 동일하게 반복.
- 회차별 이론 70분 : 실습 50분. 4회 합산 280분 : 200분으로 요청 비중 6:4에 근접.
- **순차 구조**: 1회차에서 "우리 데이터가 어디 있고 분석 가능한가"를 진단하지 않으면 3~4회차 AI 분석 자동화가 성립하지 않음. 데이터 레이크를 선행 이해 대상으로 본 고객 의견 반영.
- 마지막 모듈을 과제 기획 워크숍으로 배치해 "부서별 모델 방향성 설정" 목표를 산출물로 확인. 분반당 10~15명이라 조별 진행 가능.
