## 교육 배경 및 목표

- 제조 현장 데이터가 설비·공정·품질 시스템에 **분산 축적**되어 있어, 부서 단위로 분석 과제를 정의하지 못하는 상태
- **목표**: 각 팀·부서가 **자체적으로 ML/DL 모델의 방향성을 설정**할 수 있게 하는 것
- **도달점**: 모델 구현이 아니라 **통계 기반 분석에 대한 이해도 증진** + 사내 문서·데이터를 AI가 읽을 수 있는 형태로 구조화해 자동화로 연결하는 경험
- 고객 논지: 제조업 특성상 통계적 분석이 중요하며, 이를 위해 **데이터 레이크에 대한 선행 이해가 필수**. 데이터가 축적되어야 예지보전·회귀·분류 모델 수행이 가능해짐

## 교육 구조

### 오프닝세션 (1회 / 2H / 53명 전원)

- **실습 없음 — 강사 시연으로 임팩트 확보** (핸즈온 미포함 확정, 2026-08-12)
- 기술 교육이 아닌 **전략적 관점** 세션
- 핵심 메시지: ① 데이터 레이크의 중요성 ② 전사 데이터가 구조화되었을 때 수행 가능한 미래 과제

> **경위**: 고객은 당초 임원 대상 '실습 바이브코딩'으로 자동 데이터 분석 시연을 원했으나, 짧은 시간 내 기술 강의는 비효율적이라는 김영광 연구원 의견에 따라 전략 관점으로 전환 합의.

### 본교육 (4분반 × 4회 = 16회 / 회당 2H)

- **분반 구분 기준 없음 → 4개 분반 모두 동일 커리큘럼 반복**
- 1개 분반의 4회차 = 8개 모듈. 이를 4개 분반이 동일하게 반복 운영
- 마지막 회차를 **부서별 과제 기획 워크숍**으로 배치해 "부서별 모델 방향성 설정" 목표를 산출물로 확인

### 대상자

**오프닝세션과 본교육의 수강생은 동일 집단(53명)** — 이경주 프로 재확인 사항.

## AI 활용 방향 (확정)

AI 활용 파트는 **범용 프롬프트 활용이 아니라, 사내 문서·데이터를 지식 그래프로 구조화해 자동화·대시보드로 연결하는 흐름**으로 설계합니다.

1. **온톨로지 범위**
   - Copilot·Claude를 활용해 다양한 사내 문서·데이터를 **AI가 읽기 쉬운 지식 그래프로 사전 컴파일링** (LLM 위키 개념 / Google OKF 유사 포맷)
   - 조직 차원의 지식 관리 체계를 세워 **각 프로세스 모듈별 자동화 환경**을 조성
   - 제조 현장에서 **RAG만으로는 업무 적용이 어려운 지점**을 비교하며 온톨로지 개념을 알기 쉽게 설명
2. **활용 산출로 연결**
   - 구축한 데이터 관계망을 기반으로 **대시보드 구성 / 업무 자동화 1종**을 직접 만들어 보는 방향
   - 개인 단위로는 **'세컨 브레인'** 구축 → 담당 업무 자동화로 확장

> **온톨로지 관련 경위**: 고객이 데이터 레이크·통계분석 중심으로 방향 전환을 요청해 온톨로지 비중을 축소했으나, **AI 활용 2회는 온톨로지·지식 그래프 구축과 그 기반의 자동화·대시보드 활용으로 진행**하는 것으로 정리됨 (2026-08-12).

### 실습 수준 (확정, 2026-08-12)

**적극적 기준으로 설계** — Claude Code 기반 LLM 위키(지식 그래프 사전 컴파일링)를 실제로 구축하고, 그 결과물을 자동화·대시보드로 소비하는 수준까지 진행합니다.

- 3회차: 사내 문서·데이터를 AI가 읽기 쉬운 포맷으로 컴파일 → 관계망(지식 그래프) 산출
- 4회차: 3회차 산출물을 입력으로 자동화 1종 또는 대시보드 프로토타입 구축
- **전제**: 사내망에서 파일 업로드·코드 실행이 가능해야 함 → 아직 미확인(§미확인 사항 3). 불가 회신 시 채팅 기반 구조화 실습으로 축소하는 대안을 병행 준비

### 제안서 도구 표기 원칙 (확정, 2026-08-12)

- 제안서 본문·`tech_stack`·`tracks[].tools`에는 **Copilot·Claude만 명시**합니다 (고객이 사내망에서 쓰기로 한 도구).
- Claude Code·LLM 위키는 제품명을 전면에 쓰지 않고 **"Claude 기반 지식 그래프 구축 환경"** 등으로 일반화해 표기합니다 — 비개발자 53명 대상이라 도구명이 진입장벽으로 읽히는 것을 피하기 위함.
- 강사 운영 기준(내부)은 위 '실습 수준'대로 Claude Code·LLM 위키를 사용합니다. **표기와 운영 기준이 다르다는 점을 강사와 사전 정렬할 것.**
