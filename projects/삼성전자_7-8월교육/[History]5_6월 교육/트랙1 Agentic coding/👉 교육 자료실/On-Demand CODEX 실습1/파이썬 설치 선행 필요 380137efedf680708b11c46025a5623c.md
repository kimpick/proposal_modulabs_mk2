# 파이썬 설치 선행 필요

## Python 설치 및 경로 확인

### 1. Windows PowerShell

먼저 Python 실행 여부와 실제 경로를 확인한다.

```powershell
py --version
where.exe py
py -c "import sys; print(sys.executable)"
```

보조 확인:

```powershell
python --version
where.exe python
python -c "import sys; print(sys.executable)"
```

설치가 안 되어 있으면 설치한다.

```powershell
winget install -e --id Python.Python.3.13
```

설치 후 PowerShell을 새로 열고 다시 확인한다.

```powershell
py --version
where.exe py
py -c "import sys; print(sys.executable)"
```

`python` 경로가 안 잡히면 설치 위치를 찾는다.

```powershell
Get-ChildItem "$env:LOCALAPPDATA\Programs\Python" -Recurse -Filter python.exe | Select-Object -First 5 FullName
```

예시 결과:

```
C:\Users\computer\AppData\Local\Programs\Python\Python313\python.exe
```

PATH에는 `python.exe` 파일이 아니라, 그 부모 폴더와 `Scripts` 폴더를 넣는다.

```powershell
$pythonDir="C:\Users\computer\AppData\Local\Programs\Python\Python313"; $scriptsDir="$pythonDir\Scripts"; $userPath=[Environment]::GetEnvironmentVariable("Path","User"); [Environment]::SetEnvironmentVariable("Path", "$userPath;$pythonDir;$scriptsDir", "User")
```

PowerShell을 새로 열고 확인한다.

```powershell
python --version
where.exe python
python -c "import sys; print(sys.executable)"
```

### 2. macOS Terminal

먼저 Python 실행 여부와 실제 경로를 확인한다.

```bash
python3 --version
command -v python3
python3 -c "import sys; print(sys.executable)"
```

Homebrew가 있는지 확인한다.

```bash
brew --version
command -v brew
brew --prefix
```

Homebrew가 없으면 설치한다.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Apple Silicon Mac이면:

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

Intel Mac이면:

```bash
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"
```

Python을 설치한다.

```bash
brew install python
```

설치 후 확인한다.

```bash
python3 --version
command -v python3
python3 -c "import sys; print(sys.executable)"
```

PATH가 안 잡히면 Mac 종류를 확인한다.

```bash
uname -m
```

Apple Silicon이면:

```bash
echo 'export PATH="/opt/homebrew/bin:/opt/homebrew/sbin:$PATH"' >> ~/.zprofile
source ~/.zprofile
```

Intel Mac이면:

```bash
echo 'export PATH="/usr/local/bin:/usr/local/sbin:$PATH"' >> ~/.zprofile
source ~/.zprofile
```

다시 확인한다.

```bash
python3 --version
command -v python3
python3 -c "import sys; print(sys.executable)"
```
