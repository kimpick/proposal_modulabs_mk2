## 2. 아래와 같이 프롬프트 명령어를 통해 md 파일을 업데이트하기

```markdown
변경 구조:
.
└── AGENTS.md

`AGENTS.md`에는 Codex가 이 프로젝트에서 항상 따라야 할 기본 작업 원칙만 짧고 명확하게 업데이트하라.

작성 언어:
- 모든 내용은 한국어로 작성한다.
- 이후 Codex의 설명, 계획, 보고도 기본적으로 한국어로 하도록 명시한다.

최상단에는 현재 작업 환경 정보를 먼저 기입하라.

포함할 환경 정보:
- 현재 프로젝트 운영체제
- 현재 shell 또는 terminal 환경
- 현재 프로젝트 루트 경로
- 사용 가능한 주요 런타임이 확인되면 함께 기록한다.
  예: python, node, npm, git

단, 환경 정보를 확인할 수 없으면 추정하지 말고 `UNKNOWN`으로 기록한다.

`AGENTS.md`에 반드시 포함할 작업 원칙:

- 현재 프로젝트 스코프로 작업 범위를 명시하라.
- 가장 최상위에는 현재 작업 환경 및 운영체제에 대한 정보를 찾아서 기입하라. 

1. 프로젝트 내부 파일을 직접 읽고 판단한다.
2. 추정으로 구현하지 않는다.
3. 요구사항이 모호하면 먼저 짧게 확인하거나, 확인이 어려우면 안전한 최소 범위로 작업한다.
4. 필요한 경우 먼저 짧은 계획을 세운 뒤 작업한다.
5. 코드 수정 후 관련 테스트 또는 최소 검증을 수행한다.
6. 테스트를 실행할 수 없으면 그 이유를 명확히 기록한다.
7. 변경 내용과 검증 결과를 마지막에 짧게 요약한다.
8. `.env`, secret, credential, API key, 인증 파일은 출력하거나 수정하지 않는다.
9. 프로젝트 스코프 밖 파일은 읽기/수정하지 않는다.
10. 삭제, 강제 덮어쓰기, 원격 push 같은 파괴적 작업은 수행하지 않는다.
11. 사용자가 제공한 변수명, 함수명, 파일명은 임의로 바꾸지 않는다.
12. 불필요한 대규모 리팩토링을 하지 않는다.
13. 요청 범위 밖의 기능을 임의로 추가하지 않는다.

완료 후에는 생성한 파일 목록만 짧게 보고하라.
`AGENTS.md` 전체 내용을 장황하게 반복하지 말고, 핵심 원칙이 반영되었는지만 확인하라.
```

## 3. [AGENTS.md](http://AGENTS.md) 파일을 내 생각대로 변경하는 지시문 작성해보기

**Claude Code의 `CLAUDE.md`, Codex의 `AGENTS.md`는 “AI에게 매번 다시 설명하기 싫은 개발 운영 원칙”을 적어두는 파일이다.** 

따라서, 코드 생성 능력을 직접 올리는 개념이라기 보다는, 정확히 다음 문제를 최소화하는 개념에 더 가깝다. 

1. 매번 같은 설명을 반복해야 하는 문제
2. LLM이 로컬 환경 & 프로젝트 구조를 마음대로 추측하는 문제
3. 요청보다 더 많이 고치는 문제
4. 테스트 없이 “된 것 같다”고 끝내는 문제
5. 팀의 개발 규칙, 실행 명령, 금지사항을 자주 잊는 문제

→ 물론, 파일 구조도 및 코딩 스타일 코딩 제약사항 등을 넣기도 한다. 

메모리 파일은 모든 프로젝트에 그대로 쓰는 정답의 개념이 없다. 
각자 자신의 프로젝트에 맞춰 구체화해야 한다.

```markdown
좋은 예:

- TypeScript 파일 수정 후 `pnpm typecheck`와 관련 unit test를 실행하라.
- API response field name은 하위 호환성을 위해 임의 변경하지 마라.
- `legacy/`와 `generated/`는 요청받지 않으면 수정하지 마라.

```

좋은 문구는 “행동”, “대상”, “금지/허용 기준”, “검증 방법”이 들어간다.

### 3-1. 부족한 점을 물어보기

```markdown
넌 현재 내 AGENTS.md 파일을 분석하여, 

1) 전반적인 코딩 개발 과정에서 부족한 지점, 
2) 위 내용 중 모호한 지점, 
3) 공통 프로젝트에서 필수적으로 포함되어야 하는데 누락된 지점을 차례대로 분석하여 고도화를 진행한다.

이를 고도화하기 위해 나에게 5개의 질문과 각 질문에 3개의 선택지를 근거와 함께 제시하라.
내가 선택하고 피드백을 준 대로 AGENTS.md 파일을 업데이트하라.
업데이트 시, 반드시 짧고 명확한 형태로 context가 구성되어야한다. 
```
