# MCP 설치 프롬프트

```markdown
목표:
- MCP를 claude project scope로 설치하고 연결 검증한다.

대상 MCP:
- Context7: npx -y @upstash/context7-mcp
- Firecrawl: .claude/mcp/firecrawl.ps1 wrapper 사용
- Playwright: npx -y @playwright/mcp@latest

반드시 먼저 공식 문서를 확인하라:
- https://code.claude.com/docs/en/mcp

필수 확인:
- .mcp.json, .claude/settings.json, .claude/settings.local.json, package.json 존재 여부 확인
- 기존 MCP 설정이 있으면 백업하거나 변경점 요약
- Firecrawl API Key는 .env의 FIRECRAWL_API_KEY 사용 - .env 원문/키 값을 출력하지 말고, FIRECRAWL_API_KEY는 값 노출 없이 환경변수로만 로드해 MCP에서 사용한다.
- API Key 출력 금지, .mcp.json 하드코딩 금지
- .env가 .gitignore에 없으면 추가

설치 기준:
- Windows PowerShell 기준
- Claude Code CLI의 현재 권장 MCP 설치 방식 사용
- 각 MCP는 공식/신뢰 가능한 패키지 기준으로 설정

검증:
- - FIRECRAWL_API_KEY 검증은 값 출력 없이 존재 여부만 Boolean으로 확인하고, .env 원문을 읽어 출력하는 명령은 금지한다.
- Claude Code에서 MCP 서버 목록 확인
- 각 MCP가 최소 호출 가능한지 테스트
- 실패 항목은 원인 요약

최종 보고:
- 설치 성공/실패
- 설정된 MCP 목록
- 수정된 파일
- 남은 문제

```
