# 터미널 명령어 &  Frontmatter

### 터미널

| 목적 | 명령어 | 설명 |
| --- | --- | --- |
| 현재 위치 확인 | `pwd` | 현재 터미널 위치 출력 |
| 파일 목록 보기 | `dir` | 현재 폴더 내부 파일/폴더 출력 |
| 폴더 이동 | `cd 폴더명` | 특정 폴더로 이동 |
| 상위 폴더 이동 | `cd ..` | 한 단계 위로 이동 |
| 최상위 폴더 이동 | `cd ~` |  |
| 폴더 생성 | `mkdir test` | `test` 폴더 생성 |
| 파일 생성 | `ni app.py` | 빈 Python 파일 생성 |
| 파일 내용 출력 | `type app.py` | 파일 내용 확인 |
| 파일 복사 | `copy app.py backup.py` | 파일 복사 |
| 폴더 복사 | `xcopy test test_backup /E /I` | 폴더 전체 복사 |
| 파일 이동/이름변경 | `move app.py src\app.py` | 파일 이동 |
| 파일 삭제 | `del app.py` | 파일 삭제 |
| 폴더 삭제 | `rmdir /S test` | 폴더 전체 삭제 |
| 현재 폴더 VS Code 열기 | `code .` | VS Code 실행 |
| 현재 폴더 Cursor 열기 | `cursor .` | Cursor 실행 |
| Visual Studio 실행 | `devenv .` | Visual Studio 실행 |
| Git 초기화 | `git init` | Git 저장소 생성 |
| Git 상태 확인 | `git status` | 변경 파일 확인 |
| Git add | `git add .` | 전체 파일 스테이징 |
| Git commit | `git commit -m "msg"` | 커밋 생성 |
| Git push | `git push` | 원격 저장소 업로드 |
| Python 가상환경 생성 | `python -m venv .venv` | `.venv` 생성 |
| 가상환경 활성화 | `.\.venv\Scripts\activate` | venv 활성화 |
| 패키지 설치 | `pip install torch` | 라이브러리 설치 |
| 설치 패키지 확인 | `pip list` | 설치 패키지 확인 |
| Python 실행 | `python app.py` | Python 파일 실행 |
| 터미널 복사 | `Ctrl + Shift + C` | 터미널 텍스트 복사 |
| 터미널 붙여넣기 | `Ctrl + Shift + V` | 터미널 붙여넣기 |
| 이전 명령 반복 | `↑ 방향키` | 이전 명령 다시 사용 |
| 터미널 정리 | `cls` | 화면 초기화 |
