# 삼성전자 Track1 진행 핑시트 (Google Sheets)

온라인 라이브 교육 중 수강생이 단계별 진행상황을 직접 남기고(ping) 질문을 기재하면,
강사가 실시간으로 진도/막힘을 한눈에 모니터링하는 공유 시트.

- **대상 과정**: Track1 = 하네스 엔지니어링 Level 1 입문 (1일 8시간, 온라인)
- **공유**: 링크 보유자 누구나 편집 가능 (외부 수강생 접속 가능)
- **링크**: https://docs.google.com/spreadsheets/d/1z6k_yhH0oiDt3PL4XbhdTdIahHao14IrtPolR2q4vJM/edit
- **생성일**: 2026-05-27

## 탭 구성
| 탭 | 용도 |
|---|---|
| 📋 핑시트 (진행 현황) | 행=수강생 / 열=단계(M01~M04+예비). 셀 드롭다운으로 상태 입력. 질문/이슈·산출물 링크 자유 입력 |
| 💬 질문 로그 | 질문/이슈 누적 (시각·이름·단계·처리상태 드롭다운: 답변대기/해결) |
| 📊 강사 대시보드 | 단계별 완료/진행중/막힘/대기 인원 자동 집계(COUNTIF), 막힘 합계 강조 |
| ℹ️ 사용법 | 수강생·강사 사용법 + 재사용 안내 |

## 상태값 (드롭다운)
⬜ 대기 · 🔄 진행중 · ✅ 완료 · 🆘 막힘(도움요청)
- ✅ 초록 / 🔄 노랑 / 🆘 빨강(강조) / ⬜ 회색 조건부 서식 자동 적용

## 재사용
파일 > 사본 만들기 → 핑시트 탭의 단계 헤더(B1~F1)만 새 과정에 맞게 교체.
대시보드/조건부서식/드롭다운은 그대로 따라감.
