#### 3.3.4 트랙별 기획안 양식 (③ Prototype)

| 트랙 | 기획안 양식 항목 (③ Prototype = PLAN) |
|---|---|
| **Track 1** · 연구 설계 개요 | • 연구 질문 • 가설 / 기여 포인트 • 검증 방법 • 데이터 수집 전략 |
| **Track 2** · 커리어 계획서 | • 정체성 · Sweet Spot • 전문성 스토리아크 • 가치 제안 · 차별 각도 • 1년 / 10년 목표 |
| **Track 3** · 사업 기획안 (1장 요약) | • 미션 · 고객 · 문제 • 오퍼(1줄) • AI Agent 핵심 가치 • 초기 시그널(첫 100인 지표 1줄) |

> **3트랙 공통 원칙 — 산출물 1(③ 기획안)과 산출물 2(워드 보고서)의 역할 분리**:
> - ③ 기획안 = **PLAN** ("어떻게 발전시킬 것인가", 요약·설득용 슬라이드)
> - 워드 보고서 = **DRAFT OUTPUT** ("7월에 만들 최종 결과물의 실제 초안", 상세·실행용)
> - 같은 항목이 양쪽에 등장해 "내용 repeat"이 되지 않도록, ③은 관점/질문 중심, 워드는 결과/실행 중심으로 분담.
>
> **트랙2 심화 (구조 SWAP)**: 커리어 계획서가 **목적지(③ 기획안)**, 콘텐츠 전략 기획이 그 **길(워드 보고서)**. 아이디어 → ③ 커리어 계획서(정체성·비전) → 워드 콘텐츠 전략 기획(구체적 콘텐츠 실행안) 순으로 설계. 커리어 요소(Sweet Spot·스토리아크·1년/10년 목표)는 ③에만, 콘텐츠 요소(주제·채널·지표)는 워드에만. 팔로워 수가 아니라 **목적지와 길의 일관된 스토리**를 평가.

## 6. xlsx 변환을 위한 데이터 구조 (사용자 확정 — 7개 시트)

마스터 기획서를 xlsx로 변환할 때 사용자가 확정한 7개 시트 구조:

### Sheet 1: `전체 개요` 🟢
- 컬럼: 단계 / No / 세부 단계명 / 일시 / 시간 / 장소 / 담당 / 대상 / 상태 / 비고

- 요약 매트릭스: §5 트랙별 요약 매트릭스 포함

### Sheet 2: `아이디어톤 상세` 🟢
- 컬럼: 시간 / 세션 / 내용 / 담당 / 산출물 / 준비물
- 데이터: §3.3.1 통합 타임라인(9행) + §3.3.2 산출물 2타입 + §3.3.3 트랙별 루브릭(12행) + §3.3.4 선발 기준 + §3.3.5 준비 체크리스트

### Sheet 3: `Track 1 상세 (연구자동화)` 🟢
- 컬럼: 주차 / 일정 / 주제 / 세부 타임라인 / 핵심 활동 / 산출물 / 담당 / 비고

- DT 세션 명시: 1주차 오프닝 DT(아이스브레이킹) / 3주차 클로징 DT(회고)
- ⭐ **역량 평가 루브릭 추가 (§3.4.1 Track 1)**: 정량·정성·AI활용 3축 평가 기준표 포함

- 데이터: §3.4 Track 2 × 1/2/3주차 = 3행 (오프닝 DT 1H + 본과정 10H + 클로징 DT 1H = 12H)

- ⭐ **역량 평가 루브릭 추가 (§3.4.1 Track 2)**: 정량(참고지표)·정성·AI활용 3축 평가 기준표 포함

### Sheet 5: `Track 3 상세 (AI 비즈니스 랩)` 🟢
- 컬럼: 동일 구조
- 데이터: §3.4 Track 3 × 1/2/3주차 = 3행 (오프닝 인터스텔라 1H + 본과정 10H + 클로징 인터스텔라 1H = 12H)
- DT 세션 명시: 1주차 오프닝 인터스텔라(아이스브레이킹) / 3주차 클로징 인터스텔라(회고)
