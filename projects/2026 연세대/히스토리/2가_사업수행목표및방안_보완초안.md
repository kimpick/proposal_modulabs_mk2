### 사업 수행 목표

본 사업의 수행 목표를 다음 네 가지로 설정하고, 각 목표에 대한 정량적 달성 기준을 제시합니다.

**가. 3개 기관 통합 AX 교육 체계 구축 및 전주기 교육 운영**

- 신촌캠퍼스 도서관(연세 AX 아카데미), 국제캠퍼스 도서관(연세 AX 스타트), 신촌캠퍼스 박물관(연세 AX 뮤즈로그)을 기관별 독립 운영하되, 기초→활용→심화 단계별 연계 구조를 설계하여 체계적으로 AX 역량을 쌓을 수 있도록 합니다.
- 달성 기준: 총 90건 과정, 343회, 549시간 교육 운영 완료

**나. 문제정의–실습–프로젝트–성과확산 전주기 커리큘럼 설계·운영**

- 봄학기 문제 발견(디자인씽킹) → 여름방학 기술 심화(AX 캠프) → 가을학기 프로젝트 수행 → 겨울 MVP 완성·쇼케이스로 이어지는 4계절 전주기 교육을 설계합니다.
- 체험 교육(5건) → 세미나(8건) → 워크숍(41건) → 멘토링(9건) → 공모전·성과 공유(7건) + 콘텐츠 개발(20건)의 단계적 교육 체계를 구성합니다.
- 달성 기준: 전 과정에 문제정의–실습교육–프로젝트–성과확산의 전주기 구조 적용

**다. 총장 명의 AX 역량 인증서 발급 체계 구축**

- 사회적 수요를 반영한 AX 역량을 도출하고, 학부 재학 중 이수 가능한 기초(AX Starter)→활용(AX Practitioner)→심화(AX Creator) 3단계 교육 과정을 설계합니다.
- 국제캠퍼스 연세 AX 스타트(신입생)에서 신촌캠퍼스 연세 AX 아카데미(심화)로 자연 연계되는 로드맵을 구성합니다.
- 달성 기준: AX 역량 인증 로드맵 수립 및 인증서 발급 프로세스 운영

**라. 실습 교육 콘텐츠 15종 및 실감형 콘텐츠 5종 기획·제작**

- AX 교육의 학습 효과 극대화를 위해 주제별·수준별 맞춤형 실습 교재 및 콘텐츠를 개발합니다.
- 실감형 콘텐츠는 연세 학술정보원의 VR/AR/MR 인프라를 활용하되, Physical AI 기술 요소(센서 데이터 연동, 공간 인식 AI 등)와의 접점을 탐색하여 차세대 실감 교육 콘텐츠를 기획합니다.
- 달성 기준: 실습 교육 콘텐츠 15종 + 실감형 콘텐츠 5종 = 총 20건 제작 완료

### 추진 전략: The Trinity of Joy (배움의 세 가지 즐거움)

위 네 가지 목표를 달성하기 위해, 모든 프로그램은 아래 세 가지 즐거움을 설계 원칙으로 삼습니다.

**전략 1. Joy of Depth — 깊이의 즐거움**

도구 숙련 중심 교육은 "얼마나 빠르게"를 묻지만, "왜 배우는가"에는 답하지 못합니다. 기술을 표면적으로 익힌 학생은 다음 트렌드가 오면 다시 처음부터 시작해야 하지만, 원리를 이해한 학생은 도구가 바뀌어도 스스로 적응합니다. 연세대학교 학생이 단순 이용자가 아닌 설계자로 성장하려면, 깊이 있는 학습 경험이 먼저입니다.

*"나는 AI가 어떻게 작동하는지 안다. 그래서 다음 기술이 나와도 무섭지 않다."*

- 구현 프로그램: AX 기술 실습 워크숍(41건), 여름 AX 심화 캠프 — Vibe Coding → Agentic Coding → Harness Engineering 단계별 심화
- 연결 목표: 목표 나(전주기 커리큘럼)의 "기술 심화" 단계

**전략 2. Joy of Expansion — 확장의 즐거움**

대학 AI 교육의 문제는 기술 부족이 아니라 적용 맥락 부족입니다. 이공계 중심 설계 속에서 인문·예체능 학생이 '나와 무관한 기술'로 인식하고 이탈하는 문제가 발생합니다. 3개 캠퍼스 특성화 운영과 4계절 전주기 생태계로 진입점을 다변화해야 합니다.

*"나는 내 전공으로 AI를 활용할 수 있다. 기술과 내 일상이 연결되는 접점을 찾았다."*

- 구현 프로그램: 3개 캠퍼스 특성화 운영, AX 트렌드 세미나(8건), 박물관 인문학 역량 강화 융합 교육, 실감미디어 체험 프로그램(5건)
- 연결 목표: 목표 가(3개 기관 통합 교육 체계)의 "기관별 특성화"

**전략 3. Joy of Originality — 자기다움의 즐거움**

수료 후 단절이 반복되는 이유는 배움이 학생의 것이 되지 않기 때문입니다. 강의실 안에서 완성된 결과물이 사회적 가치를 증명할 기회를 갖지 못하는 문제를 해결하기 위해, Wild Public Release · 총장 명의 인증서 · 최종 쇼케이스를 도입합니다.

*"나는 AI를 도구로 삼아 세상에 내 결과물을 공개했다. 그리고 반응을 받았다."*

- 구현 프로그램: 멘토링 프로젝트(9건), 공모전·경진대회·쇼케이스(7건), Wild Public Release(SNS 배포)
- 연결 목표: 목표 다(AX 역량 인증서)의 심화 단계 — MVP 완성 → SNS 배포 → 전문가 피드백 → 인증서 발급

### AX 역량 로드맵

총장 명의의 AX 역량 인증서 발급을 위해, 학부 재학 중 이수 가능한 기초–활용–심화 3단계 교육 로드맵을 구성합니다. 사회적 수요를 반영한 AX 역량을 도출하고, 국제캠퍼스(신입생)에서 신촌캠퍼스(심화)로 자연 연계되는 성장 경로를 설계합니다.

**단계 1. 기초 — AX Starter ("AI를 이해하다")**

| 항목 | 내용 |
|------|------|
| 대상 | 국제캠퍼스 신입생 (연세 AX 스타트) |
| 핵심 역량 | AI 기초 리터러시, 생성형 AI 도구 활용 능력 |
| 이수 요건 | 체험 교육 참여 + 입문 세미나 수강 + 기초 워크숍(생성형 AI 원데이 클래스 등) 2건 이상 이수 |
| Joy 매핑 | Joy of Depth — AI가 무엇이고 어떻게 작동하는지 이해하는 단계 |
| 인증 | AX Starter 수료 인증 (출결 + 기초 과제 제출) |

**단계 2. 활용 — AX Practitioner ("AI로 만들다")**

| 항목 | 내용 |
|------|------|
| 대상 | 신촌캠퍼스 (연세 AX 아카데미) 및 AX Starter 이수자 |
| 핵심 역량 | AI 도구 활용 실무 능력, 주제별 문제 해결 역량 |
| 이수 요건 | 주제별 워크숍 4건 이상 이수 + 멘토링 프로젝트 1건 참여 |
| Joy 매핑 | Joy of Expansion — 배운 기술을 자신의 전공·관심 도메인에 적용하는 단계 |
| 인증 | AX Practitioner 수료 인증 (워크숍 이수 + 프로젝트 결과물 제출) |

**단계 3. 심화 — AX Creator ("AI로 증명하다")**

| 항목 | 내용 |
|------|------|
| 대상 | 전 캠퍼스 (AX Practitioner 이수자, 공모전·쇼케이스 참여자) |
| 핵심 역량 | AI 기반 창의적 문제 해결, 프로젝트 완수 및 사회적 확산 능력 |
| 이수 요건 | 공모전 또는 경진대회 출품 + 최종 쇼케이스 발표 + AX 포트폴리오 제출 |
| Joy 매핑 | Joy of Originality — 나만의 결과물(MVP)을 만들어 세상에 공개하는 단계 |
| 인증 | **총장 명의 AX 역량 인증서 발급** |

**로드맵 연계 구조:**

```
[국제캠퍼스 · 1학년]          [신촌캠퍼스 · 2~4학년]           [전 캠퍼스]
     AX Starter         →        AX Practitioner        →       AX Creator
   (AI를 이해하다)              (AI로 만들다)                  (AI로 증명하다)
                                                                    ↓
   체험 + 세미나 + 기초WS       워크숍 + 멘토링               공모전 + 쇼케이스
                                                           총장 명의 AX 인증서
```

**이수 현황 관리:**
- 참여자 출결, 결과물 등 수료 기준 및 교육 이수 현황 체계적 관리
- 단계별 이수 조건 충족 여부 자동 추적 및 인증서 발급 대상 관리
- 학기별 이수 현황 보고를 통한 로드맵 운영 실효성 확보
