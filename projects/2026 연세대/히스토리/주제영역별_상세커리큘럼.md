## 1. 생성형 AI (약 29건)

### 영역 개요

본 사업 90건 중 29건(약 32%)이 생성형 AI 영역에 배정된 이유는 명확합니다. 학부생이 졸업 시 ChatGPT·Gemini·Perplexity·NotebookLM을 활용해 자기 전공의 문제를 정의하고, 자연어로 시제품을 만들어 공개하는 일련의 흐름을 자기 주도로 수행해야 하기 때문입니다. 본 커리큘럼은 도구 사용법이 아니라 학습자 본인의 도메인 문제에서 출발합니다. 모든 차시에서 학생은 자기 전공·동아리·진로의 실제 문제를 가져와 5단계를 통과시키며, 마지막 공개 단계에서 산출물을 외부에 공개합니다.

### 대표 워크숍 4건

#### 워크숍 A. 프롬프트 엔지니어링 실전 — 리서치에서 보고서까지
- 대상·시간: 학부생 25명 / 4시간(2회×2H) / 신촌 AX 아카데미
- 학습 목표:
  1. 입출력·맥락을 분리한 문제 진술서 1편을 작성합니다
  2. Perplexity 리서치 결과를 ChatGPT 보고서로 변환합니다
  3. 재사용 가능한 프롬프트 5개를 라이브러리화합니다
- 회별 모듈: 1회 — 도메인 문제 발굴 30분 → 문제 진술서 작성 60분 → Perplexity 출처 검증 30분 / 2회 — ChatGPT 다단계 프롬프팅 60분 → NotebookLM 소스 그라운딩 40분 → 동료 피드백 20분
- 핵심 도구: ChatGPT, Perplexity, NotebookLM
- 학생 산출물: 문제 진술서 1편, 출처 인용 리서치 브리프 1편(A4 3매), 프롬프트 라이브러리 5개
- DT 매핑: ① ② ③

#### 워크숍 B. 자연어로 만드는 첫 시제품 — Codex 입문
- 대상·시간: 학부생 20명 / 4시간(2회×2H) / 국제캠퍼스 AX 스타트(평일 야간 17~21시)
- 학습 목표:
  1. 자기 학과 과제용 미니 웹앱 1개를 자연어 지시로 구현합니다
  2. 오류 메시지를 ChatGPT로 진단·수정합니다
  3. GitHub URL 형태로 시제품을 공개합니다
- 회별 모듈: 1회 — 시제품 아이디어 정의 40분 → Codex 환경 셋업 30분 → 첫 동작 확인 50분 / 2회 — 기능 추가 60분 → 디버깅 페어워크 40분 → 공개 URL 발행 20분
- 핵심 도구: Codex, ChatGPT, Gemini
- 학생 산출물: 동작하는 웹앱 1개, 공개 URL 1건, 디버깅 로그 노트 1편
- DT 매핑: ④ ⑤

#### 워크숍 C. NotebookLM 기반 컬렉션 큐레이션 (박물관 연계)
- 대상·시간: 학부생 20명 / 3시간(1회) / 신촌 박물관
- 학습 목표:
  1. 박물관 1차 자료 10건을 NotebookLM에 그라운딩합니다
  2. 출처 각주가 달린 큐레이션 텍스트 800자를 작성합니다

- 회별 모듈: 자료 수집·업로드 40분 → NotebookLM Q&A 검증 50분 → 큐레이션 초고 40분 → Gamma 패널 발행 50분
- 핵심 도구: NotebookLM, ChatGPT, Gamma
- 학생 산출물: 인용 각주 포함 큐레이션 텍스트 1편(800자), Gamma 전시 패널 5장
- DT 매핑: ① ② ④

#### 워크숍 D. 공모전 출품작 만들기 — 아이디어에서 발표 자료까지
- 대상·시간: 공모전 참가팀 30명 / 4시간(2회×2H) / 국제캠퍼스 2학기
- 학습 목표:
  1. Gemini로 30개 아이디어를 발산하고 3개로 수렴합니다
  2. Codex로 개념 시제품 1건을 구현합니다
  3. Gamma 발표 자료 10장을 완성합니다
- 회별 모듈: 1회 — 페르소나·문제 정의 40분 → Gemini 발산 50분 → 수렴 워크숍 30분 / 2회 — Codex 시제품 70분 → Gamma 발표자료 40분 → 리허설 10분
- 핵심 도구: Gemini, Codex, Gamma, ChatGPT
- 학생 산출물: 아이디어 보드 1건, 시제품 1건, 발표 자료 10장, 90초 피칭 스크립트 1편
- DT 매핑: ② ③ ④ ⑤

## 2. 데이터 분석 (약 5~6건)

### 영역 개요

학부생이 마주하는 과제·동아리·인턴 업무 대부분은 흩어진 자료에서 의미 있는 패턴을 찾아 한 장으로 설명하는 일입니다. 비전공자에게 데이터 분석은 더 이상 SQL·통계 수식 암기가 아니라, 질문을 잘 정의하고 AI에게 적절히 맡기고 결과를 비판적으로 해석하는 능력입니다. 본 영역은 NotebookLM·ChatGPT·Codex를 통해 학생이 직접 공공데이터·논문·기관 리포트를 다루며, 자기가 궁금했던 질문에 숫자로 답하는 경험을 만드는 데 초점을 둡니다. 이공계 학생에게는 Colab 기반 자연어 분석 코드 생성을, 비전공 학생에게는 NotebookLM 중심 해석 워크플로우를 제공해 출발점이 달라도 같은 산출물에 도달하도록 설계합니다.

### 대표 워크숍 3건 (각 4시간 / 신촌)

#### W1. 공공데이터로 내 동네·내 학과 질문에 답하기
- 학습 목표: ① 공공데이터포털에서 분석 가능한 데이터셋 식별 ② NotebookLM으로 다중 자료 교차 해석 ③ ChatGPT 데이터 분석 모드로 1차 인사이트 도출
- 모듈: 좋은 질문 만들기·데이터셋 탐색 60분 / NotebookLM에 공공데이터+관련 보고서 적재·요약 60분 / ChatGPT 파일 업로드 분석·교차 검증 90분 / 인사이트 1장 정리 30분
- 도구: 공공데이터포털, NotebookLM, ChatGPT
- 산출물: 공공데이터 인사이트 리포트 1편(A4 2매) + 노트북 링크
- DT: ① ②

#### W2. NotebookLM으로 리서치 메모에서 분석 질문 뽑아내기
- 학습 목표: ① 논문·기관 리포트를 분석 가능한 질문으로 분해 ② Gemini로 가설·반증 탐색 ③ 분석 설계서 1종 작성
- 모듈: 관심 주제 자료 10건 수집 60분 / NotebookLM 노트·FAQ·브리핑 자동 생성 60분 / Gemini로 가설·대안가설 발산 60분 / "무엇을 측정할지" 분석 설계서 작성 60분
- 도구: NotebookLM, Gemini, 공공데이터포털
- 산출물: 분석 설계서 1종 + 인터뷰용 질문지 10개 + 데이터 후보 리스트 3건
- DT: ② ③

#### W3. Codex·Colab로 자연어 분석 코드 만들기
- 학습 목표: ① 자연어 지시로 Python 분석 코드 생성·수정 ② Colab에서 시각화 3종 산출 ③ 결과를 슬라이드 1장에 설명
- 모듈: Codex·ChatGPT 코드 생성 패턴 45분 / Colab에서 데이터 로드·전처리·기술통계 75분 / 시각화 3종(분포·추이·비교) 생성 75분 / 발표용 슬라이드 1장 정리 45분
- 도구: Codex, ChatGPT, Python(Colab)
- 산출물: 데이터 시각화 자료 3개 + Colab 노트북 1개 + 1장 요약 슬라이드
- DT: ④ ⑤

### 멘토링 프로젝트 연계 (여름 AX 캠프)

W1에서 정의한 동네·학과 질문은 캠프 프로젝트의 출발 주제로, W2의 분석 설계서는 멘토링 1주차 검토 자료로, W3의 Colab 노트북은 캠프 중간 산출물의 분석 백본으로 이어집니다. 캠프 멘토는 학생의 노트북 링크를 그대로 열람하며 코드·해석을 함께 보강해, 워크숍 4시간이 6주 프로젝트의 1차 시제품으로 자연스럽게 확장됩니다.

## 3. AI 에이전트 (약 5~7건, Codex 중심)

### 영역 개요

AI 에이전트는 자연어 지시만으로 코드 생성·도구 호출·작업 자동화를 수행하는 시스템으로, 학부생이 전공과 무관하게 자신의 학습·연구·일상 문제를 직접 해결할 수 있게 해주는 결정적 도구입니다. 특히 Codex를 활용하면 코딩 경험이 0~1년인 학생도 한국어로 의도를 설명하는 것만으로 동작하는 시제품을 만들 수 있어, 진입장벽이 사실상 사라집니다. 본 영역은 Vibe Coding(의도→코드) → Agentic Coding(AI가 도구 사용·자율 판단) → Harness Engineering(멀티 에이전트 오케스트레이션)의 3단계를 따라, 학생이 쓰는 사람에서 만드는 사람으로 전환되는 경험을 설계합니다.

### 대표 워크숍 3건 (각 4시간 / 신촌)

#### W1. 내 일상을 자동화하는 AI 비서 만들기 (Vibe Coding 입문)
- 학습 목표: ① Codex 자연어 프롬프팅 익히기 ② 첫 동작 시제품 완성 ③ 디버깅 루프 체험
- 모듈: 발견·정의 — 내 일상의 반복 작업 찾기 30분 / Codex 환경 셋업·첫 프롬프트 60분 / 발산 — 시나리오 3안 비교 40분 / 시제품 — 개인 비서 구축 90분 / 공개 — 시연·회고 20분
- 도구: Codex(주), ChatGPT(아이디에이션)
- 산출물: 학생 본인의 과제 일정/이메일/노션을 자동 정리하는 개인 AI 비서 1개

#### W2. 리서치를 대신해주는 에이전트 만들기 (Agentic Coding)
- 학습 목표: ① Tool-use·ReAct 루프 이해 ② 웹검색·문서요약·정리까지 한 번에 수행하는 에이전트 구현 ③ 실패 케이스 분석
- 모듈: 발견 — 학과 리서치 페인포인트 30분 / 정의 — 입력·출력 명세 작성 30분 / 발산 — 도구 조합 설계 40분 / 시제품 — Codex로 검색→요약→레포트 파이프라인 120분 / 공개 — 동료 데이터로 검증 40분
- 도구: Codex(주), Gemini(검색·근거 보강)
- 산출물: 자율 리서치 에이전트 1개 (주제 입력 → 출처 포함 2페이지 브리프 자동 생성)

#### W3. 여러 에이전트가 협업하는 워크플로우 (Harness Engineering)
- 학습 목표: ① 멀티 에이전트 역할 분담 설계 ② 노코드 연결로 외부 서비스 통합 ③ 운영 관점에서 신뢰성 확보
- 모듈: 발견·정의 — 협업이 필요한 복합 업무 도출 40분 / 발산 — 에이전트 분업 다이어그램 40분 / 시제품 — Codex로 메인 에이전트 + n8n/Zapier로 외부 연결 120분 / 공개 — 팀별 데모·피드백 40분
- 도구: Codex(주), n8n, Zapier
- 산출물: 3개 에이전트 협업 워크플로우 1개 (예: 동아리 운영 자동화 — 모집글 작성·지원자 분류·일정 안내)

### 여름 AX 캠프 Track B (AI 에이전트 트랙)

일정: 여름방학 4시간 × 5일 집중 + 멘토링 2주

| 일차 | 단계 | 학습 내용 | DT 단계 |
|---|---|---|---|
| 1일차 | Vibe | Codex 셋업, 자연어 → 첫 시제품, 페인포인트 발굴 | 발견·정의 |
| 2일차 | Vibe→Agentic | Tool-use 기초, 단일 에이전트 구축 | 발산 |
| 3일차 | Agentic | ReAct 루프, 외부 API·웹 연동 | 시제품 |
| 4일차 | Harness | 멀티 에이전트 분업, n8n 오케스트레이션 | 시제품 |
| 5일차 | 통합 | 데모데이 — 실사용자 피드백·반복 개선 | 공개 |

최종 산출물: 팀별 실생활 문제 해결 에이전트 서비스 1개(예: 신입생 수강신청 어시스턴트, 학과 공지 자동 큐레이션 봇) + 시연 영상 + 운영 매뉴얼

## 4. 디지털 콘텐츠 제작 (약 16건)

### 영역 개요

인문·예체능 학부생에게 디지털 콘텐츠 제작은 더 이상 취미가 아니라 자기 서사를 사회와 연결하는 언어입니다. 졸업 후 SNS 릴스, 링크드인 포트폴리오, 공모전 출품, 첫 직장의 브랜드 운영 업무에서 즉시 요구되는 표현 문법입니다. AI 시대의 콘텐츠 제작은 Canva·CapCut 같은 도구를 다루는 숙련이 아니라, 기획 의도를 정확한 프롬프트로 번역하고 AI 생성물을 자기 관점으로 큐레이션·재편집하는 판단력을 기르는 일입니다. 본 영역은 비전공자가 자기 메시지의 주도권을 잃지 않은 채 AI를 활용해 산출 속도를 끌어올리는 실전 워크플로우를 다룹니다.

### 대표 워크숍 4건

#### W1. 3시간 만의 브랜드 미니 캠페인 (미디어 제작)
- 대상·시간: 1학기 신입생 25명 / 평일 야간 17~20시 / 3H
- 학습 목표: ① 캠페인 컨셉을 한 문장 슬로건으로 좁히기 ② Midjourney 프롬프트로 톤앤매너 일관된 비주얼 4컷 생성 ③ Canva로 SNS 3채널(릴스 커버·카루셀·스토리) 동시 운용 포맷 완성
- 회별 모듈: 발견·정의(페르소나 인터뷰 + ChatGPT 인사이트 추출) 60분 / 발산·시제품(Midjourney 비주얼 + Canva 레이아웃) 60분 / 공개(동료 피드백 + 수정) 60분
- 도구: ChatGPT, Midjourney, Canva
- 산출물: SNS 캠페인 키트 1세트 (슬로건 + 비주얼 4컷 + 채널별 포맷 3종)

#### W2. 숏폼 다큐 — 내 동네 3분 (미디어 제작)
- 대상·시간: 학부생 20명 / 3H
- 학습 목표: ① 인터뷰·B롤 촬영 본인 소스를 CapCut AI 자막·컷편집으로 다듬기 ② Suno로 무드에 맞는 BGM 생성 ③ 3분 다큐 구조(훅-본문-여운) 설계
- 회별 모듈: 발견 — 동네 산책·촬영 브리프 60분 / 시제품 — CapCut 편집 + Suno BGM 60분 / 공개 — 시사회 60분
- 도구: CapCut, Suno, ChatGPT
- 산출물: 3분 다큐 영상 1편 + 포트폴리오용 메이킹 노트

#### W3. 책을 한 장의 인포그래픽으로 (북클럽 연계)
- 대상·시간: 북클럽 참여자 25명 / 3H
- 학습 목표: ① 책의 핵심 논지를 Gemini로 구조화 ② Gamma로 시각 슬라이드 자동 생성 후 본인 해석 레이어 추가 ③ 인포그래픽 1장으로 압축
- 회별 모듈: 정의 — 책 인사이트 추출 60분 / 발산·시제품 — Gamma 초안 + Canva 마감 60분 / 공개 — 갤러리 워크 60분
- 도구: Gemini, Gamma, Canva
- 산출물: 책 1권 → 인포그래픽 1장 + 발표 슬라이드 5장

#### W4. 북클럽 → 공모전 출품작 만들기 (북클럽 연계)
- 대상·시간: 공모전 출품 희망자 20명 / 3H
- 학습 목표: ① 책의 메시지를 본인 시선으로 재해석한 트리트먼트 작성 ② Midjourney·Suno로 분위기 자산 제작 ③ CapCut으로 60초 출품 영상 완성
- 회별 모듈: 정의·발산 — 트리트먼트 60분 / 시제품 — 비주얼·사운드 60분 / 시제품·공개 — 영상 마감 + 출품 전략 60분
- 도구: ChatGPT, Midjourney, Suno, CapCut
- 산출물: 공모전 출품용 60초 영상 1편 + 출품 신청서 초안

### 실감미디어 체험 교육 (252회 운영)

## 5. 인문학 × AI 융합 (박물관, 약 6건)

### 영역 개요

박물관은 본래 시간을 견딘 것들이 모이는 장소이며, AI는 그 시간을 새로운 언어로 다시 읽게 합니다. 신촌캠퍼스 박물관에서 AI 교육을 한다는 것은 기술을 가르치는 일이 아니라, 인문학이 디지털 시대에 어떻게 더 멀리 닿을 수 있는지를 함께 묻는 일입니다. 디지털은 인문학을 대체하지 않으며, 오히려 한글 고문헌·연세 역사 자료·박물관 컬렉션을 더 많은 사람과 연결하는 통로가 됩니다. 본 영역은 학생이 박물관의 자원을 텍스트·이미지·소리로 재해석하며, 의미를 다루는 인문학적 감수성과 AI 도구를 다루는 손을 동시에 단련하도록 설계합니다.

|---|---|---|---|---|---|
| 1 | AX 시대, 인문학의 미래 (강연) | 강연 + Q&A | 디지털 인문학·미디어철학 연구자 | AI 시대 인문학의 위치를 사유 | NotebookLM으로 강연록 정리 |
| 2 | AX 시대, 인문학의 미래 (토론) | 사례 토론·라운드테이블 | 문화비평가·콘텐츠 기획자 | 산업·문화 현장의 쟁점 토론 | ChatGPT 활용 토론 회고문 |
| 3 | 한글을 지킨 연세의 거인들 | 박물관 유물 투어 + 강의 | 국어학·연세 사학 전공자 | 외솔 최현배 등 연세 인물 재조명 | Gemini로 인물 아카이브 카드 제작 |
