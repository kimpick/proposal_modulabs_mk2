# 4차원 검토 리포트 — 커리큘럼 초안 (US-012)

- **대상**: `커리큘럼_초안_v1.md` (8/14 고객 발송 예정본)
- **기준**: `docs/커리큘럼_검토_가이드.md` · `docs/review_agent_prompts.md` · `docs/review_governance.md`
- **판정 규칙**: FIX 1개 이상 또는 WARN 3개 이상 → NEEDS_FIX / WARN 1~2 → PASS_WITH_NOTES / WARN 0 → PASS
- **최종 판정**: ✅ **PASS_WITH_NOTES** (2026-08-13, 3라운드 종료 시점)

`content.json`이 아니라 마크다운 커리큘럼에 4관점을 적용했다. `content.json` 3-way check는 **커리큘럼 ↔ 덱 ↔ 배포물 2종의 4자 일관성**으로 대체했다.

## 수용한 WARN·INFO (수정하지 않음)

| 관점 | 항목 | 수용 근거 |
|---|---|---|
| ① | 00:03–00:08 세그먼트가 개념 4개·장표 3장으로 밀도 최고 | 시간 총량 30분과 세그먼트 경계는 **고객과 합의된 구조**다. 경계 조정은 8/14 발송을 앞둔 이 단계의 범위 밖이며, 리허설에서 강사 스크립트로 조절한다 (`review_governance.md` D1 계열 판단) |
| ④ | `.svg-fallback`이 `.no-svg` 클래스를 붙이는 코드가 없어 도달 불가 | SVG가 **인라인**이라 CDN·네트워크 실패와 무관하게 렌더된다. 실위험이 없고 AC-8의 "`.svg-fallback` 존재" 요건은 충족한다. `display:none`이라 레이아웃 높이에도 영향 없음 |
| ④ | `measure_ac2.py:68`의 `fitContent` 재호출이 no-op | 덱의 `fitContent`가 IIFE 내부라 전역에 없다. 다만 load 훅이 이미 전 슬라이드에 실행하고 `is-active` 전환은 opacity/translateX만 바꿔 **높이에 영향이 없으므로** 게이트 판정에 무영향 |
| ③ | sec-num(04·05·06)과 원칙 번호(①②③) 불일치 | §6 장표 구성안과 일치한다. 화면 번호는 섹션 순번이고 원칙 번호는 킥커에 따로 있어 의미가 겹치지 않는다 |
