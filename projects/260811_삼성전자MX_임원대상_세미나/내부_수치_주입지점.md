> **내부 문서. 고객 전달 대상이 아니다.**
> 고객 회신으로 수치를 받으면 **판단 없이 기계적으로** 치환할 수 있도록 위치와 문구 형태를 미리 고정한다.

## 2. 치환 후 필수 후속 작업

수치를 넣으면 반드시 이 순서로 뒤따라야 한다. 빠뜨리면 문서 간 정합이 깨진다.

1. `리서치_토큰최적화_근거.md` §2에서 해당 행을 제거하고 §1로 승격 (출처 = 고객 제공 사내 자료)
2. `내부_근거_대조표.md`에 새 행 추가 — 근거표 # 열을 비우면 **AC-7 실패**
3. 커리큘럼과 덱 **양쪽** 수정 (3자 일관성. 배포물에도 해당 수치가 있으면 3곳)
4. `내부_검증/measure_ac2.py` 재실행 — **정상 + `--font-break` 2회 모두.** 수치 추가는 텍스트를 늘리므로 축소가 발생할 수 있다
5. 여유 하위 3장은 특히 확인: **N11(24px) · N9(45px) · N3(57px)**

## 3. 추가 예산 (AC-2 충족의 유일한 안전장치)

무축소 정책에서 모든 추가는 동량의 삭제로 지불해야 한다. 현재 실측 여유(폰트 폴백 기준):

| 슬라이드 | 여유 | 추가 가능 분량 |
|---|---|---|
| N11 요약 | 24px | 거의 없음. 표 셀 문구를 줄여야 추가 가능 |
| N9 재사용 | 45px | 표 1행 정도 |
| N3 원리 | 57px | 캡션 1~2행 |
| N4 두 변수 | 65px | **환산 비율 4열 추가 시 여기서 소모됨.** 4열은 폭만 늘리고 높이는 늘리지 않으므로 통과 예상되나 셀 줄바꿈 주의 |
| N2 · N10 | 108~121px | 표 2행 또는 각주 3행 |
| N5 · N6 · N7 · N8 | 134~191px | 여유 있음 |
| N1 표지 | 328px | 해당 없음 |

참고: `.tbl.compact` 1행 ≈ 44px, 일반 텍스트 1행 ≈ 24px, 셀 줄바꿈 1회 ≈ 22px.

## 4. 장표 도식 제작 사양

커리큘럼 §3에 있던 그래프 제작 명세를 이관했다(가독성 검토 WARN — 고객 본문에 제작 명세 노출). 덱 제작 시 이 사양을 참조한다. 커리큘럼에는 1~2문장 요약만 남긴다.

### 월말 잔량 곡선 (덱 N2 · 커리큘럼 00:00–00:03)
가로축은 1일부터 말일까지, 세로축은 월간 한도 대비 잔량 100퍼센트에서 0퍼센트다. 균등하게 나눠 쓰는 기준선(직선)과 실제 소모선(기준선보다 기울기가 큰 직선)을 겹쳐 그리고, 두 선이 벌어져 말일 전에 잔량이 0에 닿는 지점을 소진 시점으로 표시한다. 하루 사용 기준을 넘겨 쓰면 습관이 변하지 않아도 월말 전에 바닥난다는 것이 메시지다. 티어별 절대 수치는 쓰지 않고 비율로만 표현한다.

### 앞 내용을 매번 다시 계산 (덱 N3 · 커리큘럼 00:03–00:08)
가로축은 같은 대화에서의 질문 횟수 1회부터 10회, 세로축은 누적 입력량이다. 질문 1회를 1단위로 두면 열 번째 질문까지 이어 썼을 때 누적은 55단위, 세 턴짜리 대화 세 개와 한 턴 하나로 나누면 6+6+6+1 = 19단위다. 막대를 신규 입력분과 다시 계산한 분량 두 색으로 쌓아 보여준다. 대화가 한도에 가까워지면 도구가 앞 대화를 요약해 곡선이 한 번 꺾이므로, 요약이 걸리기 전 구간이 가장 비싸다는 점을 함께 표시한다.
