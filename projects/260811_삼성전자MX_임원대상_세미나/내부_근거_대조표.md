# 내부 근거 대조표 — 발표덱·배포물 수치 역추적

> **내부 문서. 고객 전달 대상이 아니다.**
> 덱·배포물에 올린 모든 수치·주장이 `리서치_토큰최적화_근거.md` §1의 어느 행으로 역추적되는지 기록한다.
> AC-7 판정: **`근거표 #` 열에 빈 값이 0건**이고, 각 행의 근거 텍스트가 게재 수치를 지지해야 통과.
> **게재처** 열은 이 행이 실제로 등장하는 산출물을 표기한다. 근거가 없으면 "근거 없음"이라고 그대로 적는다 — `§2 미확보` 같은 표기를 근거 열에 채워 넣지 않는다(미확보가 확정 진술을 떠받치는 것처럼 보이는 것을 막기 위함, 260813 3차 검토 반영).
> **260813 5차 검토**: 강사 소개 슬라이드가 새 2번으로 들어오면서 덱이 12장이 됐고, 이후 슬라이드 번호가 전부 하나씩 밀렸다.
> **260813 6~10차 검토**: 강사 이력 과장 3건 정정, 문제 정의 lead·박스 재편, 절감 4지점 재구성, 재사용 "스킬" 개념 도입, 시간 재배정(측정 3분/절감 5분), 용어 선참조 브릿지 추가, §6 내부 구현 용어 제거 등을 순차 반영.
> **260813 11차 검토**: 문제 정의 슬라이드의 월말 잔량 곡선 SVG·캡션을 삭제하고 제목·구성을 전면 재편.
> **260813 12차 검토(이번 라운드)**: 고객이 "가장 중요한 커리큘럼 테이블이 없다", "하네스 구조·팀 에이전트 세팅·업무별 AI 활용도·업무 매트릭스까지 포함하라", "시간 제약 생각하지 말고 일단 다 넣어라", "실습 대신 시연이나 사례 소개면 된다"고 지시해 덱이 **12장 → 15장**으로 커졌다. 새 2번 슬라이드(오늘 다루는 것)가 진행 구성표 역할을 하고, 원칙③(재사용)이 하네스 3층 구조·팀 에이전트 세팅으로 재구성되고, 시연·업무 매트릭스 슬라이드가 신설됐다. 시간 표기는 분 단위 확정에서 "시간 배분은 내용 확정 후 조정" 잠정 표기로 전환됐다. 아래 슬라이드 번호는 모두 새 15장 번호 기준이다(구 N2~N12 → 신 N3~N15, 그 사이에 N2·N12·N13 신설).

## Q&A 대비 (강사용, 덱 미표기)

임원 질의에서 나올 가능성이 높은 순서다. 근거표에 행이 없는 항목은 "확인 후 회신"으로 답한다.

1. "등급 간 몇 배냐" → 공개 단가 기준으로는 몇 배에서 열 배까지 벌어지지만, **사내 환산 비율이 확정되지 않아 단정하지 않는다**고 답한다
2. "지시문 등록하면 얼마 절감되냐" → 입력 분량 감소만큼은 확실하고, 도구 내부 재사용 절감의 사내 환산 반영 여부는 확인 중
3. "토큰 집계가 늘었다는 게 얼마냐" → 모델 세대에 따라 다르고 사내 도입 모델 확인이 필요
4. "우리 티어는 얼마냐" → 확인 요청 항목
5. "업무 매트릭스는 우리 조직도 이렇게 채우면 되나" → 빈 양식은 배포물에 있고, 이번 표는 임원 업무를 예로 든 사례 소개라고 답한다
