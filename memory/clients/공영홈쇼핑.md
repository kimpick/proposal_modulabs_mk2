## 4. 확정된 조건·제약

- 교육 단계 설계가 **3단 파이프라인**: 기초과정 → 바이브코딩 워크샵 → **사내 확산(부서 챔피언 주도)**. 제안은 이 흐름의 어느 단계인지 명시해야 설득됨 [출처: 요구조건_바이브코딩.md]
- 바이브코딩 건 규모: 총 14H (7H × 2일), **2차수**, 팀별 1명 선정 약 40명(20명씩 분반) [출처: 동일]
- 이론 20% / 실습 80%, **1인 1챗봇 결과물 확보**가 핵심 요구 [출처: 동일]
- 도구: **Claude Pro** (Projects로 부서 자료 컨텍스트 + Artifacts로 한 페이지 앱). 수강생 **1인 1계정** 필요 — 교육사 사전 발급 또는 본사 일괄 가입 [출처: 동일]
- 사내 보안 정책상 외부 AI 사용 제약이 있을 경우 인프라 협의 필요 — **(미확인, 확인 안 되면 제안 전에 반드시 질의)** [출처: 동일]
- 사전 준비물: 부서별 사규·매뉴얼·FAQ를 수강 전 PM이 안내해 수집 [출처: 동일]
- 보조강사 1인 권장 (실습 80%, 20명 동시 개발 환경) [출처: 동일]
