# 고객사 기억 인덱스

`projects/` 폴더는 **회차/건 단위**로 쪼개져 있어 한 고객사가 여러 폴더에 흩어져 있습니다.
고객사 단위 기억은 이 디렉토리(`memory/clients/<고객사>.md`)에 **한 파일로만** 둡니다.

## 사용 규칙

1. **작업 시작 전**: 아래 매핑에서 폴더 → 고객사를 확인하고 `memory/clients/<고객사>.md`를 먼저 읽습니다.
2. **기본 규칙**: 매핑표에 없으면 **폴더명 = 고객사명**으로 간주합니다. 예외만 아래에 등록합니다.
3. **작업 종료 후**: 새로 알게 된 재사용 가능한 맥락을 고객사 파일에 추가하고, 이번 회차의 진행 경과는 `projects/<폴더>/MEMORY.md`에 적습니다.
4. **역할 분담**
   - 확정 사실(계약·단가·매출·수강인원 실적) → **Notion 「영업/제안현황」 DB**가 원본
   - 재사용할 맥락(담당자 성향, 거절 사유, 선호 포맷, 지난 피드백, 제약) → **이 파일들**
   - 제안 설계 입력(배경·요구조건) → `projects/<폴더>/context.md`, `요구조건.md` (기존 관례 유지)
5. `memory/YYYY-MM-DD-HHMM.md`는 OpenClaw가 자동 생성하는 **세션 로그**입니다. 이 디렉토리와 무관하며 손대지 않습니다.
