- 조직 특성: 마포 본사 + 지역 지점(성수·명동·강북·송파·강동·은평 등). 교육 대상 부서는 본부(기조실·총무·사업운영), 영업점, 보증재단, 채권관리. **전 부서에 'AI 리더'가 지정되어 있고 그중 선발해 교육한다** [출처: 1차 유선 상담 2026-09-03]
- 주요 업무: 보증서 발급, 보고서 작성(공공기관 특성상 비중 높음), 실적 데이터 분석
- 보안·인프라 제약: **내·외부망 분리**. 사내 AI 스튜디오(MSAP.ai / AI Studio) 자체 구축·운영. 소상공인 금융정보를 다루므로 개인정보 민감도가 높다
- **사내 AI 스튜디오 사양** (강사 가이드북 v0.9 실측): 모델 `google/gemma-4-31B-it` + `qwen3.8-flash-next` (vllm 자체 호스팅, Gemini·GPT 없음) / 코드 실행·데이터 시각화·파일 만들기·웹 검색·HTTP·MCP(exasearch) 활성 / 이미지 생성·음성 채팅 비활성 / 에이전트·워크플로우(노드 14종)·지식 베이스 RAG(HWP 직접 적재 가능) / **채팅 업로드는 HWP 미지원** [출처: 재단 제공 가이드북 2026-09]

## 4. 확정된 조건·제약 (다음 견적에 그대로 반영할 것)

- **계약 방식**: 나라장터 **전자수의계약**. 수의계약 범위를 2천만원 이내로 언급했다 (VAT 포함/별도 여부는 미확인)
- **인프라 비용은 견적에서 제외를 요청한다.** 사내 강의장 사용 + 교육생 AI 계정을 재단이 부여하기 때문
- **'기타 운영비' 또는 '교육 제반 비용' 항목을 별도로 편성해야 한다.** 모두의연구소가 교육 운영 시 다과를 직접 결제하는 방식. **항목명을 '다과비'로 쓰면 안 된다**
- 단가: 시간당 50만원 적용 (기본 60만원에서 4회차 연속 운영 할인). 총 1,870만원(VAT 포함)
- 교육 형태: 사내 교육장 오프라인 (30석, 25명 적정)
- 계정·라이선스: **재단이 조달.** 강사에게 Gemini Enterprise 일시 계정 부여 가능

## 5. 통한 것 / 통하지 않은 것

**통한 것**
- 재단이 이미 구축한 사내 AI 스튜디오를 주 실습 환경으로 쓰는 설계. "기존 투자 자산을 실제 업무에 쓰이게 만든다"는 논리
- 고객이 요청한 자료를 메일 본문 표로 항목별 답변해 함께 보내는 방식
- 재단이 강사 가이드북 작성을 위해 계정을 제공했다 → **환경 자료를 요청하면 주는 고객사다**

**통하지 않은 것 (반복하지 말 것)**
- 1차 상담의 "상용 Gemini 수준은 아님"만 근거로 사내 도구를 얕게 판단한 것. 실제로는 코드 실행·RAG·워크플로우까지 갖춘 환경이었다. **환경 자료를 먼저 받고 커리큘럼을 짜야 한다** — 이 때문에 4회차 구성을 전면 재설계했다
